# 雪を落とす枝

## 何をしているか

松の枝やその上の雪をつかみ、下へ引いて離す。小さく引くと雪を載せたまま揺れ、ほどほどに引いて離すと先側の小塊が外れ、強く引くと主枝と小枝の雪の大半が落ちる。雪の重さが減ると枝が戻る。引く場所、距離、速さで結果が変わる。

落ちた小塊は、画面の下へ達する途中で角や縁から少しずつ崩れる。核は途中で消さず、薄い雪煙を残す。すべて落ちてから4秒待ち、3.5秒かけて新しい雪が積もる。枝の姿勢は巻き戻さない。つかんでいる間は再積雪を止める。

## 大事なところ

枝に雪が載り、荷重でしなり、一部の雪を失うと戻る、というつながりを見せる。枝のねじれと雪の支持を先に成立させ、表面の粒や煙だけで雪らしさを足そうとしない。

雪は帯全体にわたって不規則な盛り上がりを持ち、側縁と帯の両端が丸く下へ回り込む形にする。一帯を4塊に分け、境目の結合と付着を局所的に解く。瞬間の反力だけで一帯をまとめて外さない。新しい雪は小さな領域から厚くなり、その体積に応じて枝への荷重も増える。

## 枝の計算

`rod.ts` は、中心線と区間ごとの断面の向きを持つ、長さを変えない離散弾性棒である。根元の位置と境界の断面座標を固定する。区間の断面はその中心で代表させ、根元から最初の区間中心までの半区間にも曲率を持たせる。描画でも付け根の接線は固定する。

親区間との休止時の相対姿勢に対し、回転ベクトルで二方向の曲げと軸まわりのねじれを表す。分岐も同じ接続を持つ。相対回転の弾性エネルギーは、区間間の距離を ℓ として `(B(qy²+qz²)+C qx²)/(2ℓ)` とする。曲げ剛性は `B=Eπr⁴/4`、ねじり剛性は `C=Gπr⁴/2`、`G=E/2.6`。E は広い画面で 1.8×10⁷、短い主枝を使う狭い画面で 1.25×10⁷ とする。場面の単位に合わせた値で、実在する松の材料定数ではない。

小枝の無荷重の形は水平に近く、先が少し下がる。主枝からの分岐角を上向きにせず、6秒ならした後の形には枝と雪の重さによるたわみを残す。

固定刻みは1/120秒。回転の指数写像とその微分から点の位置と速度の関係を求め、枝と付着中の雪の並進慣性を同じ質量行列へ足す。断面には小さな回転慣性も持たせる。弾性と Rayleigh 減衰を含む陰的な速度更新を Cholesky 分解で解く。局所の回転は有限回転として合成するが、速度更新では質量行列の時間微分による項を省いた近似である。静かな場面と手でしならせる操作を対象にする。

物理は TypeScript で計算し、描画用の位置と断面を WebGPU の storage buffer へ送る。Node の数値検査と画面で別々の物理実装を使わないためである。雪が外れた後の接触反力も枝に返す。つかむ位置は線分上の割合として保持し、対応する一般化力を枝へ伝える。固定された根元の近くを選んでも、別の節点へ選び直さない。

## 雪の支持と破断

広い画面は3帯・12塊、幅600px未満では2帯・8塊にする。枝はそれぞれ26点、19点である。付着中の下面は、枝の断面から半径と0.045だけ上げた支持面へ拘束し、位置と向きをその面へ追従させる。支持中の法線方向にばねを入れると、引き下げた枝から雪が取り残されるため使わない。

支持面の加速度を含む有効な重力で、圧縮、引張り、面に沿うせん断を評価する。pointer入力の段差をそのまま破断へ渡さないよう、加速度を45ミリ秒の時定数で平均する。静止摩擦は安息角38〜43°に対応させ、滑走摩擦は0.58とする。重さによる必要な力と、接触面積に0.21〜0.31の耐力を掛けた付着容量を比較する。設定の「雪の留まりやすさ」はこの容量の倍率である。面の傾斜が大きいと摩擦を超えて滑り、枝が下向きに重力より強く加速すると引張りで付着が傷む。超過率を3までに制限し、0.1秒相当の損傷で切る。超過がない間は毎秒0.3ずつ回復する。塊ごとに質量、耐えられる力の係数、摩擦の角度が異なるため、一斉には外れない。隣接する塊の境目は滑りの差を伝え、破断後は結合しない。

外れる直前まで重心と断面の履歴を更新する。破断は拘束だけを外し、質量、並進速度、角速度を変えない。枝の回転による重心の速度もここに含む。新しく外れた塊は同じ刻みで接触を解くが、時間を二重に進めない。

離脱後は元の支持区間に限らず、すべての枝と松葉に両側から当たる。枝は半径付き線分、松葉は描画と同じ根元・向き・たわみを使った二本の細い線分で近似する。雪にはSDFの細かな凹凸と別の回転する包絡箱を使う。線分と箱の最短距離を、箱の面を横切る区間ごとに求める。上下だけでなく端や横からの接触も拾い、枝の跳ね上がりで雪を押し上げる。松葉への反発は小さく、摩擦を強めにする。接触で付着を復活させたり、離れた物体を引き寄せたりしない。

重力は棒と雪で共通の場面単位2.8とし、従来の大きさと時間の関係を保つ。実在の松や雪の材料定数の再現ではない。枝は従来どおり1/120秒で解く。雪と接触は最低4分割し、並進が一回0.018、回転が0.05ラジアンを超えないよう最大64分割まで増やす。各回で前後の枝・松葉の位置を補間し、最も深い接触を最大8回解消する。衝撃は重心からのずれに応じて回転も変える。棒の質量、減衰、剛性、つかんでいる点の拘束から接触点の動きやすさを求め、雪と棒の両方へ逆向きの運動量を渡す。棒へ返した速度変化は同じ刻みの後続接触にも反映する。棒の位置が応答するのは次の固定刻みであり、完全な同時連成ではない。

落下中は姿勢ごとの投影面積と質量から二乗速度に比例する空気抵抗を求める。抵抗係数も塊ごとに少し異なり、回転には弱い減衰を掛ける。角の崩れで失う体積に比例して質量を減らし、削れた分はその時点の速度で運動量を持ち去る。距離場、光、雪煙と堆積の見た目は変えない。

## 雪の形と描画

物理用の包絡形と、目に見える雪面を分ける。`snow-shape.ts` は体積表、質量、選択判定と物理の形状格子に使う。接触では雪の格子を貫く線分を見落とさないよう、連続した包絡箱を使う。描画は `snow-render.ts` の距離場で行い、各小塊の位置・断面の向き・堆積量・削れ量を同じ Snow バッファから読む。描画の細かな凹凸の体積を、物理の質量へ足し戻すことはしない。

各小塊に画面上の四角を一枚だけ描き、フラグメントで最大72歩のレイマーチをする。一帯で共通の七つのつぶれた楕円体を滑らかに合わせ、三次元の非周期ノイズを三段重ねて、表面を浅く押し引きする。楕円体の位置・高さ・幅は一帯ごとの固定した種からずらす。物理の四分割で形の乱数種を変えず、隣接面をわずかに重ね、繰り返す筒の節を出さない。帯の両端は楕円体の丸みに任せる。底は支持面近くに残し、幅のある縁は少し下へ垂らす。松葉の一部は縁から突き出る。

光は曇天を想定する。上面を明るい白、下へ回り込む面をわずかに青灰色にし、距離場から凹みの浅い陰を調べる。微粒の法線の揺らぎと、ごく少数の弱いきらめきを加える。視線に沿う薄い縁は散乱光を近似して少し明るくする。レイマーチの交点から深度を書き、枝・松葉との前後を深度テストする。影の描画にも同じ距離場を使う。

堆積時は足場を平方根で広げ、高さを堆積量に応じて増やす。落ちた塊は既存の物理の削れ量に合わせて少し縮め、切り口を丸くし、角を不規則に欠く。完全な体積破壊や粒子への分解は計算しない。

`snow-powder.ts` は各小塊につき三枚だけ、崩れ始めた位置で時間をずらして雪煙を出す。放出時の速度の一部を引き継ぎ、ゆっくり沈みながら広がって2.1秒で消える。核が画面外で停止しても雪煙は最後まで残る。薄く大きくぼかした面を、枝と雪の後に深度テストとアルファ合成で重ねる。煙は力も質量も物理へ返さない。32バイトの Powder バッファを描画だけに追加し、Point と Snow、uniform の形式は変えない。

枝の管は断面12分割、長さ方向4分割。節点の間を Hermite 補間し、根元の接線は固定する。松葉の向きも断面に追従する。影は1024×1024の深度を9点でならす。4サンプルの MSAA を使い、ピクセル比は1.5までにする。霧の木立と空も計算で描き、外部の画像やテクスチャを読まない。

## 操作と停止

枝の描画曲線から表示上の24px以内、または現在の雪の投影内からつかめる。描画と同じ補間と投影を使い、CSSピクセルで距離を測る。`dragging.ts` で、選択、画面からの換算、つかんだ位置のずれ、変位上限2.8をまとめ、実際の入力とNode検査で同じ処理を使う。空のドラッグではカメラを動かさない。案内は左下の一行、設定は閉じて始める。指の縦移動は記事のスクロールへ渡す。

画面外と非表示タブでは更新を止める。動きを減らす設定では6秒ならした一枚を描き、つかんでいる間だけ更新する。再積雪は停止する。WebGPU を使えない場合やデバイスを失った場合は Canvas 2D の静止画と一行の案内へ切り替える。

## ブラウザを使わない検査

`node src/demos/nature-snow-bough/check.mjs` で、実際の更新処理を次の順に検査する。

- 二方向の片持ち梁の小変形を `FL³/(3B)` と比較し、誤差5%以内を確かめる。ねじれの復元と、枝全体の剛体回転に対するエネルギー・位置の一致も見る。
- 広い画面と狭い画面で6秒ならしてから40秒放置し、断面の姿勢変化1°未満、枝の長さ、雪の全点が枝軸の上にあることを確かめる。引いている間と離した後も、付着中の雪が下へ回り込まないことを見る。
- 1280×800で主枝の先寄り（第10区間の75%）を実際の画面位置から選び、30px・100px・160pxを0.5秒、220pxを0.2秒、290pxを0.12秒で下へ引く。60Hzと120Hzのpointer入力を通し、離して4秒後までの落雪数を数える。30pxは0塊、100pxは先側の1〜2塊、220px以上は8塊以上、両方の小枝でもそれぞれ2塊以上が外れることを確かめる。破断前後の質量・並進速度・角速度、画面の下までの落下、核の質量の減少、下からの引き寄せがないことを確かめる。
- 1280×800の(1000,450)から150pxを0.4秒、100pxを1.5秒、250pxを0.2秒で引く。60Hzと120Hzの入力で、支持面とのずれ、離脱時の並進・回転速度、枝軸が核を通過しないこと、跳ね返りによる上向きの速度、落下速度と回転のばらつきを見る。一刻みで2単位動く枝を六方向から当てる検査もある。
- 厚みの連続性、丸い縁、体積の増減を調べる。4秒待機、3.5秒の堆積、体積と質量の一致、つかんでいる間の停止も見る。
- 八つの画面サイズ・10,476件の選択判定、24pxの境界、雪からの選択、80バイトの uniform、80バイトの Point、192バイトの Snow、8個の binding の並び、32バイトの Powder、WGSL の予約語を検査する。雪煙の発生、核が停止した後の漂い、消滅と初期化も見る。

GPU上のコンパイル、描画の見た目、実際の指やマウスの操作はこの検査に含まない。
