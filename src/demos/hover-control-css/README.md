# CSS のホバーは途中で戻る

## 何をしているか

4 本の帯が並んでいる。マウスを乗せると、帯が左から赤く塗られていく。マウスを外すと、塗りが左へ戻る。CSS の `:hover` と `transition` だけで書いた版で、hover-control（JS で最後まで動かす版）と比べるためのもの。

## 大事なところ

CSS の `transition` は、状態が変わった瞬間に、そのときの値から新しい値へ向かい直す。マウスを乗せてすぐ外すと、塗りが途中まで伸びたところで向きを変えて戻っていく。帯の上をさっとなでると、どの帯も少しだけ赤くなってすぐ消える。

これはこれで素直な動きで、マウスの動きにすぐ応える。ただ、「塗りきってから戻る」という見せたい動きは、マウスを止めてくれる人にしか見えない。速く動かす人には、ちらつく中途半端な動きに見える。hover-control は、この問題を JS で解いている。

入るときと出るときで動きを変えるには、`transition` を 2 か所に書く。`:hover` の側に書いたものが入るときに、ふだんの側に書いたものが出るときに使われる。ここでは、入るときは 0.6 秒の `ease-out`（すっと伸びて止まる）、出るときは 0.5 秒の `ease-in-out`（ゆっくり戻り始める）にしている。

塗りは幅を変えるのではなく、`transform: scaleX()` で 0 から 1 にしている。`transform-origin` を左にしておくと、左から伸びる。幅を変えるよりレイアウトの計算が起きず、なめらかに動く。

## 作り方

動きは CSS だけで書いている。`main.ts` は、組（hover-control）の中で切り替えるための、何もしない `mount` だけを持つ。帯は 4 行の grid で入れ物いっぱいに並べている。塗りは帯の中に重ねた要素で、`z-index` で番号の文字の下に置いている。

## もとのデモから変えたこと

- 帯の高さを 500px の 4 分の 1 から、入れ物の高さの 4 分の 1 にした。iframe でも全画面でも 4 本で埋まる
- SCSS の入れ子をやめ、素の CSS にした
