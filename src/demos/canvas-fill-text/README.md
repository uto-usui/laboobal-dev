# 円で埋める文字

## 何をしているか

大きな 1 文字の形の中に、小さな円を次々に置き、ほかの円にぶつかるまで膨らませる。しばらくすると大小の円で文字が埋まる。クリックすると別の文字でやり直す。

## 大事なところ

円の置き場所は、文字を見えない canvas に書いて、塗られた画素から選ぶ。文字の形を数式で持たなくても、`fillText` で書いて `getImageData` で読めば、どんな字形でも「形の中の点」の一覧が手に入る。

円は「置く」と「膨らむ」を毎フレーム繰り返す。毎フレーム 10 か所を試し、すでにある円の中なら置かない。置いた円は 1px ずつ膨らみ、どれかの円に触れたところで止まる。最初に置かれた円ほど長く膨らめるので大きくなり、あとから隙間に置かれた円は小さいまま止まる。この大小の混ざり方が、詰め込んだ泡のような見た目になる。

膨らむのを止めるのは円どうしがぶつかったときだけで、文字の輪郭では止めない。だから輪郭から少しはみ出す円があり、それが手描きのような揺らぎになる。輪郭で止めると、きれいだが硬い形になる。

線は 1px の輪郭だけにして、色は青緑の中で色相と彩度を少しずつばらつかせる。塗りつぶすと重たい塊に見え、輪郭だけだと泡が透けて重なって見える。

## 作り方

Canvas 2D。毎フレーム全部の円を描き直す。ぶつかりの判定は、まだ膨らんでいる円だけについて、ほかの全部の円との距離を見る。止まった円は二度と見ないので、円が増えても重くなりにくい。新しい円が 1 秒置けず、膨らんでいる円もなくなったら、ループを止める。

文字の形を読む canvas は `willReadFrequently` を付け、CSS の px の大きさで作る。描く側の canvas は `fitCanvas` で解像度を上げ、座標は CSS の px のまま書くので、2 つの座標がそのまま合う。置き場所は 2px おきに集めている（1px おきだと多すぎて、選ぶ手間が増えるだけ）。

膨らむ速さは時間で決めている（1 秒に 60px）。旧デモは 1 フレームに 1px で、画面の書き換えが速い端末ほど速く膨らんでいた。

## もとのデモから変えたこと

- 旧デモは A〜F から選び、`sans-serif` の太字で書いていた。Montserrat の太字で、20 字から選ぶようにした。前と同じ字は続けて出さない
- 旧デモはずっとループを回し続けていた。埋まったら止める
- 旧デモは白い背景だった。サイトの暗い背景に合わせた。色の決め方は同じ
- iframe の大きさが変わったら、同じ文字で詰め直す
