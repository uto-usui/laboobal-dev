# グラデーションの水玉を描く

## 何をしているか

6 列 6 行の水玉を、画面いっぱいに等しい間隔で並べる。色は列ごとに変わり、左の青緑から右の赤紫へ移っていく。真ん中に細い線の正方形を 1 つ描く。processing.js の入門の記事の 1 本で、変数と `for` ループを見せる。

## 大事なところ

位置も色も、変数とループの番号から計算している。

- すき間の幅は、画面の幅から水玉の幅の合計を引き、すき間の数（水玉の数 + 1）で割って決める。320 − 30 × 6 = 140 を 7 で割って 20
- 水玉の中心は、`すき間 + 半径 + (すき間 + 直径) × 番号`。列の番号 `i` が x、行の番号 `j` が y になる
- 色は HSB の色相を `160 + 30 × i` にしている。列が 1 つ右へ行くたびに色相が 30 進むので、グラデーションに見える

水玉の数や大きさの変数を変えても、すき間が計算し直されて画面に収まる。

## 作り方

二重の `for` で 36 個の円を描いている。HSB の色は `src/shared/processing.ts` の `hsb()` で rgb に直す。もとの変数は `int` なので、すき間の割り算は `Math.trunc` で小数を切り捨てている。座標は記事と同じ 320×320 のまま書き、表示の大きさに合わせて拡大している。

## もとのデモから変えたこと

記事の本文にはコードがなく、fiddle のコードがもと。違いは次のとおり。

- processing.js をやめて、canvas 2D で描いた。`colorMode(HSB, 360, 100, 100, 100)` の色は、同じ色の rgb に直して渡している
- 背景の `background(180, 35, 80, 20)` は半透明。後ろのグラデーションが透けて見えるのは、もとと同じ
- 320×320 の固定の大きさをやめて、画面の大きさに合わせて正方形のまま拡大・縮小するようにした（もとの 2 倍まで）
- 見出しは Google Fonts の Dancing Script を実行時に読んでいた。外から読まないよう、同梱の Molle にした
- Bootstrap 4 alpha の CSS と JS を読んでいたのをやめた。見出しの大きさと余白は自分で書いた
- 枠の点線は canvas ではなく、外の箱に付けた。canvas に付けると、描く大きさが線の分だけずれるため
