# マウスの位置に円を描く

## 何をしているか

マウスの位置に、青から水色の半透明の円を毎フレーム描き重ねる。マウスを動かすと太い筆で描いたような跡が残り、止めた所ほど濃くなる。押している間は背景が暗い灰色になり、離すと明るい灰色に戻って、描いた円が消える。processing.js の入門の記事の 1 本。

## 大事なところ

`draw()` の中で、`mouseX` と `mouseY` の位置に円を 1 つ描くだけ。前のフレームの絵を消さないので、動かした跡がそのまま線になる。

- 円は不透明度 10% なので、1 つでは薄い。同じ所に重なるほど濃くなるので、速く動かすと薄く、ゆっくり動かすと濃い跡になる
- 色相は毎回 170 から 220 の間で引き直す。重なった所で水色と青が混ざる
- `mousePressed()` と `mouseReleased()` で `background()` を呼ぶ。背景を塗ると、それまでの円も塗りつぶされるので、これがリセットになる。押している間だけ暗いので、押したまま動かすと暗い背景の上に描ける

## 作り方

共有の `trackPointer` でマウスの位置を取り、`loop()` で毎フレーム円を描き足す。マウスが canvas の外にある間は描かない。押す・離すは `pointerdown` と、離したのが canvas の外でも拾えるよう window の `pointerup` で見ている。

画面の大きさが変わって描き直すときのために、リセットしてから描いた円を覚えておく（新しいほうから 3000 個）。座標は記事と同じ 320×320 のまま書き、表示の大きさに合わせて拡大している（`sketch.ts`）。

マウスのない端末では、触れていない間は共有の `pointerOrWander` が 8 の字をなぞり、その位置に描く。指で横になぞればその位置に描け、縦になぞると記事のスクロールになる（`touch-action: pan-y`）。動きを減らす設定では 8 の字は止まり、なぞった所だけに描く。

## もとのデモから変えたこと

記事の本文にはコードがなく、fiddle のコードがもと。違いは次のとおり。

- processing.js をやめて、canvas 2D で描いた
- `background(320)` と `background(200)` は、`colorMode(HSB, 360, ...)` の中では 360 を白とする灰色になる。その色（`rgb(227 227 227)` と `rgb(142 142 142)`）をそのまま書いた
- もとは、開いてすぐマウスを動かす前から、左上の角（0, 0）に円を描き重ねていた。マウスが canvas の上にある間だけ描くようにした
- マウスのない端末で、触れていない間は 8 の字をなぞって描くようにした
- 320×320 の固定の大きさをやめて、画面の大きさに合わせて正方形のまま拡大・縮小するようにした（もとの 2 倍まで）
- 見出しは Google Fonts の Dancing Script を実行時に読んでいた。外から読まないよう、同梱の Molle にした
- Bootstrap 4 alpha の CSS と JS を読んでいたのをやめた。見出しの大きさと余白は自分で書いた
- 枠の点線は canvas ではなく、外の箱に付けた。canvas に付けると、描く大きさが線の分だけずれるため
