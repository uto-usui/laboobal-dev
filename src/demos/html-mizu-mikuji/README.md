# 水占みくじ

## 何をしているか

小さな社の、湧き水を張った石の水盤。底に白紙のおみくじが並んでいて、水にひたした所だけ墨の文字がにじみ出る。手を近づけた側が持ち上がり、水は反対側へ寄る。水の中の文字は揺れて読みにくく、札の端の「結ぶ」「持ち帰る」も水の中では押せない。傾けて水を引かせ、濡れた紙を読んでから、結ぶか持ち帰るかを選ぶ。結んだ札は細く折られて、上の注連縄に掛かる。縁の御籤箱を押すと、空いた所に次の白紙が出る。水面には花手水の椿が浮いていて、水と一緒に流れてきて文字を隠す。

夜の焚き上げ所（html-takiage）と同じ社の、昼の水盤という置き方。ともしび川（html-emaki）が近くを流れていて、みくじの歌にも出てくる。

## 大事なところ

- 文字を隠すのは墨だけ。札の画素が紙の色から「灰色の向き」にずれていれば墨、赤だけが残るずれなら朱の刷りとみなす。ずれの向きで見るので、文字のふちの紙と混ざった薄い画素も取り違えない。朱の枠、見出し、項目名、結ぶ・持ち帰るの札はいつも見え、運勢と歌と答えだけが白紙に見える
- 札ごとに「どこがどれだけ水にひたったか」を横の列で数え、ひたっている間だけ増やす。減らさないので、一度出た文字は水が引いても残る。にじみ出る境目はノイズでむらにして、文字が一度にではなく、水際からまだらに湧いてくるようにする
- 濡れている間は紙が暗くなり、墨は青みのある灰色で少しぼける。水が引くと 3 秒ほどで乾き、くっきりした墨に戻る
- 水盤の底は椀の形。平らに置くと水は真ん中に溜まり、傾けると低い側へ寄る。いちばん傾けたとき、水の中心が端の札の上まで行く深さにしている。真ん中の札は、開いたときから水の中にあって文字が出てくるので、何をすればよいかが見て分かる
- 押せるかどうかは毎フレームの水から決める。札のうち水から出ている、いちばん長いひと続きの幅だけを当たり判定（`canvasClip`）にし、全部沈んだら外して `inert` にする。水盤の右半分の札は、結ぶ・持ち帰るを右の端（外側）に置く。真ん中は水の溜まる所なので、内側に置くと、押そうと手を寄せても傾きが足りない
- 傾きは画面の中での回転ではなく、奥行きの傾き（`rotateY`）。持ち上がった側が手前に来て大きく見える。いちばん傾けたときの四隅を先に画面へ写し、注連縄の下に収まる倍率をかけるので、高さ 400px の iframe でも角が外へ出ない
- 椿は水の流れに運ばれ、浅い所からは深い方へ引かれる。水を寄せると一緒に寄ってきて、ひたした札の文字を隠す。椿は札より手前の要素なので、重なった所の札は押せない

## 作り方

- HTML-in-Canvas（Chrome 157〜）。札、立て札、御籤箱、椿、注連縄を、それぞれ別の `drawable` の子にする。`paint` の `changedElements` に入った要素だけを `gl.texElementSubImage2D` で写し直す
- おみくじは本物の HTML の縦組み（`writing-mode: vertical-rl`）。縦書きの中の flex の column は右から左へ並ぶので、結ぶ・持ち帰るを `margin-block-start: auto` で読み終わり（左）に寄せる
- 水は横に 96 列の 1 次元の浅水方程式で、底の高さを足している。乾いた側の底が水面より高い所は壁として扱い、水のない所から押す力を作らない。量は列のあいだの流れでしか動かさないので変わらない
- 描く順は、石と底の札と縁の物を水盤の座標の framebuffer へ、それを水盤の形で画面へ（ここで水の屈折、色、光の網、空と葉の映り込み、木漏れ日をかける）、椿、飛んでいる札、注連縄、結んだ札。WebGL2 を直に使う
- 結ぶ、持ち帰る、引くの動きは、札の見えている四角から行き先の四角へ、画面の座標で補間する。結ぶときは折り目の山と谷を明暗でつけながら細くする
- マウスのない端末ではゆっくり揺らす。指で触った所は 4 秒そのまま傾けておく
- 動きを減らす設定では、勝手に揺らすのをやめ、水は振動させずに寄せ、文字はひたったらすぐに出す。結ぶ、持ち帰る、引くの動きは、読む人が始めるものなので残す
- 使えないブラウザでは、おみくじをふつうの HTML として並べる（文字は全部見える）
