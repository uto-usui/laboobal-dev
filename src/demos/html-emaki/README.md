# 透ける絵巻

## 何をしているか

HTML で描いた長い絵巻（紙 8 枚、7200px）を、机の上で横に引いて読む。右から左へ読み、読んだ所は右に巻きとられ、まだ開いていない所は左の巻きからほどけて出てくる。題は「ともしび川絵巻」で、山のしずくが里と市をとおって夜の海へ出るまでの一日を描いている。

市で灯籠を選ぶと、選んだ灯籠が渡し舟、灯籠流し、海の場面に描きこまれ、奥書に流した数が入る。渡しで岸を選ぶと、夕立の詞書と雨やどりの場所、灯籠を流す岸が変わる。変わった先の場面は、まだ巻かれたままでも裏から透けて見える。

## 大事なところ

- 巻いた感じは、紙の裏から絵が透けることで出る。巻きの外に見えるのは紙の裏なので、同じ位置の絵を薄く、ぼかして、色を少し抜いて重ねる。さらに 1 巻き内側の絵を、もう 2 枚ぶんの紙を通したくらいの薄さで重ねる。夜の場面が近づくと、左の巻きが暗くなる
- 巻きは等間隔の渦にする。巻いた長さから外の半径が決まり、外からの角度は半径の差に比例する。読むほど右の巻きが太り、左がやせる。手前の木口には、層の境目が渦の線として見える
- 左の巻きの芯は絵巻の終わりに付く軸で、軸首が天地から出る。右の巻きの芯は始まりの細い八双で、巻いた量がまだ少ないうちは細い
- 斜投影（z の分だけ画面の上へずらす）で描く。平らな紙は z = 0 なので、画面への写し方が平行移動と拡大だけになり、HTML の当たり判定をそのまま重ねられる。絵巻そのものが使う平行投影（吹抜屋台）と同じ見え方でもある
- 当たり判定は平らに見えている所だけ。巻きの下に隠れた幅も外す。巻かれかけた灯籠や岸の札は押せない
- 紙継ぎ（2 枚が重なる所）は少し暗く、透けにくい。天地の耳はノイズで不揃いにし、紙には繊維とむらを入れる

## 作り方

- HTML-in-Canvas（Chrome 157〜）。紙 1 枚を `drawable` の子 1 つにして、`paint` の中で `texElementSubImage2D` で 1 枚の atlas に右から左へ並べて写す。`changedElements` に入った紙だけを写し直す
- 巻きの形は頂点シェーダーで決める。頂点には紙の上の位置 s と天地の y だけを入れて固定し、毎フレーム送るのは巻きの中心と半径などの uniform だけ（`shaders.ts`、`scene.ts`）
- 当たり判定は紙ごとに `updateElementGeometry` の `canvasTransform`（平行移動と拡大）と `canvasClip`（要素の中の座標）で置く。平らな所に見えていない紙は `clearElementGeometry` で外す
- 横のドラッグ（離すと慣性）、トラックパッドの横スワイプ、← → キーで動かす。縦のホイールと縦のスワイプは記事のスクロールに残す（`touchGate`）。巻かれた所の部品に Tab で来たら、そこまで開く
- 灯籠と岸の選択は CSS の `:has()` だけで先の場面に反映する。奥書の数と日付だけ JS で書く
- 絵は SVG と CSS。`feTurbulence` と `feDisplacementMap` のフィルターで、線を少しゆらし、岩絵具のざらつきを足している
- 巻きの奥に入った紙は CSS の animation を止め、`paint` が出続けないようにする
- 動きを減らす設定では、開く再生、慣性、紙の浮き、水や雨の animation を止める。ドラッグはそのまま動く
- HTML-in-Canvas が使えないときは、紙を右から左へ並べて横にスクロールして読む
