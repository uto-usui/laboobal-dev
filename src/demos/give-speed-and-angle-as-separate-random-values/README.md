# スピードと角度を別々のランダムな sin 波で与える

## 何をしているか

灰色の箱が、縦・横・奥行きの 3 つの向きに、それぞれ違う速さで揺れる。3 つの揺れがそろわないので、同じ道を二度となぞらず、ふわふわと漂って見える。開くたびに動き方が変わる。

## 大事なところ

x、y、z のそれぞれに、始めの角度と速さを別々に持たせる。始めの角度は 0〜360 度、速さは 1 秒に -120〜240 度のあいだから、開いたときにでたらめに選ぶ。毎フレーム、それぞれの角度を自分の速さで進め、x と y は `sin(角度) × 半径`、z は `cos(角度) × 半径` にする。

[奥行きのある円運動](../circular-motion-with-depth/) は角度が 1 つなので、きれいな円になる。ここでは角度が 3 つあり、進む速さもばらばらなので、円にならない。速さが負になった向きは、逆に回る。

## 作り方

位置は GSAP の `gsap.set` で `x`、`y`、`z` を入れている。でたらめな数は `random()`（src/shared/math.ts）で選ぶ。

動きを減らす設定のときは、箱を真ん中に置いて止める。でたらめな角度のまま止めると、画面の端で止まることがあるため。

## もとのデモから変えたこと

記事の本文には TweenMax と jQuery のコードが載っている。違いは次のとおり。

- TweenMax 1.20 と jQuery を、GSAP 3 にした
- もとのコードは、y の位置にも `angle.x` を使っていた。y の角度と速さを選んでいるのに使っておらず、箱は斜めの線の上を行き来していた。題名どおり、y には y の角度を使うようにした。このため、もとのデモより縦に自由に動く
- 角度の進み方を、1 フレームに -2〜4 度から、1 秒に -120〜240 度にした
- 中心と半径を、ステージの大きさで、大きさが変わるたびに決め直すようにした
- 大きな画面で箱が `perspective` を越えて消えないよう、`perspective` を広げるようにした
- 画面の外では止まる。動きを減らす設定では、真ん中で止まる
