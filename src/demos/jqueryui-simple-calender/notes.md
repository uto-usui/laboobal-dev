# 開始日と終了日を選ぶカレンダー

## 何をしているか

上の枠は、開始日（FROM）と終了日（TO）を選ぶ 2 つの欄。開始日を選ぶと、終了日はそれより前を選べなくなる。終了日を選ぶと、開始日はそれより後を選べなくなる。

下の枠は、いつも出しておくカレンダー。日を押すと、その日が下の欄に入る。Prev と Next で月を移る。

## 大事なところ

記事の言う「時空が逆転しないようにする」は、片方を選んだら、もう片方の選べる範囲の端をその日にすること。開始日を選んだら終了日の `min` に、終了日を選んだら開始日の `max` に入れる。入れるのは選んだときだけで、あとから開始日を変えれば終了日の範囲もついてくる。

カレンダーは、月の 1 日が何曜日かを見て、その数だけ前を空けてから日を並べる。日の数は「翌月の 0 日」（`new Date(year, month + 1, 0)`）、つまりその月の最後の日で分かる。

## 作り方

jQuery UI は使っていない。

開始日と終了日は `<input type="date">` にした。カレンダーはブラウザのものが出て、`min` と `max` で選べない日は押せなくなる。jQuery UI の `minDate` と `maxDate` にあたる。

下のカレンダーは自分で作った。見出し（Prev、月、Next）と曜日は 1 回だけ作り、月を移るたびに日のところだけを作り直す。見出しを作り直さないので、Prev や Next にキーボードの focus が残る。日は `<button>` で、選んだ日には `aria-pressed="true"` を付けて色を変える。見た目は、もとで jQuery UI のカレンダーに当てていた CSS（`#ccc` の線と文字、`#fafafa` の地、大きな影）を移した。

## もとのデモから変えたこと

記事の本文には jQuery UI のコードが載っている。違いは次のとおり。

- jQuery と jQuery UI をやめた。jsfiddle の「jQuery (edge)」はその時の最新の jQuery を読むので、jQuery UI 1.12 と合わなくなるおそれがあった
- 開始日と終了日を、jQuery UI の `datepicker` から `<input type="date">` にした。開いたカレンダーの見た目はブラウザのものになり、もとの CSS は当たらない
- 範囲を狭めるきっかけを、カレンダーを閉じたとき（`onClose`）から、日が変わったとき（`change`）にした
- 下の欄に入る日の形を、`11/02/2026` から `2026-11-02` にした。上の欄の値と同じ形
- 2 つの枠を、広い画面では横に並べた。縦に積むと、高さ 400px の iframe ではカレンダーがほとんど隠れる
- 見出しは Google Fonts の Dancing Script を実行時に読んでいた。外から読まないよう、同梱の Molle にした
- Bootstrap 4 alpha の CSS と JS を読んでいたのをやめた
- SCSS を普通の CSS にした
