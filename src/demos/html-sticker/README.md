# 箱のシールを剥がす

## 何をしているか

段ボール箱に、宛名ラベル、こわれもの、丸い検品済み、天地無用の 4 枚のシールが貼ってある。どれも本物の HTML で、宛名ラベルの欄には名前を書ける。シールの角をつまんで引くと、角が筒に巻きつくようにめくれて裏の白が見え、持ち上がった所の影が箱に落ちる。離すと貼り戻り、箱に当たった角が小さく跳ねる。マウスを角に近づけると、角が少し浮く。

## 大事なところ

- めくれ方は物理演算ではなく、形を式で決めている。つまんだ角から引いた向きに折り目を置き、折り目から角の側を半径 13px の筒に巻きつける。巻くのは半周より少し手前（π − 0.38）までで、その先は巻き終わりの向きのまままっすぐ伸ばす。めくれた所が平らに裏返らず、少し持ち上がって見える
- 折り目の位置は、指が動いた距離から逆に求める。筒に巻きついている間、角は横へはほとんど動かず上へ持ち上がるので、引き始めの数 px で角がふっと浮く。引き続けると、角が指の下についてくる
- めくる起点は、引く向きに沿っていちばん手前の点にしておく。そうしないと、引き始めた瞬間に、つまんだ角より先に別の縁がめくれる。四角は角を動かさず、引く向きを角から内側の 90° に収める。丸は向きを縁から中心へ向かう向きの左右 70° に収め、起点をその向きの反対側の縁へ動かす。どちらも、外へ引いてもシールは内側へめくれる
- 剥がれきらない。折り目がシールの奥行きの 8 割を越えないようにし、その手前から引いても重くなるようにした（tanh で上限へ寄せる）。勢いよく離したときも、ばねの行き過ぎで上限を越えないよう止める
- 跳ねている途中でつかみ直すと、そのときのめくれた量から続く。上限へ寄せる式を逆に解いて、指がそれだけ動いたことにして始める
- つかんでいる指だけを見る。2 本目の指で押しても、ほかのシールはつかまない
- 離したあとはばねで戻し、0 を下回ったら速さを 3 割だけ逆向きにして返す。これで角が箱に当たって跳ねる。跳ね返る速さには上限を付けて、大きくめくって離しても跳ねすぎないようにした
- 影は 2 つに分けた。貼ってある所の縁に出る紙の厚みの影と、持ち上がった所の影。持ち上がった所の影は、高さに比例して右下へずらし、高いほど薄くぼかす。筒の所と伸びた所の影が重なって濃くならないよう、ステンシルで 1 つの画素に 1 回だけ描く

## 作り方

- HTML-in-Canvas（Chrome 157〜）。`<canvas content="drawable">` の子に 4 枚のシールを置き、`paint` のたびに `texElementSubImage2D` で WebGL のテクスチャに写す。欄に字を打つと、めくれている間もそのまま写る
- めくれ方は頂点シェーダーで計算する（`render.ts`）。シールごとに 5px 角の格子を作り、折り目の位置、引いた向き、筒の半径を uniform で渡す。CPU の側（`peel.ts`）は、指の動きから折り目の位置を求めるだけ
- 裏返ったかどうかは、法線が画面の奥を向いているかで決め、裏は台紙の白で塗る
- 当たり判定は `updateElementGeometry` に、貼ってあるときの位置と傾きの行列を渡す。めくれている間は HTML に触らせず、どこを押してもつまむ側になる
- three は使っていない。html-cloth と同じく、`texElementSubImage2D` は WebGL のテクスチャを直に渡す API のため
- 使えないブラウザでは、シールを canvas の外へ出して、ふつうの HTML として並べる
