# 1 列を引き伸ばす

## 何をしているか

写真の縦 1 列だけを切り出して画面の幅いっぱいに引き伸ばすと、横縞になる。使う列を左右に往復させるので、縞の色が移り変わり続ける。クリックすると、左から 1 列ずつ写真を本来の位置に描きながら、今の列を右の端まで伸ばす。写真が縞を引きずりながら左から現れる。

## 大事なところ

`drawImage` の 9 つの引数の形（写真の側の範囲と、画面の側の範囲）を使うと、写真の幅 1 列を画面の何百 px にも引き伸ばせる。縦の色の並びはその列のまま、横だけが伸びるので、写真の持っている色が帯になって見える。

写真を出すときは、描いたところを消さない。左から 1 列ずつ本来の位置に描き、その右の残りは今の列で塗りつぶす。次のフレームでは 1 列右から同じことをするので、左側には本来の写真が残り、右側は毎フレーム新しい縞に塗り替えられる。境目では、直前に描いた列の色がそのまま右へ流れ出しているように見える。スキャナーやスリットスキャンの写真と同じ見え方。

旧デモは 1 フレームに 1px ずつ進めていた。速さを時間で決めると 1 フレームに数 px 進むことがあるので、進んだ分の列は伸ばさずにまとめて本来の位置に描き、最後の列だけを伸ばす。こうしないと、写真に縞の抜けが残る。

## 作り方

Canvas 2D。`fitCanvas` で解像度を上げ、座標は CSS の px で書く。写真は画面いっぱいに切り取る範囲（`object-fit: cover` と同じ）を先に求め、画面の x の位置を、その範囲の中の写真の x に直して読む。

縞のときは 1 秒に 90px、写真を出すときは 1 秒に 240px 進める。出しているときに iframe の大きさが変わったら、左からやり直す。

## もとのデモから変えたこと

- 旧デモは「show」のボタンで写真を出すだけで、戻せなかった。画面のどこをクリックしても、縞と写真を行き来する
- 旧デモは写真の幅を画面の幅に合わせていて、縦長の写真は上のほうしか使っていなかった。画面いっぱいに切り取る形にした
- 写真は旧デモと同じ Unsplash の写真（photo-1608902918218-0f142aef5cfd）を落として置いた
- 縞の動きの描き方は旧デモと同じだが、旧デモは引き伸ばす先を画面の左の外から始めていた。見え方は変わらないので、画面の左端から描く
