# ぶつかって弾く玉と線

## 何をしているか

大きさと色の違う玉を画面いっぱいにゆっくり漂わせ、近くにいる玉どうしを細い線で結ぶ。玉どうしが重なると、互いに反対へ弾かれて速くなり、だんだん元のゆっくりした速さに戻る。

## 大事なところ

玉は 3 つの層に分かれている。奥の層は小さく暗い色、手前の層は大きく明るい色で、線を結ぶ距離も奥ほど短い（45px、75px、100px）。線の色も奥ほど暗い。ぶつかるのも線を結ぶのも同じ層の中だけなので、層どうしは互いに素通りし、奥行きのある網に見える。

置き方は、画面を升目（70px × 80px）に分け、升ごとにどの層の玉を置くかをくじで決める。0〜5 の数を引き、0 なら大と中、1 なら中と小、2 なら大と小を置き、3〜5 なら何も置かない。升目に沿って置くので玉どうしが最初から重ならず、くじで穴があくので、升目の並びが目に見えない。

弾かれた玉は速くなるが、毎フレーム「今の速さと元の速さの差」の 1 割ずつ減らすので、急に止まらず、すっと元の漂いに戻る。この戻り方が、ぶつかったときの気持ちよさを決めている。弾く速さは右上の設定のパラメーターで変えられ、大きくすると玉が勢いよく散る。

線は、玉が近づくと急に現れ、離れると急に消える。線の透明度は距離によらず一定（60%）なので、網目がつながったり切れたりする様子がはっきり見える。

## 作り方

Canvas 2D で描いている。毎フレーム画面を消し、奥の層から順に、線を引いてから玉を描く。

動きは 60fps のときの 1 フレーム分を基準にし、`loop` から来る前のフレームからの秒数に 60 を掛けて進める。速さを減らす係数も `0.9 ** フレーム数` にして、フレームレートが違っても戻り方が同じになるようにした。

画面の大きさが変わったら（`onResize`）、canvas を `fitCanvas` で合わせ直し、玉を置き直す。数字はすべて CSS ピクセルで書いている。

弾く速さは `params` に出していて、右上の設定を開いたときにだけ lil-gui で欄を出す。値を変えると玉を置き直す。`prefers-reduced-motion` が有効なときは、玉を置いた 1 枚だけを描いて動かさない。

## もとのデモから変えたこと

- 旧デモは canvas を画面の 2 倍の大きさで作って CSS で縮めていたので、コードの数字がすべて 2 倍だった。作り直しでは `fitCanvas` で解像度を合わせ、玉の大きさ、升目、線を結ぶ距離、速さをすべて半分にして CSS ピクセルで書いた。見た目の大きさは同じ
- 旧デモは、衝突したかどうかを 1 つの変数で全部の玉に共有していて、最後に調べた組が重なっていたかどうかで、全部の玉の減速をするかしないかが決まっていた。実際には減速しないフレームがときどき混ざるだけなので、作り直しでは毎フレーム減速するようにした
- 画面の端で跳ね返る判定が、左右に当たったときは上下を見ていなかった。4 辺とも見るようにした
- 旧デモは画面の大きさが変わっても玉を置き直さず、ページを開き直すたびに玉が足されていた。作り直しでは大きさが変わったら置き直す
- 1 フレームに進む量を、フレームレートに左右されないようにした
- パネルを tweakpane から lil-gui にした。弾く速さの値は半分にしたので、初期値は 5.5 から 2.75 に、範囲は 0.25〜50 にした
