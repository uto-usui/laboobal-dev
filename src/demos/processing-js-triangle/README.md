# 三角形を描く

## 何をしているか

灰色の正方形に、画面いっぱいの円と、その円に収まる上向きの三角形を描く。左上には白く塗った小さな三角形がある。processing.js の入門の記事の 1 本。

## 大事なところ

三角形の描き方を 2 通り見せている。

- 白い三角形: `triangle(100, 50, 50, 150, 150, 150)`。3 つの頂点の位置をそのまま書く
- 大きい三角形: 円を 3 等分する点（0 度、120 度、240 度）を求めて結ぶ。半径と角度から `r × cos`、`r × sin` で頂点を出すので、数を変えれば五角形や六角形にもなる

0 度は右を向くので、そのままだと三角形は右を向く。先に座標を -90 度回しておくと、1 つ目の頂点が真上に来る。

## 作り方

canvas 2D のパスで頂点を結んでいる。回すのは `ctx.translate` で中心へ移してから `ctx.rotate`。座標は記事と同じ 320×320 のまま書き、表示の大きさに合わせて拡大している（`src/shared/processing.ts`）。

## もとのデモから変えたこと

記事の本文には `triangle()` の 1 行だけが載っている。違いは次のとおり。

- processing.js をやめて、canvas 2D で描いた
- もとは円と大きい三角形を `draw()` で毎フレーム描き重ねていた。同じ所に重ねるだけなので、1 回だけ描くようにした。もとは重ねるうちに線のにじみが濃くなっていたので、線は少し薄く見える
- `stroke(100)` は、`colorMode(HSB, 360, ...)` の中では 360 を白とする灰色になる。その色（`rgb(71 71 71)`）をそのまま書いた
- 320×320 の固定の大きさをやめて、画面の大きさに合わせて正方形のまま拡大・縮小するようにした（もとの 2 倍まで）。線の太さも同じ割合で変わる
- 見出しは Google Fonts の Dancing Script を実行時に読んでいた。外から読まないよう、同梱の Molle にした
- Bootstrap 4 alpha の CSS と JS を読んでいたのをやめた。見出しの大きさと余白は自分で書いた
- 枠の点線は canvas ではなく、外の箱に付けた。canvas に付けると、描く大きさが線の分だけずれるため
