# マウスに合わせて傾けるパララックス

## 何をしているか

写真と見出しの箱を重ねて置き、マウスのほうへずらしながら斜めに傾ける。マウスが外に出ると、ゆっくり元に戻る。

## 大事なところ

立体に見えるのは、ずらす量の係数を要素ごとに変えているから。写真は中心からのマウスの距離の 0.05 倍、見出しは 0.1 倍動く。手前の見出しが奥の写真の倍動くので、2 枚の間に奥行きがあるように見える。

傾け方は、横のずれの 0.2 倍（度）を `skewX` と `skewY` の両方に入れるだけ。両方に同じ値を入れると、板がマウスのほうへ回り込んだように見える。3D の回転を使わずに、平らな要素を立体らしく見せている。縦のずれでは傾けない。

追いかける速さは 1.2 秒。マウスを動かすたびに、今の位置から 1.2 秒かけて行き先へ向かい直す。行き先が動き続けるあいだは追いつかないので、重さのある、遅れてついてくる動きになる。止まると減速しながら着く（`power1.out`）。

## 作り方

GSAP の `gsap.quickTo` で、要素ごとに `x`、`y`、`skewX`、`skewY` の 4 つを作っておき、`pointermove` のたびに行き先だけ渡している。`gsap.to` をマウスが動くたびに作ると、GSAP 3 では古い tween が消えずに積もるため。外に出たら（`pointerleave`）全部 0 へ向かわせる。

係数は要素の `data-mouse-parallax` に書いてある。要素を足すときは属性を付けるだけでよい。

## もとのデモから変えたこと

- `TweenMax.to(el, 1.2, {...})` を毎回作っていたのを `gsap.quickTo` にした。時間と ease（TweenMax の既定の `Power1.easeOut`）は同じ
- `data-mouse-skew` が付いた要素は傾けない、という分かれ道があったが、使っている要素がないので外した
- マウスの位置の計算を `pageX - pageYOffset` から `clientX` にした。結果は同じ
- Bulma の CSS を読んでいたのをやめ、見出しの大きさと余白を自分で書いた。見出しの文字は太字にした
- 写真は `source.unsplash.com` のランダム画像だった。Unsplash の人物の写真を正方形に切って置いた
- SCSS を普通の CSS にした
- 狭い画面ではみ出さないよう、写真の幅を `min(300px, 55cqw)` にした
