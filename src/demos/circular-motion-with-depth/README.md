# 奥行きのある円運動

## 何をしているか

灰色の箱が左右に揺れながら、奥へ遠ざかったり手前に近づいたりする。上から見ると、箱は円を描いて回っている。手前に来ると大きく、奥に行くと小さく見える。

## 大事なところ

角度を 1 つだけ持ち、毎フレーム少しずつ進める。横の位置は `sin(角度) × 半径`、奥行きは `cos(角度) × 半径 × 1.5` にする。sin と cos を組にすると円になる。[オブジェクトを円を描きながら動かす](../move-an-object-while-drawing-a-circle/) では cos を縦に使ったが、ここでは奥行き（z）に使うので、横から見た円になる。

奥行きが見えるのは、親に `perspective` と `transform-style: preserve-3d` を付けているから。z が大きいほど手前に来て、大きく描かれる。

## 作り方

位置は GSAP の `gsap.set` で `x`、`y`、`z` を入れている。角度は `loop()` の dt を使って 1 秒に 120 度進める。

中心と半径は、ステージの大きさから決める。大きさが変わったら `onResize` で決め直す。

動きを減らす設定のときは回さず、そのときの位置で止める（`autoplayLoop`）。

## もとのデモから変えたこと

記事の本文には TweenMax と jQuery のコードが載っている。違いは次のとおり。

- TweenMax 1.20 と jQuery を、GSAP 3 にした。`TweenMax.set(this.target, {...})` は `gsap.set(target, {...})`、`$('.target').width()` は `offsetWidth`
- 角度の進み方を、1 フレームに 2 度から、1 秒に 120 度にした。画面のリフレッシュレートが 60Hz でなくても同じ速さで回る
- 中心と半径を、開いたときの `window` の大きさで 1 回だけ決めていたのを、ステージの大きさで、大きさが変わるたびに決め直すようにした
- 半径が大きいと、箱が手前に来たときに `perspective`（500px）を越えて、目の後ろに回って消えていた。高さ 300px ほどの iframe では起きないが、大きな画面では起きる。`perspective` を「奥行きの振れ幅 × 2」以上に広げて、消えないようにした
- クラスをやめて、関数と変数で書いた
- 画面の外では止まる（`loop()`）。動きを減らす設定では止まる
