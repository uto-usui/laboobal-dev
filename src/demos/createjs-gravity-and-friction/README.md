# 重力と摩擦で弾む丸

## 何をしているか

上から落ちた丸が床で弾む。弾むたびに低くなり、2 秒ほどで床に止まる。止まって 1 秒たつと、また上から落ちる。

## 大事なところ

毎フレーム、縦の速さに 2 つのことをするだけで動きができている。

- 重力: `vy += .5`。毎フレーム下向きに少しずつ速くなる
- 摩擦: `vy *= 0.95`。毎フレーム速さを 5% ずつ減らす。落ちる速さは、重力で増える分と摩擦で減る分がつり合う 1 フレームに 9.5 で頭打ちになる

床に着いたら、めり込んだ分を戻して `vy *= -1` で向きを反対にする。跳ね返るときには速さを減らしていないが、上がるあいだも下がるあいだも摩擦で速さが減るので、弾むたびに低くなって止まる。

## 作り方

重力と摩擦は 1 フレームあたりの量なので、前のフレームからの秒数を 1/60 秒ずつに刻んで、その回数だけ同じ計算をしている。画面のフレームレートが 60fps でなくても、同じ速さで落ちて同じ回数だけ弾む。

もとの canvas（250×250）の座標のまま描き、入れ物に収まる大きさまで canvas を広げる（もとの 2 倍まで）。

## もとのデモから変えたこと

記事の本文には、CreateJS の `Stage`、`Shape`、`Ticker` を使ったコードが載っている。違いは次のとおり。

- CreateJS をやめ、canvas 2D で描き、共有の `loop` で回している
- もとは一度落ちて止まったら、そのまま動かなかった。止まって 1 秒たったら、また上から落とす
- 丸の色は記事のコードの `hsl(160, 65%, 70%)` にした。fiddle は `DarkRed` だった
- 見出しの「create.js」を、fiddle の題名からとった「gravity」にした。CreateJS を使わなくなったため
- canvas の点線の枠は `border` から `outline` にした。`border` だと canvas の大きさに入り、座標がずれる
- canvas を 250×250 の固定から、入れ物に合わせた大きさにした
- 動きを減らす設定では、床に止まった丸を見せる
- SCSS を普通の CSS にした
