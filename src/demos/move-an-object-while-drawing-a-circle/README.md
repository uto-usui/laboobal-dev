# オブジェクトを円を描きながら動かす

## 何をしているか

緑の玉が、薄い線で描いた円の上を、同じ速さでぐるぐる回り続ける。

## 大事なところ

角度を 1 つ持ち、毎フレーム少しずつ進める。玉の横の位置を `sin(角度) × 半径`、縦の位置を `cos(角度) × 半径` にすると、玉は半径の大きさの円の上を回る。sin も cos も -1〜1 を行き来するので、半径を掛けると、中心から半径の分だけ離れたところを動く。

半径は画面の高さの 1/4 にしている。

## 作り方

位置は GSAP の `gsap.set` で `x` と `y` を入れている。角度は `loop()` の dt を使って 1 秒に 120 度進める。

円の線は、半径の 2 倍の大きさの丸い枠で描いている。大きさは半径を決めるときに `--diameter` で渡す。

動きを減らす設定のときは回さず、そのときの位置で止める。

## もとのデモから変えたこと

記事の本文には TweenMax と jQuery のコードが載っている。違いは次のとおり。

- TweenMax 1.20 と jQuery を、GSAP 3 にした
- もとの円の線は `calc(100vw / 2 - 50px * 2 - 10px)` の大きさで、画面の幅から決めていた。玉の通り道は画面の高さから決めているので、画面の形によって、線と玉の通り道がずれていた。ここでは線の大きさを玉の通り道に合わせた
- 角度の進み方を、1 フレームに 2 度から、1 秒に 120 度にした
- 中心と半径を、ステージの大きさで、大きさが変わるたびに決め直すようにした
- 使っていなかった `perspective` と `transform-style` を外した
- 画面の外では止まる。動きを減らす設定では止まる
