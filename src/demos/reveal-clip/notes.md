# 切り抜いて見せる

## 何をしているか

写真が左から右へ、切り抜きが広がるように現れる。クリック（タップ）すると、いったん左へ畳まれてから、また左から開く。

## 大事なところ

写真は動かさず、見えている範囲だけを広げている。写真の右側を 100% 削った状態（幅 0）から、削る量を 0 にしていく。写真が滑り込んでくるのではなく、その場にある写真の上の覆いが取れていくように見える。写真の位置が動かないので、見る人の目は写真の中身に向く。

動き方は `expo.out` で 1 秒。最初の一瞬でほとんど開ききり、残りの時間で最後の少しをゆっくり埋める。開き始めの速さで「現れた」ことが伝わり、終わりのゆるさで落ち着いて見える。reveal-curtain の幕のような間（ま）はなく、1 回の動きで見せきる。

畳むときも同じ `expo.out` で、右から左へ削っていく。畳んでから開くと、同じ左端を起点に閉じて開くので、写真が左端に吸い込まれてまた出てくるように見える。

## 作り方

CSS の `clip-path: inset(上 右 下 左)` を GSAP で動かしている。隠れた形は `inset(0% 100% 0% 0%)`（右を 100% 削る）、全体は `inset(0% 0% 0% 0%)`。割合で書いているので、写真の大きさが変わっても計算し直さなくてよい。最初の形は CSS に書いておき、読み込みの直後に写真がちらっと見えないようにしている。

写真の読み込みが終わってから（`decode()`）、0.5 秒あとに開く。クリックで timeline を作り直し、畳んでから開く。

## もとのデモから変えたこと

- 旧デモは CSS の `clip: rect()`（古い指定で、今は使わない）を px で書き、要素の大きさを JS で測って固定していた。`clip-path: inset()` を割合で書くようにした
- 旧デモは写真を包む要素を JS で足していた。`clip-path` は写真に直接かけられるので、包む要素はなくした
- 旧デモは向きを 4 つ（左右上下）から選べる部品だった。このデモは左から右だけにした
- 旧デモは読み込みから 2 秒待って始めていた。写真の読み込みが終わるのを待ってから始めるようにした
- 旧デモの「Re:start」のボタンは「replay」として残し、そのほかのどこをクリック（タップ）してももう一度見られるようにした
- 写真を `source.unsplash.com` のランダム画像（サービスが止まって出なくなっていた）から、Unsplash の写真をリポジトリに置いたものにした
