# 焚き上げの短冊

## 何をしているか

夜の小さな社の焚き上げ所。札掛けに和紙の短冊の束が綴じてあり、いちばん上の短冊に、手放したいことを縦書きで書ける。短冊の足もとをつまんで引くと、綴じ目でちぎれる。ちぎった短冊は指から垂れて揺れ、篝火の上にかざすと、触れる前から下の端が焦げ始める。火が付くと、燃え際が下から上がっていき、書いた字に届くと字が先に赤く光ってから焦げ、灰と火の粉と煙になって昇る。

火から離れた所で離すと、短冊は地面に落ちる。拾い直してくべることもできる。綴じ目には、ちぎった数だけ半券が重なって残る。束を使い切ると、新しい束に替わる。

同じ社の、昼の水盤のデモ（水占みくじ）と、近くを流れる絵巻の川（ともしび川）と同じ世界に置いている。

## 大事なところ

- 燃えるのは、さっきまで自分で打っていた本物の欄。テクスチャは HTML から写しているので、変換した字も、字の大きさを詰めた跡も、そのまま焦げていく。ちぎった瞬間に欄は読みとり専用になり、もう書き直せない
- 火は炎の根もとほど熱くし、先の方では焦がすだけにしている。紙の中では、火の付いた点が隣へ燃え広がり、上へは速く、横と下へは遅い。だから燃え際が 1 本の線になって下から上がり、字の上を順に通っていく。燃え広がる速さには点ごとのむらを入れ、さらにシェーダーでノイズを足して、燃え際をぎざぎざにしている
- 熱の段階で見た目を分ける。0.3 くらいまでは茶色く焦げるだけ、0.5 で火が付き、燃え際（0.9 前後）は橙に光り、その手前で墨の濃い所だけが赤く光る。炭になった所は縮んで反り、1 で消える。炭になってからは早く崩し、黒い紙を長く残さない
- 破れるかどうかは 2 つで見る。綴じ目の伸び（綴じ目の近くをつまんだときに効く）と、つまんだ点がもとの位置から離れた長さ（60px）。綴じ目の伸びだけで見ると、下の端をつまんだときは紙が曲がるだけで綴じ目まで力が届かず、いくら引いても破れない。少し引くだけなら、どこをつまんでも綴じ目が白く伸びるだけで戻る
- ちぎったあとは、指の位置はそのままで、短冊を上の端から吊るす。足もとをつまんで引いても、字が上向きのまま垂れ、下の端から火に入る
- 炎は紙の奥に濃く描き、紙の手前には薄く重ねる。手前に濃く重ねると、燃えていく字が炎に埋もれて見えない
- 燃えつきた格子の点はその場で止める。動かすと、残った紙とのあいだに細長い三角ができる
- 半券は、ちぎれ線より上の紙を、同じぎざぎざの線で切り抜いて描く。本体と半券は同じ種のノイズの線で切るので、ちぎる前は継ぎ目が見えず、ちぎったあとはぴったり合う。前の半券ほど手前に、少しずつ上へずらして重ねる

## 作り方

- HTML-in-Canvas（Chrome 157〜）。短冊 1 枚を canvas の直下の `drawable` 1 つにし、`paint` の `changedElements` に入った短冊だけを `gl.texElementSubImage2D` で写し直す。ちぎると、次の短冊を複製して束に足し、燃えつきた短冊は要素ごと外す
- 欄は `writing-mode: vertical-rl` の textarea。字が収まらなくなったら、字を 1px ずつ小さくする（12px まで）
- 当たり判定は、束に貼られている短冊だけに置く（`updateElementGeometry`）。綴じ具の下とちぎれ線より上は `canvasClip` で外す。ちぎった短冊は `clearElementGeometry` で外し、つまむ所は格子の点から自分で探す
- 紙は 9 × 37 点の Verlet 積分の格子。隣、斜め、1 つ飛ばしの点を距離の拘束でつなぐ。上の行は綴じ目に弱いばねでつながり、その伸びが 30px を超えるか、すばやく引いて 6px を超えると、つかんだ列に近い方から順に切れる
- 描くのは素の WebGL2。紙（熱を頂点ごとに持たせたシェーダー）、炎（流れるノイズを上ほど細い形で切り抜く）、火の明かり（canvas の下の札掛けと地面を加算で照らす）、灰と繊維（三角）、火の粉と煙と紙の小さな炎（点）
- 札掛け、綴じ具、篝籠は HTML と SVG で置き、canvas の下（綴じ具だけは上）に重ねる
- キーボードでは、欄で Ctrl（Mac は ⌘）を押しながら Enter を押すと、ちぎって火の上まで運んでくべる
- 動きを減らす設定では、炎の揺れ、火の粉、灰、煙、反りを止め、炎は止まった絵にする。落ちる途中は見せずに落ちた所へ置き、燃えるのは速く済ませる。指についてくる動きと、燃え際が字の上を通るところは残す
- 使えないブラウザでは、短冊をふつうの HTML で置き、「くべる」のボタンで字を消して、焚き上げた数を数える
