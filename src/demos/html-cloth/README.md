# HTML の布をつまむ

## 何をしているか

見出し、文、入力欄、チェックボックス、ボタンでできた HTML のカードを、WebGL で布のように描いている。余白をつまんで引っぱると、つまんだ所が持ち上がってしわが寄り、離すと机の上に戻る。入力欄に書いた文字は、布が揺れている間もそのまま写る。

## 大事なところ

- 布に貼っているのは画像ではなく、いま動いている HTML そのもの。中身が変わるたび（文字を打つ、チェックを入れる、フォーカスが移る）にブラウザから `paint` が来るので、そのときだけテクスチャを写し直す
- 机に着いている所は摩擦で止め、元の場所へ強く戻す。浮いた所だけが自由に動く。こうしないと、角を引いたときに布全体がずるっと回ってしまう
- 遠くへ引っぱるほど、つまんだ点を高く持ち上げる。内側へ寄せたときに布が机の上で潰れず、上へ逃げてしわになる
- 当たり判定は、布が平らに置かれた位置に固定している。平らなときだけ欄やボタンが使え、布が浮いている間はどこを押してもつまむ側になる。見た目と当たり判定がずれる間は、HTML に触らせない

## 作り方

- HTML-in-Canvas（Chrome 157〜）。`<canvas content="drawable">` の子に `drawable` を付けた要素を置き、`paint` の中で `gl.texElementSubImage2D` を呼んで WebGL のテクスチャに写す
- 当たり判定は `canvas.updateElementGeometry` に、布を平らに置いたときの位置の行列を渡す。2D の `drawElementImage` と違い、WebGL では自分で渡す
- 布は 24 列の格子を Verlet 積分で動かす。隣どうし、斜め、1 つ飛ばしの点を距離の拘束でつなぐ。1 つ飛ばしのつなぎの強さが曲がりにくさで、「重い布」で替える
- 影は同じ格子を、高さに比例して右下へずらして机の上に描く
- three は使っていない。`texElementSubImage2D` は WebGL のテクスチャを直に渡す API で、three の Texture を通すと中の WebGL のテクスチャを取り出す手間がかかるため
- 使えないブラウザでは、canvas の子は描かれない。カードを canvas の外へ出して、ふつうの HTML として置く
