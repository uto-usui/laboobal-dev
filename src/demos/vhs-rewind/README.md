# テープの巻き戻し

## 何をしているか

ホームビデオのテープを、スクロールで再生する。画面は止めたままで、スクロールした量をテープの時間として進める。場面のあいだはカメラがゆっくり寄ったり振ったりし、場面の名前が 1 文字ずつ打たれる。場面が替わるところには、録画を止めて撮り直したときのような短い乱れが入る。左上のタイムコードは画面 1 枚ぶんのスクロールを 4 秒として 25fps で数える。

勢いよく下へ送ると「▶▶ FF」になり、明るいノイズの帯が 2 本、下へ流れる。勢いよく上へ戻すと「◀◀ REW」になり、絵が横縞ごとに左右へずれ、赤と青が分かれ、粗いノイズが乗る。ゆっくり動かすぶんには再生のまま。

開いたときに一度乱れて落ち着き、いちばん上にいるあいだは 7〜12 秒ごとに短く乱れる。左下の日付は開いた日。

## 大事なところ

- 乱れは SVG のフィルターだけで作る。`feTurbulence` の `baseFrequency` を x は 0、y は 0.0075 にすると、ノイズは縦の向きにしか変わらず、横縞になる。その R を `feComponentTransfer` の discrete で 16 段の表に置き換え、表の半分を 0.5 にする。G は 0.5 に固定してから `feDisplacementMap` に渡すので、0.5 の帯はずれず、残りの帯はそれぞれ違う量だけ左右にずれ、縦にはずれない。線形のノイズをそのままずれに使うと絵がなめらかに波打つだけで、テープの乱れに見えない。段に切って「ずれない帯」を混ぜると、帯の境目がはっきりした切れ目になる
- 表の段は入力の値の区切りで、画面を 16 本に分けるわけではない。fractalNoise の値は 0.5 のまわりに寄るので、真ん中の段にもずれる値を混ぜておかないと、ほとんどの帯が止まったままになる
- 帯の位置（`seed`）は 1/15 秒ごとに入れ替える。なめらかに流すより、ぱっと入れ替わるほうがテープらしい。フレームの数ではなく時間で数え、120Hz の画面でも同じ速さにする
- スクロールで画を縦に流さない。ふつうのページのように写真を縦に並べて流すと、ただ写真が並んでいるだけに見え、下へ進む理由が生まれなかった（作者に見てもらったときの指摘）。テープの映像は縦にすべらない。画面は止めて、スクロールを時間として使い、場面の中ではカメラを動かし、替わり目で切り替えると、スクロールが「再生する手」になる
- カメラの寄りと振りはスクロールの進み具合だけで決める。戻せば戻るので、少しずつ動かして画を確かめられる。画に使う時間はスクロールに少し遅れて追いつかせ、止めてもすっと止まらない重さを出す
- 早送りと巻き戻しで見た目を変える。どちらも同じ乱れにすると、「戻すと乱れる」という発見が薄まる。早送りはずれを弱くし、ノイズを画面いっぱいではなく、下へ流れる 2 本の帯にした（ビデオデッキで早送りしたときの帯）
- 早送りと巻き戻しの条件は、2 つそろったときだけ: 今の向きで続けて動かした量が画面 0.8 枚を超え、速さが 1 秒に画面 1.4 枚を超える。速さだけで決めると、ちょっと払っただけで乱れる。動かした量は、向きが変わったときと、0.15 秒止まったときに数え直す
- 速さは、実際のスクロールの位置の差と時刻の差で測る。`loop` の dt は 0.1 秒で頭打ちになるので、処理が詰まったフレームで速さを大きく見積もってしまう
- 乱れは速く立ち上げ、ゆっくり引く。手を止めてもすぐには消えず、テープが止まるまで少し残る
- 強さは「巻き戻し」「早送り」「場面の替わり目」「開いたとき」「いちばん上での乱れ」に分けて持ち、いちばん大きいものを使う。止め方がそれぞれ違うため（操作についてくるもの、1 回きり、ひとりでに起きるもの）
- フィルターは画面の大きさの箱（sticky の `.screen` の中の `.picture`）に掛ける。ページそのものは縦に長いが、場面は箱の中に重ねてあり、いま再生している 1 つだけを見せる。ノイズの縞は画面に対して止まり、フィルターの範囲も画面 1 枚で済む
- ずれた帯の端は透明になり、画面の黒が見える。写真を横に余分に描いて埋めることもできるが、黒い切れ目も巻き戻しの乱れらしいので残している
- 乱れていないあいだは `filter` を外し、ノイズも書かない。付けたままだと、スクロールのたびにフィルターを計算し直す

## 作り方

- SVG のフィルター（CSS の `filter: url(#...)`）、canvas 2D（ノイズ）、JS。ライブラリは読まない
- フィルターの範囲と単位は `userSpaceOnUse` にして、画面の幅と高さに合わせる。`color-interpolation-filters="sRGB"` にして、途中で色空間を変えない
- 赤と青の分け方: 変位後の絵を `feColorMatrix` で R、G、B の 3 枚に分け、R と B を `feOffset` で逆向きにずらし、`feComposite` の arithmetic（k2 = k3 = 1）で足し戻す
- ノイズは横 320px の canvas に 1 画素ずつ書き、画面いっぱいに引き伸ばして `mix-blend-mode: screen` で重ねる。高さは 1 画素が横 2 : 縦 1 になるように決めるので、粒が横に流れた筋に見える。`ImageData` は使い回す
- タッチの端末（`pointer: coarse`）では SVG のフィルターを使わず、帯を入れ替えるのと同じ間隔で画面ごと左右にずらす
- 1280×800 と 1440×900 の 2 倍で、乱れているあいだのフレームの時間を Chrome と Playwright の WebKit で測り、どちらも 60fps を保った（2026-11-12、手元の Mac。本物の Safari と iPhone では測っていない）
- 動きを減らす設定: 開いたときの乱れ、いちばん上での乱れ、場面の替わり目の乱れは出さない（替わり目はそのまま切り替わる）。カードのカーソルは点滅させない。早送りと巻き戻しの乱れは読む人の操作に応じて出るので残すが、帯の入れ替えとノイズの書き換えは点滅にあたるので止め、1 つの形のまま左右にずれるだけにする。カメラの動きと場面の名前の打ち込みはスクロールについてくるので残す
