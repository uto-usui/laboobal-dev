# 幕で隠して見せる

## 何をしているか

何もないところに、右から色の幕が伸びてきて写真の場所を覆う。少し間を置いて、幕が左へ縮んで消えると、その下から写真が現れる。クリック（タップ）するともう一度見られる。

## 大事なところ

写真そのものは動かしていない。動いているのは幕だけで、写真は幕が覆いきった瞬間に、見えないところで「出す」に切り替えている。幕が引くと、最初からそこにあったように写真が見える。見ている人には、幕の向こうから写真が引き出されたように感じる。

幕の動きは 3 つの形をつなげたもの。

1. 右端に幅 0 で隠れている
2. 全体を覆う（0.75 秒、`power1.out`）
3. 左端に幅 0 で消える（0.65 秒、`power3.out`）

1 から 2 で右から左へ伸び、2 から 3 で同じ向き（右から左）へ抜けていく。伸びてきた向きのまま通り過ぎるので、幕がその場で行って戻るのではなく、1 枚の帯が横切ったように見える。

覆いきってから引くまでに 0.5 秒の間がある。この間がないと、幕が横切っただけで写真が出たことに気づきにくい。いったん止まることで「何かが隠れている」と思わせてから見せる。

出るとき（`power3.out`）は入るとき（`power1.out`）より強いイーズアウトで、短い。最初に勢いよく引いて、最後はゆっくり止まる。幕が引く動きの方を目立たせている。

## 作り方

幕の形は CSS の `clip-path: inset(上 右 下 左)` で持ち、GSAP の timeline で `inset` の値を動かしている。右端に隠れた形は `inset(0% 0% 0% 100%)`（左を 100% 削る）、全体は `inset(0% 0% 0% 0%)`、左端に消えた形は `inset(0% 100% 0% 0%)`（右を 100% 削る）。どれも割合で書いているので、写真の大きさが変わっても計算し直さなくてよい。

写真の読み込みが終わってから（`decode()`）、0.5 秒あとに始める。クリックで timeline を作り直して、最初から流す。

## もとのデモから変えたこと

- 旧デモは CSS の `clip: rect()`（古い指定で、今は使わない）を px で書き、要素の大きさを JS で測って固定していた。`clip-path: inset()` を割合で書くようにした。要素の大きさを固定しなくてよくなった
- 旧デモは向きを 4 つ（左右上下）から選べる部品だった。このデモは右から左だけにした
- 幕の色を、暗い灰色からサイトの差し色（緑）にした。地をサイトの暗い色にしたので、暗い灰色の幕では見えないため
- 旧デモは読み込みから 2 秒待って始めていた。写真の読み込みが終わるのを待ってから始めるようにした
- 旧デモの「Re:start」のボタンは「replay」として残し、そのほかのどこをクリック（タップ）してももう一度見られるようにした
- 写真を `source.unsplash.com` のランダム画像（サービスが止まって出なくなっていた）から、Unsplash の写真をリポジトリに置いたものにした
