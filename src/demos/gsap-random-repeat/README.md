# 毎回ちがう行き先へ

## 何をしているか

四角い板を 1 枚、1 秒ごとに乱数で決めた大きさと向きへ回し続ける。

## 大事なところ

`repeatRefresh: true` で、くり返すたびに `'random(0.5, 2)'` などの乱数を引き直している。1 回の動きは「いまの姿から、新しく引いた姿へ」なので、くり返しのつなぎ目で跳ばない。行き先はでたらめでも、その間は ease でつながっているので、目で追える動きになる。毎フレーム乱数を入れ直すと、同じでたらめでも点滅にしか見えない（下げた random-transform。`docs/history/dropped/B1.md`）。

回転の行き先は -360〜360 度から選ぶので、1 回で回る量は、いまの角度と次の角度の差で決まる。ほとんど回らない回もあれば、700 度近く回る回もある。1 秒の長さは同じなので、回る量の差がそのまま速さの差になり、ゆっくり傾くだけの回と、勢いよく回る回が混ざる。

ease は `power1.out`。出だしが速く、次の姿勢へ吸い込まれるように止まり、止まりきった瞬間に次へ蹴り出される。止まる瞬間があるので、そこで姿勢が一瞬読める。

## 作り方

GSAP の `gsap.to` に、乱数の文字列（`'random(min, max)'`）と `repeat: -1`、`repeatRefresh: true` を渡すだけ。

板は表と裏の 2 枚の面を重ね、裏を少し暗い色にして `backface-visibility: hidden` にしている。いま表と裏のどちらがこちらを向いているかが分かり、回り方が読みやすい。perspective は入れ物の短いほうの辺の 80%（`80cqmin`）。

## もとのデモから変えたこと

- 旧デモの ease は `'Power1.inOut'` と書いてあったが、GSAP 3 はこの名前を知らず、既定の `power1.out` で動いていた（旧サイトで 1 フレームごとの変わり方を測ると、毎秒の始めがいちばん速く、終わりに向けて 0 まで落ちていた）。見えていた動きに合わせて `power1.out` にした
- 板の中の「1」の文字をやめ、裏を暗い色の面にした
- perspective を 400px の決め打ちから入れ物の大きさの割合にした
