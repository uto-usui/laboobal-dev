# 円を描く

## 何をしているか

灰色の正方形に、白く塗った横長の楕円を 1 つと、輪郭だけの円を 4 つ描く。processing.js の入門の記事の 1 本で、`ellipse()` に渡す 4 つの数が、`ellipseMode` によってどう読まれるかを見せる。

## 大事なところ

輪郭だけの円 4 つは、どれも `ellipse(a, b, c, d)` の 4 つの数で描いている。読み方は `ellipseMode` で変わる。

- `CENTER`（既定）: 中心の x と y、横と縦の直径
- `RADIUS`: 中心の x と y、横と縦の半径
- `CORNER`: 囲む箱の左上の x と y、横と縦の直径
- `CORNERS`: 囲む箱の左上の x と y、右下の x と y

右上の大小の円は、同じ `ellipse(200, 150, 50, 50)` を `CENTER` と `RADIUS` で描いたもの。同じ数でも、直径として読むか半径として読むかで大きさが倍ちがう。

## 作り方

canvas 2D の `ellipse()` は中心と半径で描くので、4 つの読み方は、描く前に中心と半径へ直してから渡している。座標は記事と同じ 320×320 のまま書き、表示の大きさに合わせて拡大している（`sketch.ts`）。

## もとのデモから変えたこと

記事の本文には processing.js のコードが載っている。違いは次のとおり。

- processing.js をやめて、canvas 2D で描いた。`ellipseMode` の切り替えはなくなり、どの円も中心と半径を書いている。コメントに、もとの数と読み方を残した
- 320×320 の固定の大きさをやめて、画面の大きさに合わせて正方形のまま拡大・縮小するようにした（もとの 2 倍まで）。線の太さも同じ割合で変わる
- 見出しは Google Fonts の Dancing Script を実行時に読んでいた。外から読まないよう、同梱の Molle にした
- Bootstrap 4 alpha の CSS と JS を読んでいたのをやめた。見出しの大きさと余白は自分で書いた
- SCSS の `rgba(#32355a, .55)` などを、普通の CSS の `rgb(50 53 90 / 55%)` にした
- 枠の点線は canvas ではなく、外の箱に付けた。canvas に付けると、描く大きさが線の分だけずれるため
