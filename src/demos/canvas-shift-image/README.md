# マウスで色をずらす

## 何をしているか

写真の赤、緑、青を別々の位置から読み、マウスが真ん中から離れるほど大きくずらす。真ん中ではふつうの写真で、端へ行くほど虹色ににじむ。

## 大事なところ

3 色のずらす量を 1 倍、2 倍、4 倍と変えている。同じ量なら写真ごと動くだけだが、量が違うので色が分かれる。2 倍ずつにすると、赤と緑の間より緑と青の間が広くなり、にじみに向きと流れが出る。

ずらす量はマウスと真ん中との差で決める。マウスを真ん中に戻せば、色がそろってもとの写真に戻る。デモの外にマウスが出たときも真ん中に戻すので、写真を見るときは何もしなければよい。

マウスには遅れて追いつかせる（旧デモは毎フレーム差の 7.5%）。マウスを止めても少しのあいだ色が流れ続け、にじみが後を引く。

## 作り方

three の `ShaderMaterial` で、画面いっぱいの板を 1 枚描く。フラグメントシェーダーで写真を 3 回読み、それぞれから 1 色ずつ取る。ずれた先が写真の外に出たら端の色を伸ばす（`ClampToEdgeWrapping`）。

写真は画面いっぱいに切り取って貼る（`object-fit: cover` と同じ）。タッチの端末ではマウスが来ないので、ゆっくり 8 の字を描くように自動で動かす。

## もとのデモから変えたこと

- 旧デモは写真をいったん別の描画先（`WebGLRenderTarget`）に描き、それを読み直してずらしていた。1 回で描けるので、写真を直に読むようにした
- ずらす量を px ではなく画面に対する割合で決めた。iframe の大きさが変わっても、端でのにじみ方が同じになる。端でのずれは旧デモより少し控えめ
- 写真（`images/girl/01.jpg`）は規約を確かめる前なので使わず、laboobal の別のデモにあった Unsplash の写真（photo-1548106755-5c6bf746ca84）に替えた
- 旧デモの作りは canvas-glitch-image と同じ（ykob/sketch-threejs の glitch の形）で、シェーダーだけが違っていた
