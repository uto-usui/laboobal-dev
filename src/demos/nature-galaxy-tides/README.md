# 銀河が尾を引く

## 何をしているか

青白い腕と暖かな芯を持つ大小二つの銀河が、互いの重力で光の尾を伸ばす。読み込み後は 2.2 秒だけ初めの姿を見せ、自動ですれ違いを始める。その途中でも、小銀河の円盤をつかんで別の場所へ運び、投げ直せる。つかんでいる間は芯と手のずれを保ったまま、ほぼ遅れずに手についてくる。離したときは手の速さの 35% に弱め、実時間の速さを最大 1.4 に抑えて送り出す。近くを速く通す、離してゆっくり通す、芯へ向けて落とすなど、位置と速度をその場で変えて比べる。すれ違いの終点は設けず、尾が伸びたあとも次を投げられる。投げ直しても、それまでの円盤の変形や尾は初期化しない。

何もない所のドラッグでは見る向きを変える。ほぼ正面から腕を読むだけでなく、円盤を斜めや真横から見られる。通常は銀河やカメラを操作している間も、重力と円盤内部の運動を続ける。そのドラッグを離すと少し回り続け、なめらかに止まる。自動の条件変更や再生の繰り返しはない。案内は左下の一行、設定は明るさだけで、最初は閉じている。

## 大事なところ

芯と外縁が同じ速さで動くと、円盤が移動するだけになる。円盤と球状の質量分布を内部まで動かし、外側が相手に引き出される差を作る。尾の線は足さない。芯の並進には弱い減衰と表示の外へ離れたときの引き戻しを加えるが、内部の相対速度は直接減衰させない。腕は最初の円盤に描いた模様で、重力から生まれる渦状腕の計算ではない。参考にした M51 と M74 の姿を出発点とし、その模様が重力でどう運ばれるかを見る。

光の標本は星一個ではなく、連続した円盤の頂点として扱う。近所の頂点を三角形で結び、面を伸ばす。広がった面は投影面積に反比例して暗くするが、明るさの下限は付けない。以前の面積比、細長さ、辺の絶対的な伸びによる抑制は、最も伸びた尾も消していたため外した。今は隣接する面と比べて局所的にちぎれた面だけを消す。星の集まりは別の発光として描き、その抑制や面積による減光を受けない。

## 作り方

WebGPU の compute で 2,048 個の質量点がすべての相手から受ける重力を合計する。各銀河は円盤 256 点が質量の 10%、球状の成分 768 点が 90% を持ち、球状の成分も動く。小銀河は主銀河に対して長さ 0.78 倍、質量 0.65 倍とし、内部の円運動の初速を √(0.65 / 0.78) 倍にする。重力の軟化長は 0.22、leapfrog の物理刻みは 0.0125。共有メモリに質量点を 64 点ずつ読み、workgroup 内で使い回す。

光の頂点は通常 32,768 個、タッチ端末や小さい画面では 16,384 個。質量点から引かれるが重力を返さない。円盤は角度 128 分割、半径 128 分割（小さい端末は 64 分割）、初期の最大半径は主銀河 3、小銀河 2.34。半径方向は中心ほど細かくし、角度の最初と最後も結ぶ。初速は軟化した質量分布の力を半径ごとに 24 方向で平均して求める。乱数の種と円盤の傾きは固定する。

腕と塵は初期座標を補間してフラグメントごとに描く。対数らせんの角度は `2.1 × log(1 + r / 0.38)`。薄い青白い円盤に二本の腕と細い塵を重ね、連続した低周波の濃淡を付ける。外縁は初期座標の半径 2.25〜3 でゼロへ落とす。芯には幅（σ）0.055 の黄みの白と 0.20 の暖色を重ね、円盤にも幅 0.34 のバルジを描く。

面の明るさは、頂点の前後左右から求めた投影面積の逆数を頂点間で補間する。係数は `4 × (1 − exp(−逆面積比 / 4))` で、低密度側には下限を設けず、投影で細くなる部分の過剰な発光だけを 4 未満に抑える。描画前の compute は各三角形の三辺の最大の伸び率を測る。伸び率は現在の 3D の辺長 / 初期の辺長。同じ辺を共有する三つの隣接面の伸びの中央値と比べ、3 倍を超えた面だけを消す。境界の欠けた隣接面は自分の値で補う。初期面積がゼロの中心の三角形は伸び率を 1 とする。面積や細長さを理由に面を消すことはない。

各銀河の 8 か所に置く若い星の集まりは、初期円盤上の位置を含む三角形の重心座標を持つ。同じ三頂点の動きを追い、面が消えてもその位置に独立した小さな発光を描く。面の伸びに合わせて広げず、明るい中心と少し広い青白い光を保つ。背景の 224 個の星とは別物。背景の星は画面に固定し、銀河の明るい部分では隠す。

銀河の光を `rgba16float` に加算してから露出を掛け、`mapped = 1 − exp(−light × exposure)`、`mapped / √(mapped + 0.025)` で表示へ変換する。以前の暗部を切り落とす toe と追加の減光を外し、伸びた尾の弱い光を残す。膜は面積による減光に任せる。ブルームや残像は使わない。集計画像の横幅は最大 1,920px。

## 操作と時間

各芯は円盤の最初の 32 頂点の平均位置を追う。毎フレーム GPU から二つの芯の位置と速度だけ、計 64 バイトを読み戻す。小銀河をつかめる範囲は、初期円盤の半径 2.34 を画面へ投影した長軸の半径と、60 CSS px の大きい方とする。真横から見てもつかめるよう、判定は芯を中心とした円にする。マウスが範囲に入るとカーソルを変え、小銀河の円盤・芯・星の集まりの光を 12% 増やす。つかんでいる間は 18% 増やし、切り替えには時定数 0.08 秒の補間を使う。尾が伸びた範囲は判定に含めない。

つかんだ位置と芯のずれを保存し、画面と平行な平面上の移動量から芯の目標位置を求める。押した瞬間に位置は変更しない。通常の進行率は実時間 1 秒に物理時間 1.5。各物理ステップの直前に GPU で芯の位置と速度を集計し、目標との差を `1 − exp(−実時間刻み / 0.0125)` の割合で縮める速度を求める。芯に次のステップで掛かる重力の分も差し引いて、質量点と光の頂点に同じ速度補正を加える。中心の輪は同じ位置から同じ力で動くため、その平均位置で重力を求める。一段の更新後の芯は現在位置と目標の間に収まり、ばねの振動や手の速度の外挿で行き過ぎない。時定数は 12.5ms、120Hz の入力での等速移動の位置の遅れは約 8.8ms（入力待ち・描画待ちを含まない）。尾を含む全体へ共通の補正を与え、内部の相対位置と相対速度は直接変えない。

手の速度は直近 100ms の位置から求め、持ち止めた場合も窓を進めてゼロへ戻す。離したときは手の速度の 35%、上限は実時間の速さ 1.4 とし、物理時間の速度へ換算する。GPU でその時点の芯の速度を読み、目標の投射速度との差だけを全標本へ一度加える。位置と尾の変形は保つ。操作が中断されたときは並進の投射速度をゼロにする。タッチで短く触れただけでドラッグが始まらなかった場合は変更しない。

自由運動中は両方の銀河の芯に、実時間の加速度 `−0.12 × 芯の速度` を加える。原点から半径 3.5 を出ると、外へ出た距離に比例する強さ 0.9 の引き戻しと、外向きの速度だけを弱める減衰を足す。外向きの減衰係数は半径 3.5〜5 の間で 0〜0.9 に増す。主銀河の質量や内部の回転の初期条件を変えず、遠くへ投げ続けることを抑えるための表示上の補助である。保持中の小銀河には適用せず、手の位置を優先する。内部の速度に一律の摩擦を掛けず、両方の銀河の並進にだけ共通の速度補正を加える。操作中の薄い細線は、弱めた投射速度・主銀河を固定した軟化重力・同じ引き戻しと減衰から求める目安で、実際は全質量点の相互重力で動く。

カメラは直交投影。横のドラッグで方位、縦で傾きを変え、真横まで回せる。離したときは直近 100ms の角速度を引き継ぎ、時定数 0.25 秒の指数減衰で止める。傾きの端ではその方向の角速度を止める。新しくつかんだときと操作が中断されたときも慣性を止める。両方の芯が画面に残るよう、中心と表示範囲は芯の位置へ時定数 0.4 秒で追従する。操作中は中心と表示範囲を保ち、離した瞬間に計算し直して跳ばさない。`touch-action: pan-y` と共通の `touchGate` を使い、縦に動かし始めたときは記事のスクロールを優先する。横からドラッグするか、一度タップしてから縦にも引っぱれる。

表示時間あたり 120 歩を目標とし、一フレームの上限は 3 歩。描画は前後の物理状態を補間する。GPU の読み戻し中は次のフレームを積まず、重い端末では進行が遅くなる。画面外と非表示タブではループを止める。

動きを減らす設定では、初期状態または設定を切り替えたときの一枚で物理計算を止める。尾の終点まで裏で自動計算することはない。この設定では、銀河のドラッグの移動量だけ全標本の位置へ反映し、速度は変更しない。カメラの回転にも慣性を付けず、離した後は銀河の運動とカメラの回転を止める。構図の追従と明るさの短い補間は残す。WebGPU がない場合は案内、実行時エラーは専用の箱を出す。

## 確かめ方

`node src/demos/nature-galaxy-tides/check-motion.ts` で、実装と共通の定数・投射速度・引き戻し関数を使い、4 か所から弱い・普通・強い払いを 6 方向へ放す計 72 通りについて、20 秒の芯の位置を出す。各時刻で芯が原点から半径 5 以内、間隔が 7.4 以内にあることを検査する。間隔 7.4 は円盤用の余白 7 を加え、短辺の基本表示幅 12 に対するカメラの引きを最悪の向きでも 20% 以内にする目安。自由運動の重力は各銀河を一つの軟化質量にまとめた近似であり、GPU の全質量点の変形を再現する検査ではない。保持については任意の重力キックと以前の速度を与え、目標の段差・停止・反転で行き過ぎず、等速移動の遅れが 20ms 未満になることを調べる。

静的チェックに加え、オーケストレーターが実ブラウザで確認する。ほぼ正面の初期状態と最接近後を比べ、尾の最も明るい筋が始まりの腕の 3〜4 割程度に見えるか、灰色の膜が戻っていないか、星の集まりが尾の先まで残るかを見る。これは目標であり、今回の静的チェックだけで見た目を確認済みとはしない。

自動の初回の途中で円盤をつかみ、近くを速く通す、遠くから遅く投げる、主銀河へ落とす操作を繰り返す。通り道が変わること、既存の尾がリセットされないこと、すれ違いのあともつかみ直せることを確かめる。動いている円盤の芯から 60px 以上離れた場所もつかめること、ホバー中と保持中に少し明るくなること、操作中も世界が止まらないこと、離した瞬間に位置や構図が跳ばず、弱めた速度で近くにとどまること、何もない所のドラッグ後に回転が減衰すること、真横の視線でも芯と星の集まりが残ること、リサイズとスマホの縦スクロール、動きを減らす設定も確認する。

単独の銀河を調べる場合は `initialState` の第 3 引数を `true` にし、二つを十分離して並進速度をゼロにする。無次元の長さと時間を使う相互重力の模型で、観測写真の軌道や年代、ガス、星の誕生は再現しない。衝突判定は持たない。並進の減衰と引き戻しは加えるが、合体は保証せず、近くですれ違うか捕獲されるかは相互重力にも依存する。
