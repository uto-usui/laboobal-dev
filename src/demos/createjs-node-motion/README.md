# 引き合いながら漂う点と線

## 何をしているか

30 個の小さな点が、それぞれでたらめな向きと速さで漂う。近い点どうしは線で結ばれ、近いほど線が濃い。結ばれた点は引き寄せ合うので、寄り集まってかたまりになったり、すれ違ってまた離れたりする。端から出た点は、反対の端から戻ってくる。

## 大事なところ

すべての 2 点の組について距離を見て、50 より近ければ 2 つのことをする。

- 線を引く。濃さは `(max - distance) / max` で、離れるほど薄く、50 でちょうど消える
- 引き寄せる。互いの速さに、相手の方向へ `距離 × ratio` を足し合う。遠いほど強く引くので、ばねのような力になる

引く力は 50 を越えると急に 0 になる。近づくと引かれ、勢いのまま通り過ぎて 50 の外へ出ると、もう引かれない。これが、くっつききらずにかたまりがほどけていく理由。

端の処理は跳ね返りではなく、左右と上下がつながっている（`roll`）。点の数が減らず、画面の中の混み具合が変わらない。

## 作り方

点ごとに位置と速さを持ち、1/60 秒ごとに「動かす」「近い組を引き寄せる」をくり返す。線と点は毎フレーム描き直している。点の色はでたらめな色相を 1 つ選び、線はその色に濃さを掛けて引く。

もとの見た目の大きさ（300×300）の座標のまま描き、入れ物に収まる大きさまで canvas を広げる（もとの 2 倍まで）。

## もとのデモから変えたこと

記事の本文には、CreateJS の `Stage`、`Shape`、`Ticker` を使ったコードが載っている。違いは次のとおり。

- CreateJS をやめ、canvas 2D で描き、共有の `loop` で回している
- もとは 600×600 の canvas を CSS で 300×300 に縮めて見せていた。見えていた 300×300 を座標にし、点の半径（2 → 1）、線の太さ（1 → 0.5）、線を引く距離（100 → 50）、速さを半分にした。引き寄せる強さは距離に掛けるので変わらない
- もとは `Ticker.timingMode` を決めておらず、CreateJS の既定の 1 秒に 20 回で動いていた。なめらかにするため 1 秒に 60 回に刻み、1 回あたりの速さを 3 分の 1、引き寄せる強さを 9 分の 1 にした。1 秒あたりの動きは変わらない
- 色は `Math.random() * 0xFFFFFF * 1000` を `Graphics.getRGB` に渡していた。1000 倍で 32 ビットを越えて、実際には桁があふれたでたらめな色になり、白に近い見えない色になることもあった。でたらめな色相に、彩度 70%、明るさ 45% を合わせた色にした
- 見出しの「create.js」を、fiddle の題名からとった「node」にした。CreateJS を使わなくなったため
- canvas の点線の枠は `border` から `outline` にした。`border` だと canvas の大きさに入り、座標がずれる
- 動きを減らす設定では、置いたばかりの点と線を止めて見せる
- SCSS を普通の CSS にした
