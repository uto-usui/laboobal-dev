# ホバーの動きを最後まで見せる

## 何をしているか

4 本の帯が並んでいる。マウスを乗せると、帯が左から赤く塗られる。乗せてすぐ外しても、塗りは最後まで伸びきってから戻る。hover-control-css（CSS だけの版）と並べて比べるためのもの。

## 大事なところ

CSS の `transition` は、マウスが出た瞬間に、途中からでも戻り始める（hover-control-css）。こちらは、動き始めたら最後まで動かしきる。帯の上をさっとなでても、なでた帯がすべて赤く塗りきられ、そのあと順に戻っていく。マウスの軌跡が、塗りの波として残る。

やっていることは、2 つの印を持つことだけ。

- マウスが乗っているか（isOver）
- 今動いている最中か（playing）

マウスが出入りしたとき、動いている最中なら何もしない。印を書き換えるだけ。動きが終わったときに、今マウスが乗っているかを見て、次の動きを決める。

- 入る動きが終わった。マウスが外れていたら、出る動きを始める
- 出る動きが終わった。マウスが乗っていたら、入る動きを始める

イベントのたびに動かすのではなく、動きが終わるたびに「今の状態」に合わせる。途中で何度出入りしても、最後に見えるのは今の状態に合った姿になる。逆に、動いている間の出入りはまとめて捨てられるので、ちらつかない。

入るときは 0.6 秒の `expo.out`（一気に伸びてゆっくり止まる）、出るときは 0.5 秒の `expo.inOut`（ためてから戻る）。

## 作り方

`src/shared/a/hover-control.ts` に、上の 2 つの印と切り替えを書いている。動きそのものは呼ぶ側が渡す。渡すのは「動き終わったら解決する Promise を返す関数」で、GSAP の tween は then を持っているので `gsap.to()` をそのまま返せば `await` で終わりを待てる。hover-rect でも同じものを使っている。

マウスの出入りは `pointerenter` と `pointerleave` で取る。`mouseover` と `mouseout` は、帯の中の子要素（塗りや文字）に出入りしたときにも起きるので、帯の中を動かしただけで「出た」と判断されてしまう。

## もとのデモから変えたこと

- 旧デモは `new Promise` で tween を包み、`onComplete` で解決していた。GSAP の tween は then を持つので、包まずにそのまま返すようにした
- `mouseover` と `mouseout` を `pointerenter` と `pointerleave` にした（上に書いたとおり）
- 帯の高さを、入れ物の高さの 4 分の 1 にした
