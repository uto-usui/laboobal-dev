# sin で描く波の線

## 何をしているか

ペン先を右へ一定の速さで進めながら、縦の位置を sin で振る。通ったところに線を残すので、灰色の波の線が左から少しずつ描かれていく。右の端まで描いたら消して、左から描き直す。

## 大事なところ

`Math.sin(angle)` は -1〜1 を行き来する。これに振れ幅 `range`（80）を掛けて真ん中の高さに足すと、縦の位置が真ん中から上下に 80 ずつ揺れる。

横には `speedX`（1 フレームに 0.2）、角度には `speedY`（1 フレームに 0.02 ラジアン）ずつ進める。横に 10 進むあいだに角度が 1 ラジアン進むので、波 1 つ分（2π ラジアン）は横に約 63。250 の幅に波が 4 つ入る。横の速さを上げるか角度の速さを下げると、波は横に間延びする。

## 作り方

CreateJS の `Shape` に `lineTo` を足していく代わりに、毎フレーム、左の端から今のペン先までの線を引き直している。角度はペン先の x に比例するので（`angle = x / speedX * speedY`）、点を覚えておかなくても x から求められる。

もとの canvas（250×250）の座標のまま描き、入れ物に収まる大きさまで canvas を広げる（もとの 2 倍まで）。

## もとのデモから変えたこと

記事の本文には、CreateJS の `Stage`、`Shape`、`Ticker` を使ったコードが載っている。違いは次のとおり。

- CreateJS をやめ、canvas 2D で描き、共有の `loop` で回している。速さは 60fps のときの 1 フレームあたりの量のまま、前のフレームからの秒数で進める
- もとは右の端を越えても線を描き続けたので、20 秒ほどで線が canvas の外へ出て、そのあとは何も動かなくなった。端まで来たら左から描き直す
- 記事では真ん中の高さを `canvas.height / 2`、fiddle では `canvas.width / 2` にしている。正方形なのでどちらも 125
- 見出しの「create.js」を、fiddle の題名の「sine wave」にした。CreateJS を使わなくなったため
- canvas の点線の枠は `border` から `outline` にした。`border` だと canvas の大きさに入り、座標がずれる
- canvas を 250×250 の固定から、入れ物に合わせた大きさにした
- 動きを減らす設定では、端まで描き終えた波を止めて見せる
- SCSS を普通の CSS にした
