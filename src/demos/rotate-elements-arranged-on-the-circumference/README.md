# 円周上に並べた要素を回転させる

## 何をしているか

小さな色の板が 12 枚、円の上に等しい間をあけて並び、輪ごと回る。輪は丸ごと奥と手前を行き来し、板はそれぞれ回転しながら大きさを変える。色は円の上の位置で決まり、輪が回ると色も回る。後ろに「Smooth Animation」の見出しがある。

## 大事なところ

輪全体の角度を 1 つ持ち、i 番目の板には `角度 + 360 / 12 × i` を使う。この角度の sin と cos に半径を掛けると、板が円周を 12 等分した位置に並ぶ。角度を進めると、並んだまま回る。

ほかの動きも、同じ角度から作る。

- 奥行き: `sin(角度) × 半径 × 2`。全部の板が同じ量だけ動くので、輪が丸ごと前後する
- 大きさと回転: 板ごとに角度を 75 度ずつずらした sin と cos を、`map()` で 1〜1.5 倍、1〜360 度に写す。ずれているので、板ごとに違う向きを向く
- 色: 円の上の位置の角度を、そのまま色相にする

## 作り方

板ごとに、GSAP の `gsap.set` で位置、大きさ、`rotationY`、`rotationZ`、背景の色を入れている。

動きを減らす設定のときは回さず、そのときの姿で止める。

## もとのデモから変えたこと

記事の本文には TweenMax と jQuery のコードが載っている。違いは次のとおり。

- TweenMax 1.20 と jQuery を、GSAP 3 にした。jQuery の `each` は配列の `forEach`
- 大きさと回転のずらし方を、板ごとに「半径の px の値」ずつ角度を足していたのを、75 度ずつにした。もとは画面の高さで見え方が変わっていた。75 度は、高さ 300px の iframe で開いたときの値
- 自前の `map` を、src/shared/math.ts の `map` にした。範囲の外を端に丸めるのは同じ
- 色を `hsla(…, 1)` から `hsl(…)` にした
- 角度の進み方を、1 フレームに 2 度から、1 秒に 120 度にした
- 中心と半径を、ステージの大きさで、大きさが変わるたびに決め直すようにした
- 大きな画面で板が `perspective` を越えて消えないよう、`perspective` を広げるようにした
- 画面の外では止まる。動きを減らす設定では止まる
