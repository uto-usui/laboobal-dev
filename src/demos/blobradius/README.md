# 形が変わり続ける塊

## 何をしているか

緑のグラデーションの四角を 2 つ並べ、`border-radius` を時間で変えて、ぐにゃぐにゃと形の変わる塊に見せる。右の塊は回りながら右下へ流れて戻ってくる。

## 大事なところ

四角が生き物のような塊に見えるのは、`border-radius` の 8 つの値を使っているから。`33% 67% 70% 30% / 30% 30% 70% 70%` のように `/` で区切ると、四隅の角の丸みを、横の半径と縦の半径で別々に決められる。隣り合う角の値を足して 100% になるようにしておくと、辺のまっすぐなところが残らず、全体がひとつながりの曲線になる。

形の変化は 10 個の形を順にたどるだけ。1 周を 30 秒と長くし、`ease-in-out` と `alternate`（行って戻る）にしているので、どこが区切りなのか分からず、ずっとゆっくり形が変わっているように見える。

2 つの塊は同じ keyframes を使い、右だけ逆から再生している（`alternate-reverse`）。同じ形の並びなのに、2 つが同じ形になる瞬間がほとんどない。

右の塊は、形の変化（30 秒）とは別の周期（20 秒）で、回りながら動く。周期がそろっていないので、形と位置の組み合わせが毎回違って見える。回っても塊なので向きは分からず、グラデーションの向きが変わることだけが分かる。

## 作り方

CSS の `@keyframes` だけで動かしていて、script はない。グラデーションの色はサイトの緑（`--color-accent`）から、同じ色の透明度 10% へ。透明に近い色は相対色の書き方（`rgb(from … r g b / 10%)`）で作っている。

塊の大きさは、コンテナの幅の 30% にし、高さの 60% を超えないようにした。iframe（幅 800px、高さ 500px くらい）でも上下が切れない。右の塊は動いて右端を越えるので、入れ物を `overflow: clip` にしている。

`prefers-reduced-motion` が有効なときは止める。

## もとのデモから変えたこと

- 旧デモは左の塊に `blobTrans` という名前の動きを付けていたが、その名前の keyframes はなく（あったのは `blobTrans01`）、左の塊は形が変わるだけだった。旧デモで見えていた動きはこれなので、作り直しでも左は形だけにした。使われていなかった `blobTrans01` は、`translate(50%, 20%) rotateY(10deg) scale(1.2)` へ動くものだった
- 大きさを `30vw` から、コンテナの幅と高さで決めるようにした
- 色の透明度を SCSS の `rgba($color-primary, 0.1)` から CSS の相対色にした
