# 動画にエフェクトをかける

## 何をしているか

光の玉が 3 つ流れる短い動画を、音を消して繰り返し流している。動画には CSS のフィルターで、明るさとコントラストを 2 倍にし、強くぼかすエフェクトをかけている。さらに上から黒を `color-burn` で重ねているので、ふだんは明るさが振り切れたところだけが、べた塗りの色で黒の中に浮かぶ。

- マウスを乗せると、黒の焼き込みが 0.5 秒で消え、動画が 1.05 倍に寄る。ぼけて光のにじんだ動画が見える
- 左上の「sound」を押すと、音が出て、フィルターが外れる。もう一度押すと、音が消えてフィルターが戻る

## 大事なところ

エフェクトは CSS の 2 つでできている。

- `filter: brightness(200%) contrast(200%) blur(20px)`: 明るい色はさらに明るく振り切れ、暗い色は沈み、全体がにじむ
- `::after` の黒を `mix-blend-mode: color-burn` で重ねる: color-burn は、下の色を上の色で焼き込む。上が黒だと、下の色のうち値が最大（255）のところだけがそのまま残り、ほかは黒になる。赤、緑、青のチャンネルごとに決まるので、振り切れた色だけがポスターのような塗りで残る

明るさとコントラストを上げてから焼き込むので、振り切れるところが増え、浮かぶ形が大きくなる。フィルターを外すと振り切れるところが減り、玉の芯だけが、ざらついた点のように残る。

## 作り方

動画は `assets/make-clip.sh` で、ffmpeg だけで作った。式で描いた光の玉と音なので、ほかの人の映像や音は使っていない。6 秒でつなぎ目なくループする。WebM（VP9 と Opus、約 70KB）と、WebM を流せないブラウザ向けの MP4（H.264 と AAC、約 140KB）を `<source>` で並べている。

ぼかすと縁が透けて黒く沈むので、動画を枠より 40px ずつ大きくして、縁を枠の外に逃がしている。

「sound」は `aria-pressed` で、押されているかを伝える。

動きを減らす設定のときは、動画を流さず最初のコマで止める。「sound」を押したときだけ、読む人が始めた再生として流す。画面の外では止める。

## もとのデモから変えたこと

記事のもとのデモは、jquery.mb.YTPlayer で YouTube の動画を読み、プラグインの機能でフィルターをかけていた。違いは次のとおり。

- YouTube を読むのをやめ、自分で作った短い動画に替えた。もとの動画は、ほかの人の音楽の動画だった
- jQuery と jquery.mb.YTPlayer をやめた。フィルターは、プラグインが iframe に入れていたのと同じ値を、CSS で `video` に書いた。`YTPToggleVolume` と `YTPToggleFilters` は、`muted` と `data-clear` の切り替えにした
- もとは YouTube の iframe に `transition: 1s` を付けていた。ここでは `video` の `filter` に 1 秒の transition を付けた
- 枠を 90vw × 90vh から、デモの画面の 90% にして、真ん中に置いた
- SCSS の入れ子と `//` のコメントを、素の CSS にした。`transition: 1s` を `transition: transform 1s` にした
- 動きを減らす設定と、画面の外では止まる
