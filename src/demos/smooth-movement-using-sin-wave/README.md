# サイン波を使ったスムーズな動き

## 何をしているか

箱が左右に行き来する。端に近づくとゆっくりになり、真ん中ではいちばん速い。位置に合わせて、色も赤から黄、緑、水色へと変わり、戻ってくる。

## 大事なところ

角度を一定の速さで進め、その sin を位置に使う。sin は -1〜1 を行き来する波で、端では変わり方がゆるく、0 のあたりで急になる。角度が一定に進んでも、箱は端でゆっくり、真ん中で速く動き、イージングを付けたようななめらかな往復になる。

同じ sin の値を `map()` で 0〜360 に写し、半分にして色相にしている。色は 0〜180 度（赤から水色）を行き来する。

## 作り方

位置と色は GSAP の `gsap.set` で入れている。角度は `loop()` の dt を使って 1 秒に 120 度進める。振れ幅は画面の高さの 1/4。

動きを減らす設定のときは動かさず、そのときの位置と色で止める。

## もとのデモから変えたこと

記事の本文には TweenMax と jQuery のコードが載っている。違いは次のとおり。

- TweenMax 1.20 と jQuery を、GSAP 3 にした
- 記事の本文のコードは位置だけを動かしている。デモ（fiddle の最後の版）は色も変えているので、色の変化も入れた
- 自前の `map` を、src/shared/math.ts の `map` にした
- 色を `hsla(…, 1)` から `hsl(…)` にした
- 角度の進み方を、1 フレームに 2 度から、1 秒に 120 度にした
- 中心と半径を、ステージの大きさで、大きさが変わるたびに決め直すようにした
- 使っていなかった `perspective` と `transform-style` を外した
- 画面の外では止まる。動きを減らす設定では止まる
