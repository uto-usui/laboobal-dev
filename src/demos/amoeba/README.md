# うごめくアメーバ

## 何をしているか

黒い画面の真ん中に、縁がうねり続ける形を描く。形の中はノイズで緑に光り、縁は細く赤く、まわりには青い光がにじむ。全体に細かいざらつきが乗っている。

## 大事なところ

形は「中心からの距離の逆数」で作っている。`半径 / 距離` は中心に近いほど大きく、半径のところでちょうど 1 になる。これを `floor` すると、1 以上のところ（半径の内側）だけが 1 になり、外は 0 になって、くっきりした円ができる。

この半径を、場所と時間で変わる 3D のノイズで揺らしている。ノイズの入力の 2 つを画面の座標、1 つを時間にすると、時間が進むにつれて場所ごとの半径がなめらかに変わり、縁がうねる。座標に 5 を掛けているので、1 周のあいだに凹凸がいくつもでき、ときどき本体からちぎれた小さな粒もできる。時間には 0.1 を掛けていて、うねりはかなりゆっくり。

同じ作り方の形を 3 つ重ねている。

- 半径 0.18 を `floor` したものが本体（緑）
- 半径 0.2 を `floor` したものから本体を引くと、少しだけ大きい形との差が細い縁（赤）になる
- 半径 0.195 を `floor` せずに 2 乗し、0.2 の形を引くと、形の外にだけ、遠くへ行くほど暗くなる光（青）が残る

中の緑と縁の赤には、別のノイズを掛けている。ノイズは負にもなるので、暗く抜けるところができ、中で模様が流れて見える。最後に、時間で変わらない乱数を全体に掛けてざらつかせている。光っているところが砂のように見えるのはこのため。

## 作り方

three.js の `ShaderMaterial` で、画面いっぱいの板に fragment shader を描いている。板は 2×2 で、頂点はカメラを通さずそのまま画面の -1〜1 に置く。

ノイズは共有の `src/shared/glsl/simplex-noise.glsl` の `snoise(vec3)` を、シェーダーの文字列の先頭に足して使う。横長でも縦長でも円が楕円にならないよう、y を縦横比で割って、中心も同じだけずらしている。

大きさが変わったら（`onResize`）描画の大きさと縦横比を合わせる。描画の解像度は devicePixelRatio に合わせ、2 で止める。ざらつきは画素ごとの乱数なので、解像度が変わると粒の細かさも変わる。

`prefers-reduced-motion` が有効なときは、最初の 1 枚だけを描いて止める。

## もとのデモから変えたこと

- 旧デモは three r121 で、板の大きさを画面の大きさから計算し、カメラの範囲をそれに合わせていた。どちらにしても板がちょうど画面を覆うだけなので、2×2 の板をそのまま画面に置く形にした。見え方は同じ
- ノイズは glslify の `glsl-noise` から、共有のシェーダーの `snoise` にした
- 画面の大きさは window の resize ではなく、canvas の ResizeObserver で見るようにした。iframe の高さが変わったときも描き直す
- 旧デモは devicePixelRatio をそのまま使っていた。2 で止めた
