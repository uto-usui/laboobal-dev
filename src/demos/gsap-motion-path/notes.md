# 道に沿って進む

## 何をしているか

S 字の道（SVG の path）の上を、小さな粒が 10 秒かけて端から端へ進み、引き返す。通ったところは色で塗られていく。

## 大事なところ

GSAP の MotionPathPlugin で、path の上の位置へ動かしている。`autoRotate: true` で、粒はいつも進む向きを向く。カーブにさしかかると粒が首を振るので、ただ位置が動くより「道を進んでいる」感じが出る。

ease は `power2.inOut` で 10 秒、`yoyo` で引き返す。端に近づくとゆっくりになって止まり、道の真ん中を速く抜ける。通ったところを同じ ease で塗っているので、塗りの伸び方を見ると、端で伸びが遅く、真ん中で速いのが分かる。

## 作り方

動く粒（`rect`）を、道と同じ `svg` の中に置いている。座標の決まりが道と同じなので、MotionPathPlugin の `align` が要らず、svg が縮んでも粒と道が一緒に縮んでずれない。粒は原点を中心に描き、`transformOrigin: '50% 50%'` で真ん中を軸に回るようにしている。

塗りは、同じ形の path をもう 1 本重ね、`pathLength="100"` と `stroke-dasharray="100"` にして、`stroke-dashoffset` を 100 から 0 へ動かしている。粒の動きと同じ timeline の同じ時刻に置き、同じ ease にしているので、ぴったりそろう。

## もとのデモから変えたこと

- 旧デモは丸い粒だったので、`autoRotate` で向きが変わっていることが見えなかった。前後に長い形にした
- 旧デモは HTML の `div` を `align: path` で svg の道に合わせていた。`align` は動き出すときに位置を計算するので、大きさが変わるとずれる。粒を svg の中に入れた
- 通ったところを塗る線を足した
- 道の上下に余白を足した（viewBox を上下に 20 ずつ広げた）。粒が端で切れないように
