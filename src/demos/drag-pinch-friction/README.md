# 引っぱると形と色が変わる

## 何をしているか

つまんで離すと戻る玉（drag-pinch-simple）に、引っぱった量に応じた変形と色を足したもの。引っぱるほど玉がのびて傾き、緑から赤に変わる。

## 大事なところ

指の移動量に 0.5 を掛けてから追いかけさせている。旧コードではこの係数を「摩擦」と呼んでいたが、働きは摩擦ではなく倍率。指を 200px 動かしても玉は 100px しか動かない。この「ついてこなさ」が、重いものや粘りのあるものを引っぱっている手ごたえになる。

近づく割合は 1 フレームで差の 25%（simple の 2.5 倍）。動く量を半分にした代わりに、反応は速くしている。遅れが少ないので、指に吸い付いているのに重い、という感じになる。

変形と色は、どれも「真ん中からどれだけ離れたか」だけから決めている。

- 横にのびる量は横の移動量、縦にのびる量は縦の移動量に比べる。引っぱった向きにのびるように見える
- 回る角度は横と縦の移動量の積に比べる。真横や真上に引いたときは回らず、斜めに引いたときだけ回る。右上と右下では積の符号が逆になるので、回る向きも逆になる
- 色は、真ん中からの距離が 0〜250px の範囲で、緑から赤へ混ぜる

離すと位置が 0 に戻るので、のびも回転も色も一緒に元へ戻る。戻すための処理はどこにもなく、すべて位置から計算し直しているだけ。

## 作り方

drag-pinch-simple と同じく、requestAnimationFrame と `damp`、`src/shared/a/pull.ts` で書いている。Draggable を使わない理由も同じ。

色は JS で計算せず、CSS の `color-mix()` に任せている。JS は 0〜1 の値を `--t` に入れるだけ。

## もとのデモから変えたこと

- chroma-js の `scale` で色を混ぜていたのを、CSS の `color-mix(in oklab, …)` にした。旧デモは sRGB で混ぜていたので、真ん中あたりで灰色がかった濁った色になっていた。oklab で混ぜると、濁らずに緑から赤へ移る
- 1 フレームあたりの割合を、1 秒あたりの近づき方に直した（drag-pinch-simple の notes を参照）
- 背景をサイトの暗い色にした
