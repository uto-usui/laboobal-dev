# マウスで傾ける

## 何をしているか

写真の上でマウスを動かすと、写真が板のように傾く。マウスのある側が奥へ沈み、反対側が手前に来る。マウスが外に出ると、ゆっくり正面に戻る。

## 大事なところ

傾ける角度は、マウスが真ん中からどれだけ離れているかで決める。真ん中を 0 にしたマウスの位置を、入れ物の短い方の辺の半分で割って、おおよそ -1〜1 の数（dx、dy）にする。

- 縦のマウスの位置（dy）で、横の軸のまわり（rotateX）に回す
- 横のマウスの位置（dx）で、縦の軸のまわり（rotateY）に回す

軸が入れ替わるのがポイント。マウスを右へ動かすと、縦の軸のまわりに回って右側が奥へ沈む。下へ動かすと、横の軸のまわりに回って下側が沈む。指で板の端を押したような向きになる。

角度は、位置にそのまま比例させていない。真ん中からの距離 × 15 を「掛け率」にして、位置にもう一度掛けている。だから、真ん中の近くではほとんど傾かず、端へ行くほど急に大きく傾く（距離の 2 乗で効く）。真ん中でマウスが少し揺れても写真が落ち着いていて、端に寄せたときだけはっきり反応する。

動きはマウスにぴったり合わせず、マウスが動くたびに「1 秒かけて新しい角度へ向かう」動きを作り直している。速く動かしても角度がなめらかに追いつき、止めるとふわっと収まる。出ていったときも同じように、1 秒かけて 0 度へ戻る。

奥行きは、写真そのものに `perspective(1200px)` を付けている。親に `perspective` を付けると、写真が画面のどこにあるかで見え方が変わるが、写真に付けると、写真の真ん中から見た傾きになる。1200px は大きめの値で、傾けても手前に飛び出す感じは控えめ。

## 作り方

GSAP の `quickTo` で、rotationX、rotationY、x、y の 4 つを動かしている。`quickTo` は「同じ値を何度も新しい目標へ動かし直す」ための関数で、マウスが動くたびに呼ぶとその都度、今の値から新しい目標へ 1 秒（`power2.out`）で向かい直す。`transformPerspective` で写真に奥行きを付けている。

マウスの位置は Pointer Events で取る。写真は `pointer-events: none` にして、入れ物（画面全体）の上の位置で計算している。

## もとのデモから変えたこと

- 旧デモはマウスが動くたびに `gsap.to` で新しい tween を作っていた。今の GSAP は前の tween を自動で止めないので、tween が積み重なる。`quickTo` にした
- 旧デモは、縦の位置を横幅で、横の位置を高さで割っていた（取り違え）。両方とも短い方の辺の半分で割るようにした。横長の画面では、横の傾きは旧デモとほぼ同じで、縦の傾きが少し強くなった
- マウスの位置を非標準の `layerX` から、`clientX` から入れ物の位置を引いて取るようにした
- 写真を `source.unsplash.com` のランダム画像（サービスが止まって出なくなっていた）から、Unsplash の写真をリポジトリに置いたものにした
- 写真を 16:9 で、入れ物の 80% に収まる大きさにした
