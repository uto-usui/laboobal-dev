# ランダムウォーク

## 何をしているか

画面の真ん中から 3 つの点が歩き出す。毎フレーム、上下左右のどれかへ 1 歩ずつ進み、通った所に薄い灰色の跡を残す。時間がたつと、跡がもやのように少しずつ広がっていく。processing.js の入門の記事の 1 本。

## 大事なところ

1 歩の決め方は、0 から 3 の乱数を 1 つ引いて、右・左・下・上のどれかにするだけ。行き先に意図はないのに、跡は真ん中のまわりに固まり、ときどき遠くへ伸びる。

- 同じ所を何度も通るので、跡は真ん中ほど濃い。点は不透明度 20% なので、踏んだ回数がそのまま濃さになる
- 遠くへ行くほど時間がかかる。何歩進んでも、真ん中からの距離は歩数の平方根くらいにしか伸びない
- 画面の端では、外へ出る歩みを端で止める（`constrain`）

歩く人はクラス `Walker` で書いてあり、3 人分を作って同じように動かしている。

## 作り方

共有の `autoplayLoop` で 1 秒に 60 歩ずつ進め、歩いた所にだけ点を描き足す。画面の大きさが変わって描き直すときのために、どの画素を何回踏んだかを数えておき、`1 − 0.8^回数` の濃さで点を 1 つずつ描く。歩いた順の記録は持たないので、長く開いていても覚える量は増えない。座標は記事と同じ 320×320 のまま書き、表示の大きさに合わせて拡大している（`sketch.ts`）。

動きを減らす設定のときは、3000 歩（50 秒分）を先に進めた絵で止める。

## もとのデモから変えたこと

記事の本文にはコードがなく、fiddle のコードがもと。違いは次のとおり。

- processing.js をやめて、canvas 2D で描いた。クラス `Walker` は、x と y を持つオブジェクト 3 つにした
- 色 `stroke(150, 0, 20, 20)` は彩度が 0 なので、不透明度 20% の暗い灰色（`rgb(51 51 51)`）として書いた
- 320×320 の固定の大きさをやめて、画面の大きさに合わせて正方形のまま拡大・縮小するようにした（もとの 2 倍まで）。点の大きさも同じ割合で変わる
- 画面の外にある間とタブが裏にある間は止まる。動きを減らす設定では止まった絵になる
- 見出しは Google Fonts の Dancing Script を実行時に読んでいた。外から読まないよう、同梱の Molle にした
- Bootstrap 4 alpha の CSS と JS を読んでいたのをやめた。見出しの大きさと余白は自分で書いた
- 枠の点線は canvas ではなく、外の箱に付けた。canvas に付けると、描く大きさが線の分だけずれるため
