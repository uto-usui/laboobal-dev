# 貝の縁に残る模様

## 何をしているか

65%まで育った貝殻から始まり、約11.2秒かけて完成する。初回・自動再開・「新しい貝」はどれも999行まで実際のCAを先行計算し、模様の履歴を持った状態で描く。以後は毎秒48行で進める。殻口の閉じた縁に384個のセルを並べ、活性と抑制の状態を1刻みずつ進める。その行を、同じ時刻に伸びた殻の色として残す。完成時の高さが画面の約66%になる距離から見るため、先が小さいうちと育ったあとで大きさが変わる。縦長の画面では横幅76%の制限も使う。

伸びる縁をタップすると、選んだセルの位置が一瞬光り、そこから色素の波が左右へ広がる。一セル一行では縮小時に見えないため、入力の直後に同じCAを8行進め、その後は通常の刻みで育てる。波がぶつかると消え、抑制が活性域を戻って白い面を閉じる。三角の大きさや寿命は、先に乱数で決めない。新しい入力は進行中の波にも作用し、ぶつかる場所と模様が変わる。空いた所からドラッグすると、殻を見る向きが変わる。殻の上からは視点をつかまない。Enter・空白では、今見えている縁に波を起こせる。

何も操作しない間は自然発火が見本の模様を作り、完成後5秒で別の種から育ち直す。一度操作すると、見本の進行中の波と自然発火を止め、操作で生まれた波だけを進める。波が消えたら成長も止まる。「新しい貝」は、最初は閉じているlil-guiの「設定」へ移した。「模様の決まり」の変更は殻をやり直さず、現在のセルに係数を反映し、縁に波を起こす。

## 模様の決まり

セルは色素を出す活性状態と、不応期の残量を持つ。左右へ進む興奮の前線が到着すると活性になる。前線同士が同じセルで会う場合と、隣のセルとの間ですれ違う場合の両方を衝突として扱う。衝突した前線は消え、左右へ抑制を返す。抑制は活性域だけを進んで色素の放出を止め、再発火までの不応期を残す。殻口は閉じた列なので、端を越えた波は反対側へ続く。

「三角」「縞」「網目」は同じ更新処理を使う。1刻みあたりの興奮の伝播距離、抑制の速さ、不応期、自然発火率だけを変える。三角では広がった白い面を速い抑制が閉じる。縞では興奮を速くして横へ広がった帯ができる。網目では抑制と興奮の速さを近づけ、不応期を短くして、波の干渉が細かく連なる。位相振動子や、三角形・入れ子・縁取りを別に描く処理は使わない。

画像のR成分は活性、G成分は抑制の残量で、各セルの値をそのまま記録する。白い活性域と、抑制から変わる焦げ茶〜黄土の地色を混ぜる。輪郭に濃茶の線は足さない。三角の係数は興奮の伝播距離1、抑制の速さ2、不応期1、自然発火率0.0018とした。発火率0.003のときより発火の間隔を空け、縮小しても三角の面を残す。

初期の種`0x71c3a9`で完成した384×1,536の色素画像を測ると、白は201,710セル、全589,824セルの34.20%になる。R成分が128以上の画素を白とし、上下左右と斜めの8近傍で連結成分を数える。閉じた殻口に合わせて左右の端はつなぎ、成長方向の上下はつながない。ノイズ除去や照明は加えない。成分は400個で、小（256セル未満）が234個、中（256以上2,048セル未満）が148個、大（2,048セル以上）が18個となった。面積の中央値は169セル、90パーセンタイルは1,506セル、最大は10,006セルである。これは三角模様の連結成分数で、互いに接した三角を別々には数えない。

連続する20個の種では、白が32.53〜37.52%に収まり、どの種でも小さい成分が過半数、大きい成分は8%未満になった。別に10個の種で3規則を計算し、どれも白の割合が全体の4割以内に収まることを確かめる。これらはセルの履歴での面積で、曲面上の面積や画面上の反射光の割合とは別である。

## 曲面、光、入力

殻口の断面を完成時の3.5%から拡大し、4周巻いた履歴を曲面にする。成長方向1,536段、断面256分割のうち、生成した所までだけ描く。殻口をこちらへ向ける位相は曲面に含める。外唇は12分割の薄い半円断面で、開口を板でふさがない。

完成形からカメラの距離を決め、成長中も保つ。現在の殻を正面から投影した外接矩形の中心へ、注視点を追従させる。外唇の厚み分の余白も含めて計算する。中心の計算は成長と画面の縦横比に従い、ドラッグの回転角には従わない。ドラッグではこの中心のまわりを一定の距離で回る。タップした画面の位置と、描画と同じ曲面から投影した384セルとの距離をCSS pxで比べ、40px以内で最も近いセルへ入力する。縁の判定では曲面による遮蔽を使わず、縁の近くを押した入力を取りこぼさないことを優先する。ちょうど40pxの境界には計算の丸めを吸収する微小な許容差を設けた。カーソルは縁の近くでだけ指の形にする。空いた所と殻の上は曲面への光線判定で区別する。指の操作には共通の`touchGate`を使い、ふだんは`touch-action: pan-y`にする。画面の案内は左下の「縁をタップで波が広がる」だけにし、支援技術向けには回転の説明も残す。

左上に寄せた光で丸みを出し、縦長の面光源が体層に一本だけ映り込むよう、反射の幅と長さを別々に測る。白い色素と見分けやすくするため、反射の幅を0.23〜0.19から0.30〜0.27へ広げ、強度を0.16〜0.23から0.10〜0.14へ弱めた。4倍MSAA、1,024角の深度画像と9点平均の影を使う。描いたばかりの帯は少し濡れた反射にし、色素による法線の凸凹は付けない。背景は透明なcanvasの下に置いた、ごく暗い暖かい灰色のなめらかな面である。

## 完成後と動きを減らす設定

完成してからも繰り返し触れるよう、最後の192行（殻口に近い12.5%の帯）は循環記録する模型とした。内側の1,344行はそのまま残し、縁の帯では新しい行が押し出されていく。殻全体の大きさは増やさない。帯を含むすべての色素は、同じセルの状態から来る。これにより、育ちきった殻で入力が効かなくなることを避ける。

動きを減らす設定では65%まで育った一枚を最初に描き、自動成長、自然発火の進行、自動再開、艶の時間変化を止める。タップしたときだけ96行分を計算して一枚に反映する。ドラッグによる視点の変更は残す。設定を途中で切り替えても、殻をやり直さない。

色素の履歴は384×1,536のRGBA画像と縮小画像で持つ。新しい帯に関わる行だけを面積平均してGPUへ送り、線形補間と異方性フィルタで読む。固定の刻みと共通の可視状態に従うループを使い、背面タブや画面外の時間は進めない。初期の乱数の種は`0x71c3a9`で、新しい貝ごとに7,919ずつ変える。WebGPU非対応、初期化失敗、device喪失は案内へ切り替える。

殻の成長と局所的な波の衝突を観察するための模型で、生理の実証モデルではない。完成後の帯の更新も、繰り返し操作するための省略である。

## 確認

`node src/demos/nature-shell/measure-pattern.mjs`で完成画像の白の割合と連結成分の大きさを測る。引数に保存先を渡すと、計測した二値画像をPGM形式で保存する。

`node --test src/demos/nature-shell/model.test.ts`で、波の伝播と消滅、入力による衝突時刻の変化、自然発火の停止、記録の保存、白の割合と成分の分布、差分縮小画像、開始行と完成までの時間、先行計算した履歴の一致、固定距離での成長時の大きさと中央への追従を確かめる。途中と完成後の3回の入力、1025×1753・1000×400・800×500の縁の最近傍選択、40pxの境界も検査する。描画と実機での操作はブラウザで別に確かめる。
