# ばねのように引き合うノード

## 何をしているか

黒い画面の中を 50 個の点が漂い、壁に当たると跳ね返る。近い点どうしは線で結ばれ、近いほど線が濃い。結ばれた点は引き寄せ合い、引かれるたびに少しずつ速くなる。しばらく見ていると、いくつかのかたまりができては、ほどけていく。

## 大事なところ

すべての 2 点の組について距離を見て、100 より近ければ、線を引き、互いの速さに相手の方向へ `距離 × ratio`（1/50000）を足し合う。遠いほど強く引くので、ばねのような力になる。

引き寄せる力は 100 の内側でしか働かないので、近づいた点は勢いのまま行き過ぎ、100 の外へ出ると引かれなくなる。引かれるたびに速さが積み重なるので、始めはゆっくり漂っていた点が、だんだん速く動くようになる。

壁では速さの向きを反対にする。壁に触れている点は、その向きには引き寄せる力を受けない。跳ね返った向きを、引く力が打ち消さないようにしている。

## 作り方

`createjs-node-motion` と同じ組み立てで、端の処理を「反対の端から戻る」から「跳ね返る」にしたもの。点ごとに位置と速さを持ち、1/60 秒ごとに「壁で向きを変えて動かす」「近い組を引き寄せる」をくり返す。線と点は毎フレーム描き直している。

画面いっぱいの canvas に CSS ピクセルの座標で描き、devicePixelRatio は共有の `fitCanvas` に任せている。

## もとのデモから変えたこと

もとは fiddle の HTML で jsDelivr から CreateJS 1.0.1 を読み、`_node` というクラスで書いていた。記事の本文にコードはない。違いは次のとおり。

- CreateJS をやめ、canvas 2D で描き、共有の `loop` で回している
- もとは canvas の大きさに devicePixelRatio を掛け、点の大きさ、線の太さ、速さにも同じ数を掛けていた。線を引く距離（100）には掛けていなかったので、Retina の画面では CSS ピクセルで 50 の距離でしか結ばれなかった。ここでは CSS ピクセルで 100
- もとは開いたときに 1 回だけ大きさを測った。大きさが変わったら canvas を合わせ、点を同じ割合の位置へ移す
- 色は `Math.random() * 0xFFFFFF * 1000` を `Graphics.getRGB` に渡していた。桁があふれたでたらめな色で、黒に近い見えない色になることもあった。でたらめな色相に、彩度 90%、明るさ 55% を合わせた色にした
- 下にあった「CreateJS _node」の見出しを外した。画面の高さいっぱいの黒い枠の下にあり、スクロールしないと見えなかった
- 動きを減らす設定では、置いたばかりの点と線を止めて見せる
- SCSS を普通の CSS にした
