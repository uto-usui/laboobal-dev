# 矩形を円形に描く

## 何をしているか

青緑から紫の半透明の小さな正方形 20 個を、輪のように並べる。processing.js の入門の記事の 1 本で、`translate()` と `rotate()` で座標そのものを動かす描き方を見せる。fiddle の小見出しは「translate」。

## 大事なところ

正方形はどれも同じ `rect(0, 0, 10, 10)` で描いている。動かしているのは正方形ではなく座標の原点のほう。

1. 原点に正方形を描く
2. 原点を右へ 16 だけ進める（`translate`）
3. 向きを 360 ÷ 20 = 18 度だけ回す（`rotate`）

これを 20 回くり返す。進む向きが毎回 18 度ずつ曲がるので、20 回で 360 度回りきり、正方形は輪になって最初の位置に戻ってくる。輪は画面の真ん中から右へ描き始めるので、真ん中より少し下に寄って見える（もとも同じ）。

進む距離の 16 は、`(320 − 10 × 20) ÷ (20 − 1) + 10`。もとは `int` の割り算なので 6.3 が 6 になる。

## 作り方

canvas 2D でも `ctx.translate` と `ctx.rotate` は前の変換に積み重なるので、Processing と同じ書き方ができる。色は最初に 20 個分だけ乱数で決めておき、描き直しても変わらないようにしている。座標は記事と同じ 320×320 のまま書き、表示の大きさに合わせて拡大している（`sketch.ts`）。

## もとのデモから変えたこと

記事の本文にはコードがなく、fiddle のコードがもと。違いは次のとおり。

- processing.js をやめて、canvas 2D で描いた。`rectMode(CENTER)` の代わりに、左上を `-5, -5` にして中心に描いている
- 320×320 の固定の大きさをやめて、画面の大きさに合わせて正方形のまま拡大・縮小するようにした（もとの 2 倍まで）
- 見出しは Google Fonts の Dancing Script を実行時に読んでいた。外から読まないよう、同梱の Molle にした
- Bootstrap 4 alpha の CSS と JS を読んでいたのをやめた。見出しの大きさと余白は自分で書いた
- 枠の点線は canvas ではなく、外の箱に付けた。canvas に付けると、描く大きさが線の分だけずれるため
