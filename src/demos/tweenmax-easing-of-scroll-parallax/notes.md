# ホイールのスクロールをゆっくりにしてパララックス

## 何をしているか

ホイールを回すと、ページが 3 秒かけてゆっくり止まるようにスクロールする。黒い縦長の枠の中に回る点が 5 つあり、スクロールに合わせて、点ごとに違う速さで上下にずれる。

## 大事なところ

ホイールのスクロールを止めて、自分で動かしている。ホイールが来たら `preventDefault` で普通のスクロールを止め、今の位置からホイール 1 段あたり 720px 先を目当てに、GSAP で 3 秒かけてスクロールさせる。続けて回すと、そのたびに今の位置から目当てを作り直すので、勢いが足されていく。

点のずれは、点のもとの位置が画面の上からどれだけ下にあるかに、点ごとの倍率を掛けて決める。倍率は 0.8〜2.5 で、大きい点ほど大きくずれる。ずれる量にすぐは合わせず、1.5 秒かけて追いつかせる。スクロールがゆっくり止まるのと、点が遅れて追いつくのが重なって、水の中のような重さが出る。

## 作り方

スクロールは GSAP の ScrollToPlugin で動かしている。`autoKill: true` なので、スクロールバーやキーで動かされたら、そちらに任せて止まる。点は `gsap.quickTo` で `y` を追わせている。

ホイール 1 段の大きさは、Chrome では 100px、Firefox では 3 行で届く。もとの `wheelDelta`（1 段で 120）にそろえてから使っている。

ページの端まで来たら、ホイールを止めない。記事の iframe の中で回したときに、外の記事のページへスクロールを渡すため。もとは端でも止めていたので、iframe の上ではホイールで記事を読み進められなかった。横のスクロールと、トラックパッドのピンチ（ctrl を押しながらのホイール）も止めない。

`prefers-reduced-motion` が有効なときは、ホイールのスクロールをゆっくりにしない。点のずれはそのまま。

## もとのデモから変えたこと

記事の本文には TweenMax のコードが載っている。違いは次のとおり。

- TweenMax 1.19 と jQuery を、GSAP 3 にした。`TweenMax.to($window, 3, { scrollTo })` は `gsap.to(window, { duration: 3, scrollTo })`、`Power1.easeOut` は `'power1.out'`、`overwrite: 5` は `overwrite: true`
- `mousewheel` と `DOMMouseScroll` を、`wheel` 1 つにした
- もとは、点をずらしたあとの位置を測って、ずらす量を決めていた（jQuery の `offset()` はずらした分も含む）。このため、行き着く先は倍率 r に対して r / (1 + r) 倍になっていた。ここでは、ずらす前の位置を測り、倍率を r / (1 + r) にして、同じ量だけずれるようにした
- 点の動きを、スクロールのたびに `TweenMax.to` を作っていたのを、`gsap.quickTo` にした
- 目当ての位置を、0 からページの下端までに収めた
- 見出しは Google Fonts の Dancing Script を実行時に読んでいた。外から読まないよう、同梱の Molle にした
- Bootstrap 4 alpha の CSS を読んでいたのをやめた
- SCSS を普通の CSS にした。点の位置の `@for` は、CSS の変数 `--i` で書いた
