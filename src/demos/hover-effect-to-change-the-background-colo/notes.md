# 背景の色が 2 段で変わるホバー

## 何をしているか

四角にマウスを乗せると、下から青緑の板がせり上がり、続けて金色の板が追いかけて上がる。同時に「HOVER」の字が白くなり、四角からはみ出すほど大きくなる。外すと、金色、青緑の順に下がって戻る。

## 大事なところ

色の板は、四角の疑似要素 `::before`（金色、手前）と `::after`（青緑、奥）の 2 枚。どちらも下端を軸に、高さ 0 から伸ばす。

順番は `transition-delay` で決めている。乗ったときは、青緑はすぐ、金色は 0.25 秒遅れて動く。外したときは逆に、金色がすぐ、青緑が 0.25 秒遅れて動く。遅らせる側を `:hover` の中と外で入れ替えているのがいちばんの工夫で、これで「重ねた順に積み、上から順にはがす」動きになる。片方だけに遅れを付けると、外したときに奥の青緑が先に消えて、手前の金色だけが宙に残る。

文字は 0.25 秒遅れて、0.4 秒で大きくなる。板が上がりきるころに文字がはじけるように広がる。

## 作り方

CSS だけで、script はない。`<a>` は押してもどこへも行かないよう、`click` で `preventDefault` だけしている。

板は `top` を 100% から 0 に動かしていたのを、`transform: scaleY()` にした。`top` を動かすと毎フレームレイアウトを計算し直すが、`transform` なら合成だけで済む。見た目は同じ。

キーボードで選んだときにも同じ動きになるよう、`:hover` と `:focus-visible` の両方に当てている。

## もとのデモから変えたこと

記事の本文には SCSS のコードが載っている。違いは次のとおり。

- 板の動きを `top` から `transform: scaleY()` にした
- `transition: all` を `transition: transform` にした
- `:focus-visible` でも動くようにした
- 文字の色は、Bootstrap のリンクの青だった。地の色に合わせて濃い灰色にした。乗せたときに白くなるのは同じ
- 四角の大きさを、iframe が低いときは小さくした（`min(300px, 60cqh)`）
- 見出しは Google Fonts の Dancing Script を実行時に読んでいた。外から読まないよう、同梱の Molle にした
- Bootstrap 4 alpha の CSS と JS を読んでいたのをやめた
- SCSS を普通の CSS にした
