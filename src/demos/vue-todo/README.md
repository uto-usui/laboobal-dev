# 簡単な TODO アプリケーション

## 何をしているか

小さな TODO リスト。入力欄にやることを書いて「Add」を押すと、リストの最後に足される。チェックを入れると線が引かれて薄くなる。上の「1 / 2」は、まだ済んでいない数と、全部の数。

## 大事なところ

やることは `{ text, done }` の配列で持つ。画面はこの配列から作る。

- 足す: 入力の前後の空白を削り、空なら何もしない。空でなければ配列に足し、li を 1 つ作って最後に付け、入力欄を空にする
- チェック: チェックを切り替えたら、その項目の `done` を書き換える。線を引くのは CSS（`:checked + span`）
- 数える: 足したときとチェックを切り替えたときに、`done` でないものの数を数え直す

記事のもとのデモは Vue 2 で書いていて、`data`、`methods`、`computed` に分けていた。ここでは Vue を使わず、`addTodo` は form の submit、`remaining` は `count()` にあたる。Vue は配列が変わると画面を作り直すが、ここでは変わったところだけを自分で書き換える。

## 作り方

1 件分の li は `<template>` に置き、`cloneNode` で複製して中身を入れる。文字は `textContent` で入れるので、入力に HTML を書いても、そのまま文字として出る。

## もとのデモから変えたこと

記事の本文には Vue のコードが載っている。違いは次のとおり。

- Vue 2 をやめて、素の DOM で書いた
- Bulma 0.5 の CSS を読んでいたのをやめた。使っていた部品（hero、box、入力欄とボタンのくっついた組）の見た目を、自前の CSS で近づけた
- 入力欄とボタンを `<form>` で包んだ。ボタンを押すほかに、Enter キーでも足せる
- 入力欄に `aria-label` を付けた。数のところは、変わったら読み上げるよう `aria-live` にした
- 項目の文字を囲む `"` を、HTML ではなく CSS の `::before` と `::after` で付けた
