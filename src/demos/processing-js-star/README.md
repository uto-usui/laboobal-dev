# 星を描く

## 何をしているか

同じ色の五角形の星を 2 つ、左右に並べて描く。色は青緑から紫の中から、開くたびに選び直す。processing.js の入門の記事の 1 本。

## 大事なところ

星は、中心から遠い頂点（山）と近い頂点（谷）を交互に結んだ形。

- 頂点は山 5 つと谷 5 つで 10 個。360 ÷ 10 = 36 度ずつ回りながら置く
- 偶数番目は山で、中心から幅の 1/4（80）。奇数番目は谷で、その半分（40）
- 頂点の位置は `r × cos`、`r × sin`。最初に -90 度回しておくので、1 つ目の山が真上に来る

谷の深さ（山との比）を変えると、太い星にも細い星にもなる。山と谷の数を変えれば、六芒星などにもなる。

## 作り方

星を描く部分を 1 つの関数にして、中心の位置だけを変えて 2 回呼んでいる。`translate` で中心へ移し、描いたら `restore` で戻す。座標は記事と同じ 320×320 のまま書き、表示の大きさに合わせて拡大している（`sketch.ts`）。

## もとのデモから変えたこと

記事の本文にはコードがなく、fiddle のコードがもと。違いは次のとおり。

- processing.js をやめて、canvas 2D で描いた。`setup()` と、`noLoop()` で 1 回だけ呼ぶ `draw()` の分け方はなくし、描く関数を 1 つにした
- 色は開くときに 1 回だけ決める。画面の大きさが変わって描き直しても、色は変わらない
- 320×320 の固定の大きさをやめて、画面の大きさに合わせて正方形のまま拡大・縮小するようにした（もとの 2 倍まで）
- 見出しは Google Fonts の Dancing Script を実行時に読んでいた。外から読まないよう、同梱の Molle にした
- Bootstrap 4 alpha の CSS と JS を読んでいたのをやめた。見出しの大きさと余白は自分で書いた
- 枠の点線は canvas ではなく、外の箱に付けた。canvas に付けると、描く大きさが線の分だけずれるため
