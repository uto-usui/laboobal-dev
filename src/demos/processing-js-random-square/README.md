# ランダムな大きさと色で矩形を描く

## 何をしているか

半透明の小さな正方形 300 個を、画面のあちこちに散らす。1 つずつ、位置、大きさ（5〜15）、色（青緑から紫）がでたらめに決まる。開くたびに違う絵になる。processing.js の入門の記事の 1 本。

## 大事なところ

`for` で 300 回まわし、そのたびに `random()` で 4 つの値を引く。

- 位置は画面の幅と高さの中から
- 大きさは 5 から 15
- 色は HSB の色相を 150 から 250 の中から。彩度と明るさは決めておくので、色の幅が青緑から紫に収まる

正方形は不透明度 35% なので、重なったところが濃くなる。色の幅を絞ることと、半透明で重ねることで、でたらめでもまとまった絵になる。

## 作り方

乱数は最初に 1 回だけ引いて配列に入れ、その配列から描いている。画面の大きさが変わって描き直すときに、絵が変わらないようにするため。HSB の色は `src/shared/processing.ts` の `hsb()` で rgb に直す。座標は記事と同じ 320×320 のまま書き、表示の大きさに合わせて拡大している。

## もとのデモから変えたこと

記事の本文にはコードがなく、fiddle のコードがもと。違いは次のとおり。

- processing.js をやめて、canvas 2D で描いた
- 乱数を描く前にまとめて引くようにした。開くたびに違う絵になるのは、もとと同じ
- 320×320 の固定の大きさをやめて、画面の大きさに合わせて正方形のまま拡大・縮小するようにした（もとの 2 倍まで）
- 見出しは Google Fonts の Dancing Script を実行時に読んでいた。外から読まないよう、同梱の Molle にした
- Bootstrap 4 alpha の CSS と JS を読んでいたのをやめた。見出しの大きさと余白は自分で書いた
- 枠の点線は canvas ではなく、外の箱に付けた。canvas に付けると、描く大きさが線の分だけずれるため

記事の説明文は、ひとつ前の記事（グラデーションの水玉）と同じ文になっている。記事の側の書き間違いと思われる。
