# 手書きの線を描き直す

## 何をしているか

生成りの紙に、輪、続け書き、短い払いの 3 本の手書きの線が描かれていく。長い線ほど速く進み、3 本とも同時に描き終わって輪が閉じる。描いている先端には小さな点が付いて、線を引っぱっていく。少し止まって薄くなり、また描き始める。ドラッグで自分の線を 1 本書くと、それも足して全部が最初から描き直される。次に書いた線は、前に足した線と入れ替わる。

## 大事なところ

- 進み具合 p（0〜1）を全部の線で 1 つにし、それぞれの線は「p × 線の長さ」まで見せる。長い線ほど 1 秒に進む距離が長くなり、形や長さが違っても描き終わりがそろう。足した線も同じ p で進むので、いっしょに終わる
- ease は p に 1 回だけ掛ける（`q²(3−2q)`）。線ごとに掛けると、描き終わりはそろっても途中の速さの変わり方がばらばらになる
- 書いたときの速さや止まった時間は再生しない。描き直すのは形だけで、速さは長さで決まる
- 先端の点は、描いている途中だけ出す。線より少し太い点が先を行くと、ペン先が線を引いているように見える。描き終わると消える
- 線の太さは、筆圧が取れるペンなら筆圧で、マウスと指は速さで決める（速いほど細い）。筆圧に対応していない環境では pressure が 0.5 に固定で返ってくるので、0 と 0.5 しか来ないうちは筆圧なしとみなす
- 線が自分と交わる所や、別の線と重なる所が濃くならない。全部の線を「その画素をどれだけ覆うか」の 1 枚の絵に MAX で重ね、最後に紙と墨の色を 1 回だけ混ぜる。墨の色を直接重ねると、重なった所と、なめらかにした縁が濃くなる

## 作り方

- 素の WebGL2。three は使わない
- 線の点は間引いてから Chaikin を 2 回掛けてなめらかにし、そのあと道のりを測り直す。太さも同じ割合でならす
- 線は区間ごとの台形と、継ぎ目に置いた円で作る。急に折り返しても角が飛び出さない。見せる範囲は道のりで切り、途中の先端の位置と太さは、その区間の中で補間する
- 最初の 3 本は `assets/strokes.json` に、基準の 800×500 の座標で入れてある。今は仮の線で、作者があとで書き直す。開発サーバーで線を書くと、その線を `strokes.json` の 1 本分の形で console に出す（本番のビルドには入らない）
- 描く 2.4 秒、止まる 1 秒、0.4 秒で薄くして、くり返す。書いている間は全部の線を描き終わった姿で止める
- 動きを減らす設定では、描き終わった絵を出す。自分で書くことはでき、書いた線はその場に出る
- 書いている途中で画面の外へ出たら、そこまで書いた線で確定する。iframe の端に触れただけで書いた線を捨てないため
- 指のスクロールは `pan-y` と `touchGate` に任せる。タップしてから縦にも書ける
- 色は `main.ts` の先頭の `COLORS` で替える

## もとのデモから変えたこと

もとのサイトは暗い緑の上に細い淡い線で、先端の点は白かった。ここでは生成りの紙に墨の色の線にして、先端の点も線と同じ色にした。描く時間と線の太さはこのデモで決めた値で、もとのサイトとそろえてはいない。
