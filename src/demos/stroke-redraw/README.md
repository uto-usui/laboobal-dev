# 手書きの線を描き直す

## 何をしているか

暗い緑の上に、淡い線で図形をひと筆で描く。白い点が先を行き、描き終わると消える。少し止まって薄くなり、前とは違う図形をランダムに選んで描く。ドラッグで書くと図形が自分の線に入れ替わり、その線だけをくり返し描き直す。もう一度書けば新しい線に替わる。読み込み直すまでは図形に戻らない。

左下の「draw it」は書くことを促す。最初に自分の線を書き終わると、ふわっと消える。

## 大事なところ

- 進み具合 p（0〜1）に線の全長を掛け、その距離までを見せる。図形でも自分で書いた長い線でも、長さに関係なく同じ時間で描き終わる
- ease は p に 1 回だけ掛ける（`q²(3−2q)`）。距離や先端の位置に重ねて掛けず、線全体の緩急をここで決める
- 書いたときの速さや止まった時間は再生しない。点の時刻は太さを決めるために残し、描き直す速さは全長と p で決める
- 線の太さは、筆圧が取れるペンなら筆圧で、マウスと指は速さで決める。速く動いた所ほど細い。pressure が 0 と 0.5 しか来ないうちは筆圧なしとみなす
- 線の覆いを MAX で 1 枚に重ね、最後に背景と線の色を 1 回だけ混ぜる。自分と交わる所や、なめらかにした縁が濃くならないようにする
- 白い先端は覆いに混ぜず、色を混ぜ終わった線の上に描く。線と重なっても白く見える

## 作り方

- 素の WebGL2 を使う。three は使わない
- 渦巻き、3 枚のバラ曲線、リサジュー、外トロコイド、無限大、丸みのある星形の 6 種を数式で作る。どれも一続きで、基準の 800×500 の中央に高さ約 300px で収める。横幅は 480px までにする
- 点に道のりと緩やかに変わる速さから求めた時刻を付け、既存の太さの計算を使う。手ぶれは加えず、図形の形を保つ
- 点を間引いてから Chaikin を 2 回掛け、太さもならす。そのあと道のりを測り直し、区間ごとの台形と継ぎ目の円で線を作る。途中の先端の位置と太さは区間の中で補間する
- 描く 1.6 秒、止まる 0.7 秒、薄くなる 0.4 秒でくり返す。図形を選び直すのは薄くなり終わったときだけにし、直前と同じ図形は選ばない
- 書き始めると図形を隠し、書いている線だけを出す。10px 以上動いた線を確定し、短いタップや入力の取り消しでは直前の線を残す
- 動きを減らす設定では、描き終わった姿で止める。自分で書くことはでき、書いた線はその場に出る。「draw it」もすぐ消す
- 書いている途中で画面の外へ出たら、そこまでの線で確定する。pointerId で 1 本の指だけを追い、指のスクロールは `pan-y` と `touchGate` に任せる
- context が戻ったら線を作り直す。表示の大きさと DPR の変化でも描画先を作り直す
- 配色は `main.ts` の先頭の `COLORS` で替える。「draw it」は HTML で左下に置き、最初の線を確定したときに 0.4 秒で消す。プレビューの撮影では隠す

## もとのデモから変えたこと

暗い緑、淡い線、白い先端はもとのサイトに寄せた。図形の種類や選び方、描く時間、線の太さはこのデモで決めた。記録した手書きの線は使わず、数式の図形から始めて、読む人が書いた線に置き換える。
