# かたかた震えるグリッチエフェクト

## 何をしているか

黒い帯に白い字で「GLITCH」と書いたものが 2 つある。しばらくすると、帯が数回だけ小刻みにずれたり傾いたりして、かたかたと震え、また止まる。2 つの帯は別々に、でたらめな間をあけて震える。

## 大事なところ

1 回の震えは、5 回の「ずれた姿」でできている。1 つの姿は、上下左右に -5〜5px ずらし、-2〜2 度傾けたもの。その姿で 0.05〜0.1 秒だけ止まり、次のずれた姿に変わる。5 回変わったら元の位置に戻し、0.5〜10 秒待ってから、また震える。

ずれの量も、1 つの姿でいる時間も、次に震えるまでの時間も、毎回でたらめに選ぶ。動きの間がそろわないので、機械が引っかかったような、ノイズのような震えに見える。

## 作り方

要素ごとに「次に姿を変える時刻」と「何回ずらしたか」を持ち、`loop()` の経過時間がその時刻を過ぎたら、姿を変えて次の時刻を決める。ずらすのは `transform` だけ。

開いてすぐに震えが見えるよう、最初の 1 回だけは 0.5〜2 秒で震えだす。

動きを減らす設定のときは震えさせず、ずれていない姿で止める（`autoplayLoop`）。小刻みに位置が変わるのは点滅に近いので、止める。

## もとのデモから変えたこと

記事の本文にはコードがない。fiddle では codrops の glitchFx.js を、ほぼそのまま貼っていた。違いは次のとおり。

- `setTimeout` と Promise をつないでいたのを、`loop()` の経過時間で次の時刻を決める形にした。画面の外では止まり、戻ったときにまとめて震えない
- クラスをやめて、要素ごとの小さなデータと 1 つのループにした。どの CSS のプロパティを変えるかの設定は、`transform` だけなので外した
- 戻すときの値を `translate3d(0,0,0) rotate3d(1,1,1,0)` から、`transform` を空にするようにした
- `rotate3d(0,0,1,…)` を、同じ意味の `rotate(…)` にした
- 最初に震えだすまでの時間を、0.5〜10 秒から 0.5〜2 秒にした。2 回目からはもとと同じ
- 動きを減らす設定では止まる
