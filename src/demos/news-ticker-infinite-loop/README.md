# 無限ループするニュースティッカー

## 何をしているか

お知らせの見出しを 3 つ横に並べ、右から左へ流し続ける。全部が左の端の外へ出たら、また右の端の外から入ってくる。ニュースサイトの上のほうにある、流れる帯の部品。

## 大事なところ

動かし方は単純で、並べた見出しの帯を、一定の速さで左へずらしていくだけ。

1. 始めは帯の左の端を、枠の右の端に置く（見えない所から入ってくる）
2. 少しずつ左へずらす。もとは 16ms ごとに 1px
3. ずらした量が「帯の幅 + 余白」を超えたら、全部が左の外へ出たので、1 に戻す

見出しの数や長さが変わっても、帯の幅を測って戻る位置を決めるので、そのまま動く。最後の見出しが出きってから次が入ってくるので、帯が途切れる間がある。途切れずに続けるには、帯を 2 つ並べて、1 つ目が出きったところで戻す作り方にする。

## 作り方

共有の `autoplayLoop` で毎フレーム `transform: translateX()` を書き換えている。速さは 1 秒に 62.5px で、経った時間から進む量を決めるので、画面の書き換えの速さに左右されない。帯の幅は毎フレーム `offsetWidth` で測る。`ul` を `width: max-content` にして、中身の幅がそのまま帯の幅になるようにした。

画面の外にある間とタブが裏にある間は止まる。動きを減らす設定では流さず、先頭の見出しから読める位置に止める。

## もとのデモから変えたこと

記事の本文には jQuery のコードが載っている。違いは次のとおり。

- jQuery をやめて、`querySelector` と `style.transform` にした
- `setTimeout(tick, 16)` を、画面の書き換えに合わせて回るループにした。速さは同じ 1 秒に約 62px
- 帯の幅は、もとは始めに 1 回だけ、見出しごとの `outerWidth()` に余白 30px を足して数えていた。今は帯の幅を毎フレーム測り、最後に余白 30px を足す。数え方の結果は同じで、画面の大きさや字の読み込みで幅が変わっても合う
- 戻る位置（枠の幅）は、もとは始めに 1 回だけ測っていた。今は戻るたびに測る
- 見出しの文言は、作り直しで差し替えた（「【緊急告知】」などの形はもとのまま）。リンクの `href=""` は押すとページを読み直すので、`href` のない `<a>` にした
- Bulma 0.5 の CSS を読んでいたのをやめ、`hero is-primary is-bold` の緑のグラデーションと、`title` の字の大きさと太さを自分で書いた。帯は画面いっぱいの緑の真ん中に置いた
- SCSS を普通の CSS にした
