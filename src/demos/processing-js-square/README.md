# 矩形を描く

## 何をしているか

灰色の横長の画面に、太い線の白い長方形、角の丸い白い正方形、輪郭だけの正方形 4 つ、4 つの頂点を自由に置いた四角形を描く。processing.js の入門の記事の 1 本で、`rect()` の数の読み方を見せる。

## 大事なところ

輪郭だけの正方形 4 つは、どれも `rect(a, b, c, d)` の 4 つの数で描いている。読み方は `rectMode` で変わる。

- `CORNER`（既定）: 左上の x と y、幅と高さ
- `CORNERS`: 左上の x と y、右下の x と y
- `CENTER`: 中心の x と y、幅と高さ
- `RADIUS`: 中心の x と y、幅と高さの半分

真ん中の大小の正方形は、同じ `rect(200, 150, 100, 100)` を `CENTER` と `RADIUS` で描いたもの。5 つ目の数を渡すと角が丸くなり（右下の正方形）、`quad()` は 4 つの頂点を好きな位置に置ける（左上のゆがんだ四角形）。

## 作り方

canvas 2D の `rect()` は左上と幅・高さで描くので、4 つの読み方は描く前に左上と幅・高さへ直してから渡している。角の丸い正方形は `roundRect()`、`quad()` はパスで 4 点を結んでいる。座標は記事と同じ 480×320 のまま書き、表示の大きさに合わせて拡大している（`sketch.ts`）。

## もとのデモから変えたこと

記事の本文には processing.js のコードが載っている。違いは次のとおり。

- processing.js をやめて、canvas 2D で描いた。`rectMode` の切り替えはなくなり、どの正方形も左上と幅・高さを書いている。コメントに、もとの数と読み方を残した
- 記事の本文のコードは、`noFill()` を呼ぶ位置と `rectMode(CORNER)` の行が fiddle と少し違う。デモは fiddle のコードのとおりに描いている
- 480×320 の固定の大きさをやめて、画面の大きさに合わせて同じ比のまま拡大・縮小するようにした（もとの 2 倍まで）。線の太さも同じ割合で変わる
- 見出しは Google Fonts の Dancing Script を実行時に読んでいた。外から読まないよう、同梱の Molle にした
- Bootstrap 4 alpha の CSS と JS を読んでいたのをやめた。見出しの大きさと余白は自分で書いた
- 枠の点線は canvas ではなく、外の箱に付けた。canvas に付けると、描く大きさが線の分だけずれるため
