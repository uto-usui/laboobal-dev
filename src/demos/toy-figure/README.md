# 恐竜の野原を歩くフィギュア

## 何をしているか

おもちゃ風のキャラが、恐竜のいる野原を歩き続ける。マウスを目で追い、クリックやタップで足をそろえて止まり、そちらを1.5秒見てから歩き出す。恐竜を押すと、その個体を見る。

## 大事なところ

キャラのGLBと歩きはそのまま使う。一歩は140 mm・0.34秒で、約0.412 m/秒で進む。支持脚の膝は0°、運ぶ側は0〜40°、太ももは25°以内、腕は24°までとする。スキニング後の靴底の接地点を固定し、脚の開きに合わせて腰の高さを求める。靴底の周囲には、ウェイトに由来する小さな変形が残る。

最初の歩では支持足の前方へのずれも含めて加速し、通常の歩の間は線形に進む。止まるときは現在の一歩を終え、半歩で減速する。歩の境目を越えた時間は次の歩へ渡す。

## 作り方

### カメラと景色

カメラはキャラの水平移動に付き添い、腰の上下は伝えない。初期の横角度は30°、仰角は5°、画角は25°。モデルの境界を投影して距離を求め、実際の見た目の高さは横長で約38%、縦長で約33%にする。画面ごとの距離は30°で合わせ、横に回しても距離は変えない。開発中は `?view=50` などで初期角度を指定できる。大きな恐竜が全身で入る空を空けるため、注視点をキャラの中心から横長で0.62 m、縦長で0.55 m上げる。

ヤシ2種はQuaterniusのUltimate Nature Pack、シダと茂み2種・草3種・岩と小石3種はStylized Nature MegaKitの無料Standard版から選ぶ。ヤシは6〜10 m、シダと茂みは約0.5〜1.4 m、草は約0.2〜0.5 mにする。形は既製のモデルを使い、色をセージ系の緑と茶・灰色へ寄せ、つやを抑える。遠いヤシは頭より上、近い小物は胴体より下を通る距離に配置する。重なりを避けるための非表示や透明化は行わない。画面の比率に合わせて配置数を変え、縦長では中ほどの茂みと岩も足す。手前の背の高い草と細い草は歩く道から遠ざけ、手前のシダは低くして、15〜50°で胴と頭が隠れないようにする。

長さ10 mの区間を18本から始める。前方の画面外に次の区間を置き、後方の区間は霧に隠れきってから外す。空いた区間は次の配置に使う。6種類の配置から直前と異なるものを選び、向きと位置も変える。形状は共有し、材質は個体ごとにわずかに明暗を変える。区間を入れ替える際にその材質を破棄する。16 mごとにキャラ、支持足の接地点、景色、恐竜とその接地点を同じ量だけ戻す。地面は平面にゆるい草・土・明るい色のむらと細い土の道を描いた繰り返し画像を貼る。原点を戻しても模様の絶対座標を保つ。小物の影は丸いグラデーションの板にする。空は明るい青灰色、かすみは85〜210 mにする。

### 恐竜

Animated Dinosaur PackのT-Rex、Velociraptor、Triceratops、Parasaurolophus、Stegosaurus、Apatosaurusを使う。作者のBlendファイルからBlenderでGLBへ変換し、`Walk` と `Idle` だけを残す。VelociraptorのWalkには末尾に静止区間があるため、実際の歩行周期である0〜28フレームを使う。骨や面を新しく作らず、画像のない少数の落ち着いた色へ塗り直し、meshoptで圧縮する。

恐竜は体長を12、2、8.5、9.5、8.5、22 mに合わせる。模型のWalk開始姿勢の長軸の端から端までを体長とする。種類ごとに茶、砂色、赤土色、黄土色、緑灰色、青灰色を選び、元の材質と頂点色で背を濃く、腹を明るくする。板、とさか、角と爪も分ける。

恐竜はこの順を基本に15秒間隔で出す。すでに画面を歩いている個体は置き直さず、次の待機している個体を選ぶ。同じ種類は続けて選ばない。大きさの順を保ち、Apatosaurusをさらに遠くへ置く。横長ではキャラより奥を横切り、縦長では全身が入るよう斜め奥へ歩き、角度が0.3秒止まってから画面の外に出す。登場時の視点で歩き切り、現在の画面から全身が外れたら退場する。経路を外れて入らなかった個体は、種ごとの通過時間の上限を過ぎ、画面にもいないときに回収する。Velociraptorは近くの横を短く回って退場し、遠くに点のように残さない。横長のApatosaurusはカメラの移動に合わせて少し斜めに進み、見えている間の奥行が広がりすぎないようにする。縦長の30〜50°では、角度に合わせてApatosaurusの登場位置を奥に取り、横切る成分を増やす。Velociraptorは回り始める時刻を遅らせる。

四足の3種は、前足の振りを広げ、後ろ足の振りを縮めた `*-balanced.glb` を読む。元の Walk の接地区間を使い、接地中は全脚の足裏の後退速度をそろえて焼き込む。同じ速度で胴体を進め、接地中の足裏を二関節のIKで固定する。原点を戻すときは固定した接地点も戻す。

### 読み込み

全GLBを並行してfetchし、展開後の本文バイト数を合算する。分母は素材変換で作る`asset-bytes.json`を使い、Content-Lengthに依存しない。E2Eで実ファイルとの一致を確かめる。ダウンロードを0〜90%、GLBの展開と材質の準備を92〜95%、シェーダーの準備を99%までとし、最初に描画できた時点で100%にして表示を消す。数字と120 pxの細い線を更新し、progressbarのaria-valuenowだけを変える。読み上げ用のstatusはaria-busyの外に置き、始めと終わりにだけ文を変える。失敗した場合は開き直しを促す案内を残す。

### 顔・描画・操作

NeutralToneMapping、露出1、RoomEnvironment、主光源と補助光源、キャラの足元の影を使う。眼鏡はtransmission、黒目はORMのRに保存した開口をalphaTestへ渡す。首と頭は合計9°、上半身は合計4°の小さな反応に抑える。

横に8 CSS px以上、縦の移動量の1.25倍以上動かすと、境目を超えた分だけ0.15°/pxで回る。角度は15〜50°で、手を離した位置に留まる。移動が8 px未満のときだけタップとして扱い、縦になぞると記事をスクロールできる。キャンバスをTabで選ぶと、左右キーで5°、Homeで30°、EnterまたはSpaceで中央を押せる。動きを減らす設定では、前進・景色・恐竜・まばたき・呼吸を止める。目の追従と押したときの注視、ドラッグやキーで指定した角度は残す。画面外や非表示のタブでは共通の `loop` が描画と時間の更新を止め、戻ったら続きから動く。

## 確かめ方

開発で `?walk-inspect` を付けると、`window.__toyWalk.snapshot()` に適用した角度（ラジアン）、登場・退場時の可視状態と退場理由が出る。`controls.view` をラジアンで上書きでき、`null` で操作した角度に戻る。描画中の角度（度）はステージの `data-camera-angle` でも読める。

`scripts/toy-character/dino-itch.mjs` で作者のitch.io公式配布を取得する。`dino-export.py` をBlenderで実行し、`dino-assets.mjs` で植物の色を整え、圧縮と構成の記録を行う。加工用のNode依存は以前の素材変換で用意した作業用ツール群を使う。

開発サーバーを4410番で動かし、ChromeのGPU描画で次を実行する。

- `dino2-assets.mjs`: 体色と植物の塗り、圧縮、バイト数の一覧を作る。
- `dino2-stills.mjs`、`dino2-scale.mjs`: 3サイズの静止画、脚の連続写真、実寸の比較図。
- `dino2-capture.mjs`: 横長と縦長を各3分記録し、125秒の動画を書き出す。
- `dino2-performance.mjs`: CPUを4倍遅くし、各10秒のフレーム間隔を測る。
- `dino2-loading.mjs`: build後の4411番のpreview、開発サーバー、Content-Lengthのないgzip配信で進捗を確かめる。
- `dino2-behavior.mjs`、`dino2-interaction.mjs`: 動きを減らす設定、画面外の停止、恐竜の選択と歩行再開。
- `dino2-sheets.py`: 静止画、読み込み、動画を並べた画像。

出力はキャラ制作の作業フォルダの`dino2/`に集める。元の配布、ライセンス、配布ページは前回の`dino/vendor/`、今回のGLBの構成とSHA-256、体長と高さは`dino2/assets.json`に残す。`?walk-inspect`の計測APIと実寸の比較図は開発時だけ有効。


### 四足の Walk を作り直す

元のアニメーションと体色が入った `assets/<種類>.glb` からは、リポジトリのルートで次を実行する。変換には、既存の作業用ツール群にある glTF Transform 4.5.1 と meshoptimizer 1.0.1 を使う。

```sh
node scripts/toy-character/dino4-bake.mjs
```

配布元の Blend ファイルから再作成する場合は、既存の配布取得手順で展開した素材から、次の順で変換する。3種の体色付き入力を作業フォルダに作り、既存の入力 GLB を上書きせずに派生 GLB を更新する。

```sh
blender -b --python-exit-code 1 -P scripts/toy-character/dino-export.py -- --quadrupeds
node scripts/toy-character/dino2-assets.mjs --quadrupeds-to .work/toy-character/dino4/source
node scripts/toy-character/dino4-bake.mjs .work/toy-character/dino4/source
```

`dino4-measure.mjs` は足裏の移動と脚の角度、`dino4-project.mjs` は30°の実際のカメラで見える滑りを測る。`dino4-compare.mjs` は地面に目印を置き、カメラを固定した連続写真を撮る。変更前の行には今回の変更直前に保存した `dino4/dinosaurs-before.ts` を使う。
