# 回る星

## 何をしているか

でたらめな色で塗った星が、自分の中心を軸にゆっくり回り続ける。色は開くたびに変わる。

## 大事なところ

星の形は一度だけ決め、回すのは図形の向き（`rotation`）だけにしている。星を (100, 100) に置き、星そのものは原点 (0, 0) を中心に描くので、`rotation` を変えると星の中心のまわりに回る。中心を原点からずらして描くと、回る軸が星の外へ出て、大きな円を描くように振り回される。

`rotation` は 1 フレームに 0.5 度ずつ足す。1 秒に 30 度、1 周は 12 秒。5 つの頂点がそろった形なので、72 度回るごとに同じ形に戻る。

## 作り方

`ctx.translate(100, 100)` で星の中心へ移り、`ctx.rotate` で回してから、原点を中心に星を描いている。星の形は CreateJS の `drawPolyStar(0, 0, 50, 5, .5, -90)` と同じ計算を `polyStar` という小さな関数で作る。もとの canvas（300×260）の座標のまま描き、入れ物に収まる大きさまで canvas を広げる（もとの 2 倍まで）。

## もとのデモから変えたこと

記事の本文には、CreateJS の `Stage`、`Shape`、`Ticker` を使ったコードが載っている。違いは次のとおり。

- CreateJS をやめ、canvas 2D で描き、共有の `loop` で回している。速さは 60fps のときの 1 フレームあたりの量（0.5 度）のまま、前のフレームからの秒数で進める
- 見出しの「create.js」を、fiddle の題名からとった「rotate」にした。CreateJS を使わなくなったため
- canvas の点線の枠は `border` から `outline` にした。`border` だと canvas の大きさに入り、座標がずれる
- canvas を 300×260 の固定から、入れ物に合わせた大きさにした
- 動きを減らす設定では、回る前の向き（頂点が真上）で止める
- SCSS を普通の CSS にした
