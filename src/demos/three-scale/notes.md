# 箱から画面いっぱいへ

## 何をしているか

色の箱を押すと、その箱が画面いっぱいまで広がり、少し止まってから元の箱に戻る。広がるとき、板の一部が先に動き出し、残りが遅れてついてくるので、板が曲がりながら伸びる。3 つの箱は、動き出す順番がそれぞれ違う（左から、左上の角から、真ん中から）。

## 大事なところ

板を細かい頂点に分け、頂点ごとに動き出す時刻をずらしている。「動き出す順番」（`activation`）を 0〜1 で決め、それに 0.5 を掛けた時刻から動き始める。終わりは全部の頂点で同じ（進み具合が 1 のとき）。最初の頂点は全体の時間を使い、最後の頂点は後半だけで追いつくので、遅れた側ほど速く動く。この時間差が、板が曲がって伸びる形になる。

順番の決め方を変えるだけで、まったく違う広がり方になる。左から（uv の x）なら左端が先に飛び出し、角から（x と y を混ぜる）なら斜めに引っぱられ、真ん中から（中心からの距離）なら中心が膨らむ。

頂点ごとの進み具合には `smoothstep` を通す。動き出しと止まりぎわがなめらかになるので、板の曲がった縁が丸く見える。

DOM の箱と WebGL の板を入れ替えて見せている。押した瞬間に箱を隠し、同じ大きさと位置に板を置いてから広げる。戻りきったら板を消して箱を出す。見ている人には箱そのものが伸びたように見える。

## 作り方

1 × 1 の板（64 × 64 に分割）を 1 枚だけ作り、押された箱に合わせて使い回す。箱の位置と大きさ（px）を、カメラから見える範囲の大きさで割って three の単位に直し、板の `scale` と `position` に入れる。広げる計算は頂点シェーダーでする。画面の大きさと板の大きさの比で拡大し、板の位置の分だけ真ん中へ寄せる。

進み具合は GSAP の timeline で 0 → 1 → 0 と動かし、動いている間だけ描く。板の色は箱の CSS の色を読んで渡す。three は色を linear に直して渡すので、シェーダーの最後で `colorspace_fragment` を入れて画面の色に戻す。戻さないと、板が箱より濃い色に見える。

## もとのデモから変えたこと

- 旧デモは同じ色の箱が縦に 2 つで、どちらも左から広がっていた。色と動き出す順番の違う箱を横に 3 つ並べた。旧コードにコメントで残っていた「上から」「左上から」「真ん中から」のうち 2 つを使っている
- 旧デモは広がりきるとすぐに戻っていた。広がった状態を 0.2 秒見せてから戻す
- 板をちょうど画面の大きさまで広げると縁が 1px 残ることがあるので、1% だけ大きくしている
- 旧デモは GSAP 2 の `TweenLite`。GSAP 3 の timeline にした。ease は同じ（`power1.out`）
