# 依頼: 差し替える手の候補を調べる（調査だけ）

`docs/toy-character/README.md` の工程 6b の下調べです。おもちゃ風の子どものキャラ（全高 1 m に換算、Blender 5.2.2 LTS で作り、three.js で動かす GLB として誰でもダウンロードできる形で公開する）の手を、指の骨が入った既製の手に差し替えます。ピースサイン（人差し指と中指を立て、親指・薬指・小指を握る）を骨で作れることが条件です。手を数値で作ることはしません。

前提が曖昧なところは妥当な仮定を置いて最後まで進め、置いた仮定は最終回答に書いてください。調査だけで、ファイルを書いたりインストールしたりはしません。一次情報（公式サイト、リポジトリの LICENSE、リリースノート、公式マニュアル）で確かめ、URL を添えてください。

## 調べること

1. **MPFB（MakeHuman の Blender 拡張）**
   - 最新版と、Blender 5.x（とくに 5.2）で動くかの一次情報。headless（`blender -b`）で人体を作る Python の入口（演算子や関数の名前）
   - ベースメッシュ・リグ・付属アセットのライセンス。生成した人体の一部（手）を公開 GLB に入れてよいか、表記の義務はあるか
   - 手の面数と指の骨の構成（default、game engine、Rigify のどれが向くか）。子どもの体型にする方法（age などのパラメータ）
   - 拡張を、ユーザーの Blender 設定と分けた場所に入れる方法（`BLENDER_USER_RESOURCES` など、`blender --command extension install-file` の使い方）
2. **ほかの候補**: CC0 か、公開 GLB に入れてよいライセンスの、指の骨が入った人の手か人体のモデル（Quaternius、Kenney、Mixamo、Ready Player Me、VRoid など）。おもちゃ・ちびキャラ向きの丸い手があれば優先。ライセンスの条件をそれぞれ書く
3. **Robust Weight Transfer**（SIGGRAPH Asia 2023 の「Robust Skin Weights Transfer via Weight Inpainting」と、その Blender 版）: ライセンス、Blender 5.2 で動くか、Blender の Python に追加で要る依存
4. **既製の手を別のメッシュの手首につなぐ定石**: 袖口の内側で重ねるか溶接するか、大きさと向きを合わせる手順、ウェイトのつなぎ方、色をキャラの肌に合わせる方法
