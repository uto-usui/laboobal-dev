# 依頼: 歩きの直し（歩幅とカメラ）

`scripts/toy-character/prompt-walk.md` で作った歩き（`src/demos/toy-figure/walk.ts`、`main.ts`、結果は `.work/toy-character/walk/` と `.work/toy-character/codex-walk-out.md`）の直しです。膝の向き、足の滑り、めり込みの扱いは合格です。その決まり（`prompt-walk.md` の「膝と関節の決まり」）はそのまま守ってください。

デスクトップで床を押して歩かせ、動画に撮って見ました（`.work/toy-character/walk-review/desktop.webm`、`strip.png` は横向きに歩く 2.4 秒を 6 コマ／秒で並べたもの）。直すのは次の 2 つです。

## 1. 歩幅が小さすぎて、すり足に見える

今は一歩 75 mm・0.34 秒で、両足がほとんど離れず、足も床から上がって見えません。歩いているのでなく、滑って移動しているように見えます。

- 一歩を 0.14〜0.18 m にする（1 m の背丈の小さい子の歩幅）。一歩の時間は、足の運びが速めに見える範囲で決め直す（目安 0.3〜0.4 秒）
- 足を前へ運ぶ間、靴底がはっきり床から上がる（真ん中で 25〜40 mm）。そのぶん膝を曲げるが、40° までの決まりは守る
- 腕の振りも、歩幅に合わせて見て分かる大きさにする（25° まで）
- 円の中を歩くので一歩が大きいと数歩で着く。歩き出しと止まりの一歩は短くしてよい

## 2. カメラが追いすぎて、歩いて見えない

今は奥行きをいつもぴったり追い、縦長の画面では横もぴったり追うので、キャラが画面の上でほとんど動きません（`.work/toy-character/walk/walk-mobile.png` の 4 枚がほぼ同じ絵）。近づいても大きくならず、離れても小さくならないので、その場で足踏みしているように見えます。

- カメラは止めておくのを基本にし、歩いたぶん画面の上でもキャラが動き、近づけば大きく、離れれば小さく見えるようにする
- 歩ける範囲のどこにいても、全身が画面に入る。そのためにカメラを引くか、画面の縦横の比に合わせて歩ける範囲を決める（縦長の画面では、横に歩ける幅を狭め、奥行き方向を主にする、など）。真ん中に立っているときのキャラの大きさは、今から 15% までの縮みにとどめる
- どうしても追わせる場合は、遅れてゆっくり追い、歩いた動きが画面で見えるようにする

## 確かめること（画像と動画は自分で開いて見ること）

`.work/toy-character/walk2/` に出力する。開発サーバーは http://localhost:4410 （URL の末尾の `/` が要る）。Playwright は Chrome（`channel: 'chrome'`、GPU）。

- `cycle-side.png`、`cycle-front.png`: 一歩のくり返しを 8 等分したコマ（前回と同じ撮り方）。両足がはっきり開き、運ぶ足が上がっていること
- `knee.json`、`foot.json`: 前回と同じ測り方。膝の最小が 0 未満なら不合格。運ぶ足の靴底の高さの最大も足す
- `desktop.webm` と `mobile.webm`（390×844、dpr 3）: 開いてから、手前・奥・左・右へ押して歩かせ、止まって向き直るまでの動画。各動画から、歩いている途中を 1 秒に 4 コマ並べた `desktop-strip.png`、`mobile-strip.png`。キャラが画面の上で動き、大きさが変わり、全身が切れないこと
- 真ん中に立っているときのキャラの見た目の高さ（画面の高さに対する割合）を、前と今で、デスクトップとスマホで
- `pnpm verify` を通す（前回と同じ `.work/toy-character/walk/chrome.config.ts` を使ってよい）

## 決まり

前提が曖昧なところは妥当な仮定を置いて最後まで進め、置いた仮定は最終回答に書いてください。書き込むのは `src/demos/toy-figure/`、`e2e/toy-figure.spec.ts`、`scripts/toy-character/`、`.work/toy-character/` の中だけ。`src/shared/` と GLB は変えない。コミットはしないでください。コードのコメントは、その行を見ただけでは分からない理由だけを短く書く。

## 最終回答

日本語で、結論から。決めた歩幅・一歩の時間・足の上がり・膝と腕の角度、`knee.json` と `foot.json` の値、カメラの扱いと歩ける範囲（画面の比ごと）、真ん中に立つときの大きさの前後、`pnpm verify` の結果、まだ足りないところ、置いた仮定。前置きと繰り返しは削る。
