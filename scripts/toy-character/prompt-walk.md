# 依頼: フィギュアを、押した場所まで歩かせる

`docs/toy-character/README.md` の続きです。Web のデモ `src/demos/toy-figure/` は、今はカーソルを目・頭・上半身で追い、まばたきと呼吸をするだけです。ここに歩きを足します。GLB（`src/demos/toy-figure/assets/character.glb`）と骨（20 本）とウェイトは変えません。動きは three.js のコードで、骨の角度を時間に合わせて動かして作ります（アニメーションのデータは作らない）。

歩いても形が崩れない角度の範囲は、先に Web と同じ描画で確かめてあります（README の 2026-11-20 の行、`.work/toy-character/walk-probe/`。`index.html` の `rot()` が、休止姿勢のワールドの軸まわりに骨を回す書き方）。太ももを前後 25°、膝を 20°、腕を前後 25° 振っても、ズボンの裂けや脚の食い込みはありません。膝を 60° 曲げると、膝が丸くつぶれて食い込みます。

## 動き（作者と決めたこと）

1. 床を押す（クリック、タップ）と、押した場所のほうへ体ごと向き、歩いていって止まる。止まったら正面（カメラ）へ向き直り、またカーソルを目で追う
2. 歩ける範囲は、足元の影の円の中（`main.ts` の影は中心から 0.15〜0.55 m で消える）。円の外を押したら、円の縁まで歩く
3. 小さい子らしい歩き方: 歩幅は狭く、少し速めの足の運び。体を左右に少し揺らし、腕は脚と逆に振る。歩いている間、頭と目は進む先を見る
4. 何も触らない間は、ときどき少しだけ歩き回る（スマホでは指で追わないので、動きを見せる役も兼ねる）
5. 動きを減らす設定（`docs/demo-guide.md` の 5 章）: 4 のひとりでに歩き回る分は止める。押して歩かせるのは読む人が始める動きなので残す。設定を途中で替えたら、その場で切り替わる

## 膝と関節の決まり（必ず守る）

- **膝は後ろにしか曲がらない。** 0°（まっすぐ伸びた状態）が限界で、すねが前へ出る向き（膝が逆に折れる向き）の値は、どの瞬間にも出さない。曲げる角度は計算の最後で 0° 以上に切り詰める。`walk-probe` では、`shin` を局所の x 軸まわり正に回すと正しい向きに曲がった（符号は自分で撮って確かめること）
- かかとが床に着く瞬間と、体重を乗せている間は、膝をほぼまっすぐ（0〜5°）にする。曲げるのは足を前へ運んでいる間だけで、40° まで（深く曲げると膝がつぶれる）
- 足首も逆に反らせない範囲にする。太ももは前後 25° まで、腕は前後 25° まで
- 足は床にめり込まず、浮かない。脚を前後に開くと腰の高さが下がるので、体重を乗せている足の裏が床の高さに来るよう、毎フレーム体全体の高さを合わせる
- 体重を乗せている足が、床の上を滑らない。進む速さを歩幅と足の運びに合わせる
- 腕を振ったとき、手が腰や太ももにめり込まない

## 画面

- 歩ける範囲のどこにいても、全身が画面に入る。今のカメラは止まっている姿にぴったり合わせているので、スマホのような縦長では横に歩くとはみ出す。歩ける範囲を含めて合わせ直すか、細い画面ではカメラを横に追わせるかは、測って決める。真ん中に立っているときのキャラの見た目の大きさは、なるべく今と変えない
- 押した場所は、床の平面に当てて求める。キャラのいない背景の上を押しても、床の上の位置として扱う
- iframe に入れて縦になぞったとき、記事がスクロールする（`docs/demo-guide.md` の 6 章、`e2e/toy-figure.spec.ts` のタッチの検査）。タップで歩かせても、縦のスクロールは奪わない
- `meta.ts` の `interaction` などは、`docs/demo-guide.md` の決まりに合わせて直す（どれにしたか、なぜかを最終回答に書く）。slug と title は変えない。description は、歩くことを足して書き直す

## 確かめること（画像は自分で開いて見ること）

`.work/toy-character/walk/` に出力する。開発サーバーは http://localhost:4410 で動いているので、それを使ってかまいません（止めないでください。URL の末尾の `/` が要ります）。Playwright は Chrome（`channel: 'chrome'`、GPU）で。

- `cycle-side.png`、`cycle-front.png`: 一歩のくり返しを 8 等分したコマを、真横と正面から並べたもの（Web と同じ描画）。膝が逆に折れていないか、足が浮いたりめり込んだりしていないか
- `knee.json`: 歩いている間の 1 秒ごとではなく毎フレームの、左右の膝の曲げ角度（休止姿勢からの角度。後ろへ曲げる向きを正）の最小・最大。最小が 0 未満なら不合格
- `foot.json`: 体重を乗せている間の足の裏の滑り（mm）と、床からの高さのずれ（mm）の最大
- `walk-desktop.png`（1440×900、dpr 2）と `walk-mobile.png`（390×844、dpr 3）: 範囲の端の 4 か所へ歩かせて止まったところ。全身が入っているか
- `turn.png`: 歩き終えて正面へ向き直り、カーソルを追っているところ
- 速さ: デスクトップとスマホ相当（CPU throttling 4 倍）で、歩いている 5 秒間のフレーム時間の中央値と P95
- `pnpm verify` を通す。`e2e/toy-figure.spec.ts` に、押すと歩き出すこと、動きを減らす設定で歩き回りが止まること（押せば歩くこと）を足す

## 決まり

前提が曖昧なところは妥当な仮定を置いて最後まで進め、置いた仮定は最終回答に書いてください。書き込むのは `src/demos/toy-figure/`、`e2e/toy-figure.spec.ts`（必要なら `e2e/motion.spec.ts`）、`scripts/toy-character/`、`.work/toy-character/` の中だけ。`src/shared/` は変えない。コミットはしないでください。コードのコメントは、その行を見ただけでは分からない理由だけを短く書く。
