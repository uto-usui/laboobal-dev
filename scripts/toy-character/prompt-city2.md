# 依頼: 街角の静止した見本を作り、見た目を作者に見てもらえる画像にする

`docs/toy-character/README.md` の続きです。フィギュア（`src/demos/toy-figure/`）を「いつも街を歩いている」見せ方にします。方針は `.work/toy-character/codex-city-out.md` の推す案です（斜め前から一緒に進み、道と家並みが後ろへ流れる。街は無料で配られている CC0 のモデルを拾い、塗りを変えて使う）。その「作る順番」の 1 と 2 だけを今回やります。歩かせる処理と、デモのページはまだ変えません。

## やること

1. **素材を少しだけ集めて測る**: Kenney の City Kit（Suburban、Roads、Commercial）を公式の配布元（kenney.nl）から落とし、`.work/toy-character/city/vendor/` に置く。ライセンスの文書（CC0）も一緒に残す。家 3〜4 棟、店 1〜2 棟、道路と歩道の区間、木、柵、街灯を選び、それぞれの三角形数、材質数、画像の有無と大きさ、glTF の大きさを `assets.json` に書く。足りない小物（ベンチ、街灯など）は Quaternius の CC0 のモデル（Poly Pizza にあるもの）で補ってよい。入手先の URL とライセンスを記録する
2. **静止した街角を組む**: three.js で、デモと同じ描画（`src/demos/toy-figure/main.ts` のトーンマッピング、RoomEnvironment、光、影の付け方）を使う見本ページを `.work/toy-character/city/` に作る（デモのページは変えない）。キャラの GLB（`src/demos/toy-figure/assets/character.glb`）を歩道の上に立たせ、片足を前に出した歩きの途中の姿勢にする（`src/demos/toy-figure/walk.ts` の角度の範囲で）。カメラは正面から約 30° 横、水平より 5〜10° 上。進む向きの側に道を空ける。カメラと顔の間に物を置かない
3. **塗りを 2 通り作る**:
   - **A: 配布のままの色**
   - **B: 塗り直した色**: 街全体を 6〜8 色（生成り、暖かい灰色、くすんだ青緑、薄いれんが色など）に絞り、つやを抑えた共通の材質にする。キャラより一段おとなしくし、キャラが目立つようにする。黒い輪郭線は付けない
4. **画面の大きさ 3 つで撮る**: 1440×900（dpr 2）、800×500（dpr 2）、390×844（dpr 3）。どれも頭・手・靴が切れず、街角だと分かること。Playwright は Chrome（`channel: 'chrome'`、GPU）。見本ページは `.work/` を配る静かなサーバー（たとえば `python3 -m http.server` をリポジトリの直下で、空いているポートで）で開いてよい。開発サーバー http://localhost:4410 は止めない

## 確かめること（画像は自分で開いて見ること）

- `city-A.png`、`city-B.png`: それぞれ 3 つの大きさを横に並べたもの
- `compare.png`: 1440×900 の A と B を並べたもの
- `assets.json`: 選んだ素材の測った値と、入手先・ライセンス
- 使った街の部品をまとめた大きさの見込み（meshopt で圧縮したとき）。目標は街全体で 2 MiB 以内
- 1440×900 と 390×844（CPU throttling 4 倍）での、5 秒間のフレーム時間の中央値と P95

## 決まり

前提が曖昧なところは妥当な仮定を置いて最後まで進め、置いた仮定は最終回答に書いてください。書き込むのは `.work/toy-character/` と `scripts/toy-character/` の中だけ。形を数値で新しく作らない（拾ったモデルを置き、塗りを変えるだけ。地面の平らな板はよい）。実在の街並みや、既存のゲーム・作品の見た目をまねない。コミットはしない。

## 最終回答

日本語で、結論から。選んだ素材とライセンス、A と B の見た目の違い（キャラとなじむか、キャラが目立つか）、どちらを推すか、大きさの見込み、速さ、まだ足りないところ、置いた仮定。前置きと繰り返しは削る。
