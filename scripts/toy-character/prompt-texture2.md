# 依頼: 服の色をもっとならした版を 3 段作って並べる

`--stage texture`（記録は `.work/toy-character/texture/`）で、新しい UV と部位ごとの bilateral で服の色をならしました。作者は、もっとならしてもよいと言っています。形・UV・骨・ウェイトは変えず、色の画像だけを変えます。

1. texture 段のならし方を基準（1 倍）に、強さを上げた 2 段を作る（例: 2 倍、3 倍。bilateral の空間の幅と色の幅の両方を上げるか、くり返しかける。どう上げたかを書く）。部位の境目はまたがない。しわやふくらみの大きな明暗は残す（低い周波数の明暗は、ならす前と同じくらい残っているかを測って書く）
2. 顔は目・眉・口・頬の赤みがぼけないように、肌の領域だけを弱めにならす。髪は毛束の明暗が残る範囲で
3. 3 段（1 倍・2 倍・3 倍）それぞれで GLB を作り（`.work/toy-character/texture2/character-x1.glb` など）、Web のデモと同じ描画（1440×900、dpr 2）で、全身と、胸・袖・手の拡大、顔の拡大を撮って並べる（`compare.png`）
4. 細かい明暗のばらつき（高い周波数）と、しわの明暗（低い周波数）の量を、3 段で表にする

デモの `src/demos/toy-figure/assets/character.glb` は置き換えない（作者が選んでから置き換える）。前提が曖昧なところは妥当な仮定を置いて最後まで進め、置いた仮定は最終回答に書いてください。書き込むのは `scripts/toy-character/` と `.work/toy-character/` の中だけ。コミットはしないでください。`build.py` に段 `texture2` として足し、`.work/toy-character/texture2/` に出力してください。開発サーバーは http://localhost:4410 で動いています（止めないでください）。GLB を差し替えて撮るときは、作業用のコピーかリクエストの差し替えで行い、デモのファイルは変えないでください。

最終回答は日本語で、結論から。強さの上げ方、3 段の値、見た目の違い（しわが残っているか、平たくなりすぎていないか）、GLB の大きさ、置いた仮定。前置きと繰り返しは削る。
