## 残っていること

前回の `curves.png` を見ると、まだ機械っぽく見えそうなところが 3 つあります。

- 体（腰）の左右の揺れがまったくない（横の位置が 1e-7 mm の桁で 0 のまま）
- 支える足の膝が、接地のあいだ 0°（まっすぐ）に固まっている。人は着地で 10〜15° ほど膝を曲げて受け、また伸ばす
- 腰の高さが、足が着くたびに角を作る（速度が跳ぶ）

また、前回の依頼の案 B（CC0 の人型の歩きのアニメーションをキャラの骨に移す）は試されていません。恐竜が滑らかになったのは、作者がキーで付けた Walk を再生し、接地中の足だけを IK で留めたからです。

## やること

次の 2 つを作り、前回の案 C と並べて比べ、いちばん自然なものをデモに入れる。

- **D: CC0 の歩きのアニメーションを移す。** Quaternius の Universal Animation Library（CC0）など、人型の Walk を取ってくる（取り方は `scripts/toy-character/dino-itch.mjs` が参考になる。ライセンスを配布元で確かめる。Mixamo のように CC0 でないものは使わない）。キャラの 20 本の骨へ回転を移す（骨の向きの違いは休みの姿勢どうしで合わせる）。キャラは約 3 頭身で脚が短いので、歩幅と歩調は脚の長さに合わせて決め直してよい。接地中の足は恐竜と同じやり方で地面に留める。歩きのアニメーションは別の小さな GLB か JSON に焼いて `src/demos/toy-figure/assets/` に置き、元の配布ファイルから作り直せる変換スクリプトを `scripts/toy-character/` に置く。キャラの GLB は書き換えない
- **E: 今の手続きの歩きに、上の 3 つを足す。** 腰の左右の揺れ（支える足の側へ）、着地で膝を軽く曲げて受ける動き、腰の高さの角をなくす。歩きの位相を一続きの周期として扱い、関節の角度と腰の位置の速さが、歩の境目でも途切れないようにする

どちらでも、押すと足をそろえて止まり、そちらを見てから歩き出すところ（止まる・歩き出すときのつなぎ）がカクッとならないようにする。D なら、止まる姿勢との行き来は、ポーズの間を時間で混ぜてつなぐ。

## 守ること

- 支える足が地面の上を滑らない。膝が逆に曲がらない。2026-11-20 に確かめた範囲（太もも前後 25°、膝 60° まで、腕前後 25°）を大きく超えて、服が裂けたり脚が食い込んだりしない。超えるなら、その角度で横・前・斜めから寄った静止画を撮って確かめる
- キャラの画面の高さ、カメラ、景色、恐竜、横のドラッグ、動きを減らす設定、画面の外での停止は変えない
- 速さ: CPU を 4 倍遅くした条件で、フレーム時間の P95 が今（16.7 ms 前後）より悪くならない。読み込みが増えるなら、増えた量を書く（デモの JS は Brotli で 170 KB 以内）
