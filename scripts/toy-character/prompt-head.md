# 依頼: Blender で頭だけを組み、このやり方で高い質に届くかを確かめる

おもちゃ風の 3D キャラクターを、Blender の Python スクリプトだけで組みます。今回は頭だけです（顔、目、まぶた、眉、髪、眼鏡、首の付け根）。このあと全身、ボーン、Web（three.js）へ進むので、その前に「スクリプトで組むやり方で、デザイン画の質に届くか」を作者が判断するための材料を作ります。

前提が曖昧なところは妥当な仮定を置いて最後まで進め、置いた仮定は最終回答に書いてください。書き込むのはこのリポジトリの `scripts/toy-character/` と `.work/toy-character/` の中だけにしてください。コミットはしないでください。

## 読むもの

- `docs/toy-character/README.md`: この制作の決まり。とくに「工程」と「Blender の作業はスクリプトから毎回作り直す」
- 下絵: `docs/toy-character/design/turnaround-front.png`（正面）、`turnaround-side.png`（横、画面の右を向く）、`turnaround-back.png`（背面）。3 枚は同じ大きさ・位置にそろえてあるが、生成画像なので完全には合っていない。正面を正とし、横と背面は奥行きの目安にする

## 作るもの

`blender -b --factory-startup -P scripts/toy-character/build.py -- --stage head --out .work/toy-character/head` で、何もないところから頭を組み、次を出すスクリプト。何度実行しても同じ結果になること（乱数を使うなら seed を固定）。ファイルの分け方は任せるが、あとで全身・リグ・書き出しの段を足しやすい形にする。

- `.work/toy-character/head/head.blend`
- 確認用のレンダ（下の「確かめ方」）

### 部品と、それぞれに求めること

部品は別のオブジェクトに分け、名前を付ける（`head_skin`、`eye_L`、`eye_R`、`eyelid_L`、`eyelid_R`、`brow_L`、`brow_R`、`hair`、`glasses` など。L / R はキャラクターから見た左右）。

- 顔と頭（`head_skin`）: 丸い輪郭、ふっくらした頬、小さな鼻のふくらみ、小さなあご、閉じた口（口角が少し上がった穏やかな表情）、髪に半分隠れる小さな耳。あとで首と頭のボーンで動かすので、四角形の面で、なめらかに流れる面の構成にする。Subdivision Surface でなめらかにする
- 目（`eye_L`、`eye_R`）: 白目の球に、大きな濃い茶色の虹彩と瞳、つやのハイライト。球の中心で回せるように原点を球の中心に置く（あとで視線のボーンで回す）
- まぶた（`eyelid_L`、`eyelid_R`）: まばたきができる作りにする。肌色のまぶたが目を覆う形を、シェイプキー `blink_L`、`blink_R`（0 で開いて 1 で閉じる）で作る。閉じたときに目が突き抜けないこと
- 眉: デザイン画では前髪の下に少し見える。細い濃い色の弧
- 髪（`hair`）: 前髪のあるおかっぱ。正面と横のシルエットをデザイン画に合わせる。のっぺりした塊にせず、毛束の流れが分かる溝やふくらみを形で付ける。黒に近い焦げ茶で、やわらかいつや
- 眼鏡（`glasses`）: 細い金属の丸いフレーム、ブリッジ、耳へ向かうつる（髪に隠れてよい）。レンズは入れないか、ごく薄い透明にする
- 首: 胴体につなぐ付け根まで

### 質感

最後は glTF に書き出して three.js で見せるので、glTF に書き出せる要素だけで質感を作る（Principled BSDF のベースカラー、粗さ、メタリック、法線、必要ならクリアコートやシーン）。サブサーフェスのように Web に持っていけないものに見た目を頼らない。手続き的なノードの模様は、あとでテクスチャに焼き込む前提で使ってよい。肌は血色のある温かい色で、頬にほんのり赤み。

### 大きさと向き

単位はメートル。キャラクター全体の背の高さを 1.0 とし、正面のデザイン画で測った頭の大きさの割合から頭の大きさを決める。+Z が上、キャラクターは -Y を向く（Blender の正面ビューで顔が見える向き）。

## 確かめ方（ここが一番大事）

組んで終わりにせず、レンダを下絵と比べて直す、を少なくとも 3 回くり返す。毎回、見て気づいたことと直したことを `.work/toy-character/head/log.md` に書く。

1. 正面: デザイン画と同じ向きの平行投影カメラでレンダし、デザイン画の頭のあたりを切り出したものと並べた画像と、50% で重ねた画像を作る（`compare-front.png`、`overlay-front.png`）。輪郭、目の位置と大きさ、眼鏡の大きさ、前髪の線を比べる
2. 横: 同じことを横のデザイン画でやる（`compare-side.png`、`overlay-side.png`）。後頭部の丸み、髪の厚み、鼻と口の出っ張りを比べる
3. 見た目: 斜め 45 度から、やわらかいスタジオの光で EEVEE で 1024px にレンダする（`lookdev-3q.png`）。正面も同じ光で（`lookdev-front.png`）。デザイン画と並べて、おもちゃのフィギュアとしてかわいく見えるか、角ばっていないか、質感が安っぽくないかを見る
4. まばたき: `blink` を 0、0.5、1 にした 3 枚を並べる（`blink.png`）。目の突き抜け、すき間を見る

画像を並べたり重ねたりするのは ImageMagick（`magick`）を使ってよい。レンダは自分で開いて見ること。

## 最終回答

日本語で、結論から。作ったファイルの一覧、レンダのパス、くり返した回数、デザイン画とまだ合っていないところ、このやり方で全身まで進めるかについての意見（難しかったところ、質の上限の見立て）を書く。前置きと繰り返しは削る。
