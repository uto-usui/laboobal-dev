# 依頼: サバンナの中を、ずっと歩き続けるデモにする

`docs/toy-character/README.md` の続きです。作者が、サバンナ（S）の見本（`.work/toy-character/savanna/`、`README.md` に素材・配置・撮り方の記録がある）で進めると決めました。作者の言葉は「他にもいろいろ配置していいけど、リピートしてずっと歩き続けられる感じで」です。

今回は、デモ `src/demos/toy-figure/` を、キャラがサバンナをずっと前へ歩き続け、景色が後ろへ流れていく見せ方に作り替えます。今の「押した場所へ歩く、円の中を歩き回る」はやめます。

## 引き継ぐもの

- 見せ方とカメラ: 見本と同じく、正面から約 30° 横、水平より 5〜10° 上から、カメラが前進に付き添う。カメラは腰の上下には付き添わない。画面の比ごとの、キャラの大きさと位置の合わせ方も見本と同じにする（頭・手・靴が切れない。進む向きの側に地面を空ける）
- 描画: `main.ts` のトーンマッピング、RoomEnvironment、光、影、目と眼鏡の扱い。見本の塗り（8 色、つやを抑えた共通の材質、黒い輪郭線なし）
- 歩き: `walk.ts` の膝と関節の決まり（`scripts/toy-character/prompt-walk.md` の「膝と関節の決まり」）をそのまま守る。膝は 0° より逆に曲げない、体重を乗せている間は 0〜5°、運ぶ間は 40° まで。太もも 25°、腕 25°。靴底の接地の合わせ方、足の上がり、歩幅と一歩の時間（140 mm・0.34 秒）は今のものを出発点にする

## 作ること

1. **歩き続ける**: 止まらずに前へ歩く。今は一歩ごとに前進の速さがゼロまで落ちるので、歩と歩の間で速さをつなぐ。キャラは仮想の野原の中を実際に前進し、カメラがその水平の移動に付き添う（地面だけを別の速さで流す作りにはしない）。体重を乗せている足が地面の上を滑らないこと
2. **景色をくり返す**: 野原を短い区間に分け、画面の外で付け替えて、いつまでも続くようにする。区間の作りは 4 通り以上用意し、同じ並びが続けて出ないようにする。1〜2 分見ても、くり返しに気づきにくいこと。付け替えのとき、地面や影がとばない、物が急に現れたり消えたりしない（画面の外か、遠くのかすみの中で出し入れする）。進んだ距離が大きくなっても数値の精度で揺れないよう、ときどき原点を付け替える
3. **物を増やしてよい**: 作者は「いろいろ配置していい」と言っています。見本の木、草むら、岩に加えて、同じ配布元（Kenney Nature Kit など、CC0）から乾いた野原に合う物を足してよい。ただし住宅街のようにごちゃごちゃさせない。画面に入る物は 1 枚あたり 6〜12 個を目安にし、キャラが一番目立つようにする。カメラと顔の間には物を置かない
4. **見本で見つけた点を直す**:
   - 動物: 見本のシマウマは小さすぎて、砂と同じ色なので置物に見え、頭のすぐ横の地平線に乗っていた。もっと大きく、少し手前（中ほどの距離）に置き、動物らしい色に塗る。キャラの頭や体と画面の上で重ならない位置にする
   - 動物を歩かせる: シマウマとゾウ（Gobkit、`walk` のアニメーションがある）を、ときどき中ほどの距離で歩かせる。アニメーションの足の運びと進む速さを合わせ、足が地面を滑って見えないようにする。画面の外から入り、画面の外へ出ていく。いつも出ているのではなく、ときどき出る程度にする。ほかの CC0 の動物（キリンなど、歩きのアニメーション入り）を足してもよい
   - 物の足元に、地面に着いて見える影を付ける（全部に動く影を付けなくてよい。焼いた影や、足元の柔らかい丸い影でよい）
   - 地平線: 空と地面の境目が硬い一本線で、奥行きがない。遠くをかすませ、低い丘を置いて、地面が奥へ続いて見えるようにする（丘は既製モデルか、単純な板でよい）
5. **触ったときの動き**:
   - カーソルは、歩いている間も目で追う。頭と上半身の振り向きは小さくする
   - 押す（クリック、タップ）と、キャラが足をそろえて止まり、押した方向（動物を押したらその動物）を 1〜2 秒見てから、また歩き出す。止まるときと歩き出すときだけ速さを落とす・上げる
   - タップは指の移動と区別し、`touch-action: pan-y` を残す。iframe の中で縦になぞったら記事がスクロールする（`docs/demo-guide.md` の 6 章）
6. **動きを減らす設定**（`docs/demo-guide.md` の 5 章）: 歩き続ける動き、景色の流れ、動物の歩き、まばたき、呼吸の自動の動きを止め、野原に立つ一枚の絵にする。カーソルを目で追うことと、押したときに少し見ることは残す。設定を途中で変えたら、その場で切り替わる
7. **画面の外では止める**: デモが画面の外にあるときやタブが隠れているときは、描画と歩きを止め、戻ったら続きから歩く（すでに共通の仕組みがあればそれに従う）
8. **meta**: `interaction`、`description`、`tags` を `docs/demo-guide.md` の決まりに合わせて直す。slug と title は変えない（title はあとで作者と決める）。素材は CC0 で必須ではないが、`credits` に配布元（Kenney Nature Kit、Gobkit Animal Pack など）を `{ label, url }` で入れる
9. **素材の置き場所**: 使う景色と動物の GLB は meshopt で圧縮して `src/demos/toy-figure/assets/` に置く。景色と動物を合わせて 2 MiB 以内。キャラの GLB（`character.glb`）は変えない

## 確かめること（画像と動画は自分で開いて見ること）

`.work/toy-character/savanna-walk/` に出力する。開発サーバーは http://localhost:4410 （URL の末尾の `/` が要る。止めない）。Playwright は Chrome（`channel: 'chrome'`、GPU）。

- `desktop.webm`（1440×900、dpr 2）と `mobile.webm`（390×844、dpr 3）: 開いてから 60 秒以上、歩き続けるところ。途中で 1 回、押して止まり、見て、また歩き出すところを入れる。各動画から 2 秒ごとのコマを並べた `desktop-strip.png`、`mobile-strip.png`
- 3 分歩かせたときの記録: 膝の角度の最小・最大（毎フレーム。最小が 0 未満なら不合格）、体重を乗せている足の地面に対する滑り（mm）の最大、区間の付け替えの回数、同じ区間の作りが続けて出た回数、動物が出た回数、JS のヒープの大きさの初めと終わり
- 歩の境目と区間の付け替えのときに、カメラと景色がガクッと動かないこと（カメラの位置の、フレームごとの変化の最大と、その中央値との比）
- 速さ: 1440×900 と 390×844（CPU throttling 4 倍）で、歩いている 10 秒間のフレーム時間の中央値と P95
- 動きを減らす設定で、一枚の絵になること（`reduced.png`）と、押すと少し見ること
- `pnpm verify` を通す（`.work/toy-character/walk/chrome.config.ts` を使ってよい）。`e2e/toy-figure.spec.ts` を今の動きに合わせて直す（歩き続けること、押すと止まって見ること、動きを減らす設定で止まること、縦になぞるとスクロールすること）
- 景色と動物の GLB の大きさ

## 決まり

前提が曖昧なところは妥当な仮定を置いて最後まで進め、置いた仮定は最終回答に書いてください。書き込むのは `src/demos/toy-figure/`、`e2e/toy-figure.spec.ts`（必要なら `e2e/motion.spec.ts`）、`scripts/toy-character/`、`.work/toy-character/` の中だけ。`src/shared/` は変えない。形を数値で新しく作らない（平らな地面、空のグラデーション、遠景の単純な板、丸い影の板はよい）。実在の場所や、既存のゲーム・映画・アニメの見た目をまねない。ブラウザの MCP は使わず、撮影は Playwright のスクリプトで行う。コミットはしない。コードのコメントは、その行を見ただけでは分からない理由だけを短く書く。

## 最終回答

日本語で、結論から。歩き続ける作り方（速さのつなぎ方、カメラの付き添い方、原点の付け替え）、区間の作りと付け替え方、足した物と動物とその出し方、見本から直した点、押したときの動き、動きを減らす設定、3 分の記録の値、速さ、GLB の大きさ、`pnpm verify` の結果、まだ足りないところ、置いた仮定。前置きと繰り返しは削る。
