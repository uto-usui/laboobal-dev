# 依頼: B の髪の穴を塞いで焼き直す

`docs/toy-character/README.md` の工程 7 の続きです。`--stage hair3`（記録は `.work/toy-character/hair3/log.md`）で内側のキャップを外すと、前髪の上のすき間から髪の裏と肌の裏が見え、35° の外縁と後頭部の小穴から背景が見えました。B の髪は境界辺が 1,816 本ある、開いた面でした。

見立て: B は、頭全体を詰めた閉じた面から、元の面のラベルが髪の部分だけを取り出して作った。元の頭は薄い殻で、髪の下の頭皮は顔のラベル（0）になっている。そのため、毛束のすき間の上を通る面のうち、最も近い元の面が頭皮だった所が顔として外され、穴になった。

1. 見立てを確かめる: 穴のふちの近くで外された面について、最も近い元の面のラベルと、その面が外から見えるか（26 方向）を数えて書く
2. B の髪の境界の輪を、ふちの長さと場所で分ける。顔との境目（生え際、もみあげ、えり足）と首元の輪は残し、それ以外の輪（髪の面の中の穴）は、輪のふちだけで塞ぐ面で閉じる（頂点を新しく置かない）。塞いだ輪の数と、残した輪の場所を書く
3. 髪の UV を作り直し、工程 7 と同じ方法で髪の色・法線・粗さを焼き直す（キャップは使わない）

前提が曖昧なところは妥当な仮定を置いて最後まで進め、置いた仮定は最終回答に書いてください。書き込むのは `scripts/toy-character/` と `.work/toy-character/` の中だけ。コミットはしないでください。`build.py` に段 `hair4` として足し、`.work/toy-character/hair4/` に出力してください。

`hair3` と同じ値（髪の中の肌色の画素、色の差の平均、頭の輪郭 IoU、黒い斑点の画素数）と、髪の境界辺の数を、`hair2`・`hair3` と並べて `metrics.json` に書き、`hair-compare.png`、`demo-color.png`、`hair-under.png` を出して開いて見てください。全体の三角形数も書いてください。

最終回答は日本語で、結論から。見立てが合っていたか、塞いだ輪と残した輪、値の比較、残った斑点や穴の場所、置いた仮定。前置きと繰り返しは削る。
