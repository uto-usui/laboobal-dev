## これから作るもの

- three.js（0.187）で読む GLB。SkinnedMesh。マウスに頭と目と上半身が追従し、まばたきし、呼吸で揺れ、クリックでピースをする（腕と指 2 本が曲がる）
- 頭・髪・眼鏡は頭のボーンに固定で、曲がらない。曲がるのは首、背骨、肩、肘、手首、人差し指と中指。脚はほぼ動かさない
- 目は、生成メッシュの目のくぼみに、Blender で作った眼球とまぶた（まぶたは別の部品で、シェイプキーで閉じる）をはめ込む。眼鏡も別の部品で作る
- 顔はデザイン画のかわいさに寄せるため、鼻を小さくするなど形を少し直す
- 作業者は LLM だけ。Blender は `blender -b -P` のスクリプトで動かす。無料のツールだけ。Mac（Apple M5 Max、メモリ 128GB、NVIDIA GPU なし）

## 調べて決めてほしいこと

1. 面の落とし方。少なくとも次を比べ、このキャラクターに 1 本を選ぶ。
   - Blender の Decimate（Collapse）
   - QuadriFlow、Voxel Remesh と組み合わせる方法
   - Instant Meshes（CLI）
   - pymeshlab の Quadric Edge Collapse（テクスチャ付きで UV を保つもの）と Isotropic Remeshing
   - AI でリトポロジーするオープンなもの（MeshAnything V2、DeepMesh、FastMesh、QuadGPT など、2026 年の新しいものも含む）
   - 有料のもの（Quad Remesher、ZRemesher）は使わないが、定石を知るための比較には入れてよい

   比べる観点は次のとおり。
   - 曲がる関節（肩・肘・指・首）での変形の質
   - 顔の形をどれだけ保つか
   - 100 万三角形の入力を扱えるか
   - スクリプトから動かせるか
   - Mac で動くか
   - ライセンス
2. ボーンで動かす今回の範囲で、四角形の面の流れ（エッジループ）が要るのか、三角形のままでよいのか。要るなら、どの部位だけ要るか
3. 落とす前に部品を分けるべきか（髪、頭と顔、体と服、リュック、手）。分けるならどう切るか。くっついた塊のまま進めた場合の問題（ウェイトのにじみ、髪と顔の境目など）
4. 色と凹凸の移し方。高いメッシュから低いメッシュへ、ベースカラーと法線を焼き込む手順（Cycles の Selected to Active、cage や extrusion の決め方、UV の作り方とパッキング、継ぎ目のにじみ止め）。UV を保ったまま落とせる方法なら焼き込みを省けるか、その損得
5. 目のくぼみに眼球とまぶたをはめ込むときの、低いメッシュ側の作り方（くぼみの縁のループ、穴を開けるか、どの順番でやるか）
6. Web 向けの予算。three.js でこの役のキャラクター 1 体に妥当な三角形数（体全体、顔、手の配分）、テクスチャの大きさと枚数、GLB の大きさ、Meshopt や KTX2 の使い方
7. 出来の測り方。LLM が数値と画像で判断できる基準。例: 高いメッシュとの距離（Hausdorff など、どの道具で測るか）、輪郭の比較、法線マップの破綻の見つけ方、関節を曲げたポーズのレンダ
