# 依頼: 恐竜のいる野原にして、カメラを引く

`docs/toy-character/README.md` の続きです。今のデモ `src/demos/toy-figure/` は、キャラがサバンナをずっと歩き続けます（`scripts/toy-character/prompt-savanna-walk.md`〜`prompt-savanna-walk3.md`、記録は `.work/toy-character/savanna-walk3/`）。作者がこれを見て、次のように決めました。

- 動物を、Quaternius の Animated Dinosaur Pack の恐竜 6 体（T-Rex、Velociraptor、Triceratops、Parasaurolophus、Stegosaurus、Apatosaurus）に替える。https://quaternius.com/packs/animateddinosaurs.html （CC0、歩きなどのアニメーション入り。配布は FBX・OBJ・Blend）
- 恐竜に合う植物も手に入れて、景色を作り直す。今の Kenney の角ばった傘の木は、キャラにも恐竜にも合わない
- 今の画角はキャラに寄りすぎて、キャラ以外の物が画面に入りにくい。カメラをもっと引く

歩き（一歩 140 mm・0.34 秒、足の上がり、膝と太ももの決まり、支える足が滑らないこと）、歩き続けること、区間の付け替え、原点の付け替え、押すと止まって見ること、動きを減らす設定、画面の外での停止は、今のものをそのまま守ってください。

## 1. 素材

- 恐竜: 上の 6 体を公式の配布元から落とす。three.js で読める GLB に変え（Blender はコマンドラインの `blender` で使ってよい）、歩きと待機のアニメーションを残す。襲う、吠えるなどのアニメーションは使わない
- 植物: 恐竜と同じ作者（Quaternius）の CC0 のパックから選ぶのを第一にする（候補: Ultimate Nature、Stylized Nature MegaKit、Ultimate Stylized Nature、Simple Nature。https://quaternius.com/ から探す）。シダ、ソテツやヤシのような木、背の低い草、岩など、恐竜のいる野原らしいもの。形が丸みを帯びていて、恐竜と並べて違和感がないものを選ぶ
- 配布ファイル、ライセンス、配布ページの控え、SHA-256 を `.work/toy-character/dino/vendor/` に残し、部品ごとの三角形数・材質数・画像・骨・アニメーション名・GLB の大きさを `.work/toy-character/dino/assets.json` に書く
- シマウマとゾウ、Kenney の木と草は使わなくなるので外す（ファイルも `src/demos/toy-figure/assets/` から消す）
- 塗り: 今までどおり、キャラより一段おとなしい、つやを抑えた少ない色にそろえる。恐竜も、植物と地面になじむ落ち着いた色に塗り直してよい。キャラが一番目立つこと。黒い輪郭線は付けない

## 2. カメラを引く

- キャラの見た目の高さを、今（横長で画面の高さの約 60%、縦長で約 50%）から、横長で約 35〜40%、縦長で約 30〜35% にする。これで恐竜と植物が画面に入る場所を作る。顔は小さくなるが、目と眼鏡が分かる大きさは残す（800×500 でも顔が潰れないこと）
- カメラの横の角度は、30°（今）と 50° の 2 つで作り、開発のときだけ URL の引数（たとえば `?view=50`）で切り替えられるようにする。作者が動画を見て選ぶ。本番の初期値は 30°
- どちらの角度でも、植物と恐竜がキャラの頭と体に画面の上で重ならないこと。木を消したり隠したりして避けるのでなく、置く場所で避ける（前の直しで、重なりを避けるために木が画面からほぼ消えたことがある。木が画面にいつも入っていることも条件にする）

## 3. 景色と恐竜の出し方

- 画面に入る物は、横長で 8〜15 個、縦長で 5〜10 個を目安にする。手前の小さな草やシダは、点に見えない大きさにする
- 恐竜は、ときどき中ほどから遠くを歩いて通る。いつも 1 頭は見えている必要はないが、20 秒に 1 回以上は出てくる。同じ恐竜が続けて出ないようにする。大きさの順（Apatosaurus がいちばん大きく、Velociraptor が小さい）は保つ。大きい恐竜は遠くを通し、キャラより手前は通さない
- 恐竜の歩きのアニメーションの足の運びと進む速さを合わせ、足が地面を滑って見えないこと
- 押したときは、今と同じく止まって押した方向（恐竜を押したらその恐竜）を見る

## 確かめること（画像と動画は自分で開いて見ること）

`.work/toy-character/dino/` に出力する。開発サーバーは http://localhost:4410 （URL の末尾の `/` が要る。止めない）。Playwright は Chrome（`channel: 'chrome'`、GPU）。

- `stills.png`: 30° と 50° のそれぞれで、1440×900（dpr 2）、800×500（dpr 2）、390×844（dpr 3）の静止画を並べたもの
- `desktop-30.webm`、`desktop-50.webm`（1440×900、dpr 2）、`mobile-30.webm`、`mobile-50.webm`（390×844、dpr 3）: 60 秒以上歩き続け、途中で 1 回押して止まり、見て、また歩き出す。それぞれ 2 秒ごとのコマを並べた strip
- `legs-desktop.png`: 歩いている途中の 0.7 秒を 1/12 秒ごとに、キャラの腰から下を切り出して並べたもの（引いたあとも足の開きと上がりが見えること）
- 3 分の記録（30° と 50° の両方）: 膝の最小・最大、太ももの前後の最大、支える足の滑り、区間の付け替えと同じ区間の連続、恐竜の出た回数と種類、恐竜の足の滑り、画面に入っている木と物の数（最小・中央値）、頭と体に物が重なった回数、ヒープの初めと終わり
- 速さ: 1440×900 と 390×844（CPU throttling 4 倍）で、10 秒間のフレーム時間の中央値と P95
- 景色と恐竜の GLB の大きさ（合わせて 2 MiB 以内。超えるときは、どれが重いかと減らし方を書く）
- `pnpm verify` を通す（`.work/toy-character/walk/chrome.config.ts` を使ってよい）。`e2e/toy-figure.spec.ts` を今の動きに合わせる
- `meta.ts` の `description` と `credits`（Quaternius の配布ページ）を直す。slug と title は変えない

## 決まり

前提が曖昧なところは妥当な仮定を置いて最後まで進め、置いた仮定は最終回答に書いてください。書き込むのは `src/demos/toy-figure/`、`e2e/toy-figure.spec.ts`、`scripts/toy-character/`、`.work/toy-character/` の中だけ。`src/shared/` とキャラの GLB は変えない。形を数値で新しく作らない（平らな地面、空のグラデーション、遠景の単純な板、丸い影の板はよい）。既存の映画やゲームの恐竜の見た目や場面をまねない。ブラウザの MCP は使わず、撮影は Playwright のスクリプトで行う。コミットはしない。コードのコメントは、その行を見ただけでは分からない理由だけを短く書く。

## 最終回答

日本語で、結論から。選んだ植物とパック、恐竜の変換とアニメーション、塗り、カメラの引き方と 30° と 50° の見え方の違い（どちらを推すか）、恐竜の出し方、3 分の記録の値、速さ、GLB の大きさ、`pnpm verify` の結果、まだ足りないところ、置いた仮定。前置きと繰り返しは削る。
