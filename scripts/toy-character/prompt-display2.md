# 依頼: きれいな面のデモの仕上げ（首の帯、髪の下端、ファイルの大きさ）

`--stage display`（記録は `.work/toy-character/display/README.md` と `log.md`）で、生成したままの面を骨で動かすデモができました。40 万三角形の段を採り、見た目は良いですが、次の 3 つが残っています。形を数値で作ることはしません。

1. **首の前の帯**: 立ち姿から、襟の上に約 90×12 mm の段のような帯が見える（`display/neck-rest-annotated.png`）。体の元の首の肌の切り口のふちが、頭の首元の外に出ていると見ている。まず、帯がどの部品のどの面か（体の首の肌か、頭の首元か、ふちの閉じ方か）を確かめて書く。体の首の肌の、頭の首元より外に出ている部分だけを、頭の首元の中に収まる高さで切って除く（切り口は襟と頭の首元に隠れる位置にする）。首のポーズ（左右 25°、上下 10°、組み合わせ）で、すき間や段が見えないことを、デモの画角と首の拡大で確かめる
2. **髪の下端の破片**: 髪の下端に薄い破片が見える。外から見える小さな連結成分や、細い面の切れ端のうち、髪の輪郭から離れて浮いているものを数えて除く。髪の輪郭そのものは削らない。デモの画角と、首上 10° の拡大で確かめる
3. **ファイルの大きさ**: GLB が 18.43 MiB で、目安の 15 MiB を超えている。色と粗さの画像（今は元の 4096 px）を、見た目の差が目で分からない範囲で小さくする（2048 px と 3072 px を比べる。顔は細かさを保つ）。KTX-Software の `toktx` は入っていないので、今回も WebP にする。メッシュは 40 万段のまま

前提が曖昧なところは妥当な仮定を置いて最後まで進め、置いた仮定は最終回答に書いてください。書き込むのは `scripts/toy-character/`、`.work/toy-character/`、`src/demos/toy-figure/` の中だけ。コミットはしないでください。`build.py` に段 `display2` として足し、`.work/toy-character/display2/` に出力してください。

## 確かめること

`display` と同じ Web の撮り方で、`web-desktop.png`（全身と、顔・首・胴の拡大）、`web-follow.png`、`web-neck.png`（首の 5 つのポーズの拡大）を撮り、`display` の画像と並べて開いて見る。GLB の大きさ、glTF Validator の結果、デスクトップとスマホ相当のフレーム時間と初描画を `metrics.json` に書く。`src/demos/toy-figure/assets/character.glb` を置き換え、`pnpm verify` を通す。

## 最終回答

日本語で、結論から。帯の正体と直し方、除いた破片の数、画像の大きさと GLB の大きさ、見た目の差、速さ、`pnpm verify` の結果、まだ足りないところ、置いた仮定。前置きと繰り返しは削る。
