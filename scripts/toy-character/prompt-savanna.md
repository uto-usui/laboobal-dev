# 依頼: 住宅街をやめ、物の少ない乾いた野原（サバンナ・砂漠寄り）の静止見本を作る

`scripts/toy-character/prompt-city2.md` で作った街角の見本（`.work/toy-character/city/`）を作者に見せたところ、方向を変えることになりました。作者の言葉は「住宅街はごちゃごちゃしている。サバンナや砂漠のような、物の点数を下げた場所がいい。住宅街より、動物が出てくるような環境を歩かせたい」です。

見せ方（斜め前から一緒に進み、景色が後ろへ流れる）、カメラ（正面から約 30° 横、水平より 5〜10° 上）、キャラの立たせ方、描画の設定、撮り方は `.work/toy-character/city/` の見本をそのまま引き継いでください（`index.html`、`scene.js`、`walk-snapshot.js`、`tooling/`、`README.md` に撮影と測定の手順がある）。変えるのは、キャラのまわりに置く場所と物です。歩かせる処理とデモのページはまだ変えません。

## 場所の考え方

- 地面が広く見える、平らで乾いた野原。遠くに低い丘か地平線、空は単色かゆるいグラデーション
- 物の点数を大きく下げる。画面に入る物は、目安として 1 枚あたり 4〜8 個（木、岩、草むら、動物を合わせて）。何もない地面の広さで「ひらけた場所を歩いている」と分かるようにする
- 動物が出てくる場所にする。見本では、少し離れたところに動物を 1〜2 頭置く（キリン、ゾウ、シマウマ、ラクダなど乾いた場所の動物。手に入る素材で決めてよい）。キャラの顔と体にかぶらない位置に置く
- キャラより一段おとなしい塗りにして、キャラが目立つようにする。地面、草、岩、木、動物を 6〜8 色程度に絞り、つやを抑えた共通の材質にする。黒い輪郭線は付けない

次の 2 通りを作る。

- **S（サバンナ）**: 枯れ草色の地面、傘のような形の木を 1〜2 本、低い草むら、岩、遠くの動物
- **D（砂漠）**: 砂色の地面、岩、サボテンか枯れ木を少し、遠くの動物（ラクダなど）

## 素材

無料で配られている既製モデルを拾い、塗りを変えて使う。形を数値で新しく作らない（平らな地面の板、空のグラデーション、遠景の単純な丘の板はよい）。

- ライセンスは CC0 を優先する。CC0 で見つからないものだけ CC-BY を使ってよい（その場合は作者名とクレジットの書き方を記録する）。それ以外のライセンス、出所が分からないものは使わない
- 候補は自分で調べて選ぶ。たとえば Kenney（Nature Kit、Desert 系など）、Quaternius（動物のパック、Stylized Nature MegaKit など）、Poly Pizza の CC0 の単品。動物は、骨と歩きのアニメーションが入っているものを優先する（あとで景色の中を歩かせたいので）。入っているかどうかと、アニメーションの名前を記録する
- 公式の配布元から落とし、`.work/toy-character/savanna/vendor/` に、元のファイルとライセンスの文書、配布ページの控え、SHA-256 を残す
- 選んだ部品ごとに、三角形数、材質数、画像の有無と大きさ、骨の数、アニメーションの有無、GLB の大きさを `assets.json` に書く
- 実在の場所や、既存のゲーム・映画・アニメの見た目をまねない

## 撮ること（画像は自分で開いて見ること）

`.work/toy-character/savanna/` に出力する。開発サーバー http://localhost:4410 は止めない。見本ページは静かなサーバーを空いているポートで立てて開いてよい。Playwright は Chrome（`channel: 'chrome'`、GPU）。

- `savanna-S.png`、`savanna-D.png`: 1440×900（dpr 2）、800×500（dpr 2）、390×844（dpr 3）を横に並べたもの。どれも頭・手・靴が切れず、顔の前に物がないこと
- `compare.png`: 1440×900 の S と D を並べたもの。参考に、前回の街角 B（`.work/toy-character/city/shots/B-desktop.png`）も同じ大きさで並べて 3 枚にする
- 画面に入っている物の数（1440×900 と 390×844 で）
- 使った部品をまとめた GLB の大きさ（meshopt で圧縮したとき）。目標は景色全体で 2 MiB 以内。動物は 1 頭ごとに別に書く
- 1440×900 と 390×844（CPU throttling 4 倍）での、5 秒間のフレーム時間の中央値と P95

## 決まり

前提が曖昧なところは妥当な仮定を置いて最後まで進め、置いた仮定は最終回答に書いてください。書き込むのは `.work/toy-character/` と `scripts/toy-character/` の中だけ。コミットはしない。ブラウザの MCP は使わず、撮影は Playwright のスクリプトで行う。

## 最終回答

日本語で、結論から。選んだ素材とライセンス（動物のアニメーションの有無を含む）、S と D の見た目の違い（キャラが目立つか、ひらけた場所に見えるか、物の少なさ）、どちらを推すか、大きさ、速さ、まだ足りないところ、置いた仮定。前置きと繰り返しは削る。
