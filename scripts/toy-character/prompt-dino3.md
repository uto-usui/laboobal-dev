## 1. 四足の恐竜の前足

作者が動画を見て「後ろ足はいい感じだが、四足歩行の恐竜の前足の動きにすごく違和感がある」と言っています。Triceratops、Stegosaurus、Apatosaurus の前足が、棒のようにまっすぐ伸びたまま大きく振れて見えます。

呼び出し側で見当を付けた原因は次のとおりです。確かめてから直してください。

- `dinosaurs.ts` は、接地している足をその場に留めるために、前足にも二関節の IK（`FrontUpLeg`→`FrontLowLeg`→`FrontFoot`）をかけている
- 体の進み方は後ろ足の後退量で決めている。元の Walk の前足の後退量が後ろ足より小さいため、留めた前足が引き伸ばされ、腕の長さの上限（`l1 + l2`）に当たってまっすぐになっている。接地が外れると元の姿勢へ戻るので、そこで跳ねても見える
- 曲げる向きを今の肘の位置から決めているため、伸び切ったあとに逆へ曲がる瞬間があるかもしれない

まず確かめること:

- 四足の 3 体（と、前足が地面に着くなら Parasaurolophus）について、横から寄って撮った一歩のくり返しを 1/12 秒ごとに並べる。(a) 元の Walk をそのまま再生したもの、(b) 今の実装、の 2 段。`front-legs-before.png` に置き、自分で見て、違和感の原因を数字（前足と後ろ足の接地中の後退量、前足の伸び率 `距離 / (l1 + l2)` の最大、肘の曲がる向き）で書く

直し方:

- 前足は元の Walk の形（肘や手首の曲がり、足の上がり）を保つことを第一にする。まっすぐな棒に見えない、跳ねない、逆に曲がらない
- 前足と後ろ足の歩幅を合わせる。たとえば、前足の振りの大きさを接地中の後退量が後ろ足と合うまで広げる（`FrontUpLeg` の回転を大きくする、前足の時間の流れだけを少し伸び縮みさせる）。IK に頼る場合は、補正の強さを接地の始めと終わりでなめらかに増減させ、伸び率は 0.95 以下に抑え、曲がる向きは元のアニメーションの肘の向きに固定する
- 前足がわずかに滑るのは、前足が棒に見えるよりずっとよい。前足の接地中の滑りは、画面の上で目立たない大きさ（1440×900 で 2 px 以内を目安）まで許す。後ろ足の滑りは今までどおり小さく保つ
- T-Rex と Velociraptor の前足（腕）は地面に着かないので、元の Walk のまま触らない
- 大型の恐竜の歩調（0.65 倍、Apatosaurus は 0.5 倍）が遅すぎて、前足の振りが重く見えていないかも見る。変えるなら理由を書く

直したあと、同じ撮り方の `front-legs-after.png` を作り、before と並べて見比べる。

## 2. 野原にサバンナらしさを足す

作者の言葉: 「サバンナ感はこのフィールドで出してもいいかもしれない。今のクリーム緑のようなニュアンスもいいと思う」。今の淡いクリーム緑の地面の色合いは残し、そこに乾いた野原の感じを少し足します。凝りすぎないこと。

- 地面: クリーム緑を基調のまま、乾いた草の黄土色・麦わら色の部分と、土の見える部分を、今より分かる濃さで大きくゆるく入れる。今の色むらは薄すぎて、動画ではほとんど見えません。1440×900 の静止画で、色むらがあると一目で分かる程度にする。キャラの足元の影は見えにくくしない
- 草: 今の草の一部を、乾いた麦わら色の背の低い草むら（Quaternius の草の色を変えたものでよい）にし、緑の草と混ぜる。ところどころに乾いた草が集まった帯を作る
- 中ほどの距離: 横長では、地平線とキャラのあいだがまだ空いています。ヤシ、茂み、岩、乾いた草むらを中ほどの距離にも置く（頭と体に重ねないことは置く場所で避ける）。縦長は今の置き方がちょうどよいので、大きく変えない
- 空: 白っぽい灰色に、ほんの少し青みと明るさを足す。地平線の近くは今のように淡くなじませる

## 3. 恐竜の頭が画面の上で切れる

縦長の T-Rex（2〜6 秒）と、横長の Apatosaurus の首（84〜92 秒）が、歩いている途中で画面の上の端に切られています。画面の左右の端から入ってくるときに一部が切れるのはかまいませんが、画面に入りきったあとは頭まで見えるようにする（歩く奥行きを少し広げる、首を上げる姿勢の瞬間でも入るようにするなど）。恐竜の大きさは変えない。
