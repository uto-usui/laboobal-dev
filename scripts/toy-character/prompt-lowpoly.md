# 依頼: 体と頭をつなぎ、Web 用に面を落とす（工程 6）

`docs/toy-character/README.md` の工程 6 です。方法は `docs/toy-character/mesh-method.md` に決めてあるので、その 1、3、4、5 章に従ってください（2 章の顔の修正は、頭を別に生成したので行いません）。ほかの方法を試して比べる必要はありません。UV、焼き込み、色の投影、眼球とまぶた、ボーンは次の工程なので、ここではやりません。

前提が曖昧なところは妥当な仮定を置いて最後まで進め、置いた仮定は最終回答に書いてください。書き込むのは `scripts/toy-character/` と `.work/toy-character/` の中だけ。コミットはしないでください。Blender の処理は `scripts/toy-character/build.py` の段として足し（今ある段は残す）、`.work/toy-character/lowpoly/` に出力してください。

## 入力

- 体: 全高 1m にそろえた体（`.work/toy-character/fidelity/body-normalized.blend`）と、部位のラベル（`prepare` 段）、関節の設計図（`.work/toy-character/prepare/landmarks.json`。全高 0.889 のときの値なので換算する）
- 頭: seed 42 の頭に髪のキャップを足し、位置と大きさをデザイン画に合わせたもの（`fidelity` の段の出力）。残りのずれを寄せる変形（Laplacian）をかけたものは使わない。位置と大きさを合わせただけのものを使う
- 決めたこと: README の「決めたこと」の表。とくに、手は 5 本指を作り直す、頭・髪・眼鏡は頭のボーンに固定、ピースには 5 本の指すべてが曲がる必要がある

## やること

1. 体の頭を外し、新しい頭を首でつなぐ。首は mesh-method.md 4 章の首の仕様（周方向 24〜32、長さ方向 5〜7 リング）で作り直し、頭の側と体の側の境目を面でつなぐ。襟に隠れる位置でつなぐ
2. 固定する部分（頭・顔・髪、脚と靴、リュック本体）を Collapse で減らす（3 章、部位ごとの三角形の配分表のとおり）
3. 曲がる部分（首・胴・肩・肘・手首）にリングを設計して張り、元の形に沿わせる（4 章）
4. 手は生成のものを使わず作り直す。おもちゃ風の丸みのある子どもの手で、5 本の指が分かれ、各関節の前・中心・後ろにリングがある（4 章の指の仕様）。大きさと向きは元の手と関節の設計図に合わせ、袖口の下でつなぐ。正面のデザイン画の手の形（開いて力を抜いた手）に似せる
5. 目の開口を作る（5 章）。デザイン画で測った目の開口の位置と大きさ（`.work/toy-character/fidelity/design-landmarks.json`）に合わせる。眼球はまだ入れないが、開口の奥に壁を作り、頭の内側が見えないようにする
6. 全体の三角形数を約 5 万（上限 6 万）にする。三角形化は確定する

## 確かめること（レンダは自分で開いて見ること）

mesh-method.md の「合格の基準」のうち、この工程で測れるものを測り、`.work/toy-character/lowpoly/metrics.json` に書く。

- 部位ごとの三角形数と合計
- 高密度メッシュとの距離（両方向、P95 と最大）。意図して変えたところ（首、手、目の開口）は分けて扱う
- 8 方向の輪郭の IoU と輪郭距離
- 接続（意図した開口以外の境界、3 面以上で共有する辺、退化面、重複面）

画像:
- `lowpoly-views.png`: 高密度と低密度を並べた 4 方向（色付き）
- `wire.png`: 低密度のワイヤーフレームを、正面・横と、首・肩・肘・手・顔の拡大で
- `hands.png`: 作り直した手を、手のひら・甲・横から。元の手とデザイン画の手も並べる
- `face-opening.png`: 目の開口のまわりの拡大（正面と斜め）

手順と気づいたことは `.work/toy-character/lowpoly/log.md` に書く。

## 最終回答

日本語で、結論から。部位ごとの三角形数、基準の各項目の値と合否、作り直した手と首と目の開口の様子、まだ足りないところ、置いた仮定。前置きと繰り返しは削る。
