# 依頼: 工程 6 の 8 回目（首の骨の軸、ラベルの漏れ、首とリュックのウェイトを直す）

`docs/toy-character/README.md` の工程 6 の 8 回目です。7 回目（`--stage lowpoly7`、記録は `.work/toy-character/lowpoly7/log.md`、ファイルは `character-lowpoly7.blend`）をもとに、次の 4 点だけを直します。中身の詰め方、脇の切り離し、均一な面（QuadriFlow と Shrinkwrap）、部位で制限したウェイトは 7 回目のまま使います。

## 確かめた原因（`character-lowpoly7.blend` を調べた結果）

1. **首の骨の軸が首を通っていない**: `neck` の骨は x = 0、y = 0.007〜0.010 m を通るが、頭の首元の断面（z = 0.690 m）の中心は x = 0.013、y = −0.013 m で、約 2.6 cm ずれている。首を回すと頭の首元が横に振れ、襟に当たる
2. **首の伸びは、体の首の切り口の高さ（691 mm）に集まっている**: 襟の上端は 700.6 mm なので、横と後ろでは切り口が襟の内側につながっている。切り口を head、襟を胸にしたので、その境目が裂けた
3. **袖のラベルが胴の側面に少し漏れている**: 袖ラベルの面のうち、腕の骨（upper_arm・forearm・hand）から 7 cm 以上離れた面が右 4 枚（x ≈ −0.12〜−0.13 m、z = 0.398〜0.492 m）、左 1 枚（x = 0.121 m、z = 0.477 m）あった。右腕を上げたときの最大の伸び 51.9 倍（右袖・胴、z = 396〜402 mm）は、この場所と一致する。脇より下で、腕と腕以外の頂点を両方持つ面は 0 で、脇の切り離しは残っていた
4. **リュックを胸の骨に固定していた**: 背骨を前に曲げたときの最大の伸びは、リュックと胴の境目（z = 422 mm）だった

## やること（方法は決めてあるので、ほかの方法を試して比べる必要はありません）

前提が曖昧なところは妥当な仮定を置いて最後まで進め、置いた仮定は最終回答に書いてください。書き込むのは `scripts/toy-character/` と `.work/toy-character/` の中だけ。コミットはしないでください。`build.py` に新しい段 `lowpoly8` として足し（今ある段は残す）、`.work/toy-character/lowpoly8/` に出力してください。`log.md` は段ごとに書き足してください。頂点の位置を数値で書いて形を作ることはしません。

1. **ラベルを直す**（中身を詰める前）: 元のメッシュの袖・手のラベルの面のうち、同じ側の腕の骨から 7 cm 以上離れた面を、隣り合う面で最も多い腕以外のラベルに付け替える。付け替えた面の数と場所を書く。そのあとの中身の詰め方と脇の切り離しは 7 回目と同じ
2. **首の骨を首に通す**: 頭（位置と大きさを合わせただけのもの）の首元の断面の中心を、z = 0.670〜0.700 m で 5 mm おきに測り、`neck` の骨をその中心を通る向きに置き直す。`head` の骨は `neck` の先から続ける。測った中心を書く
3. **首は頭だけを回す**
   - 体の首の肌と襟は、すべて `spine.chest` に 1.0 にする（体の側は首のポーズで変形しない）
   - 頭は、元の下端（668.6 mm）で切り直し、首元をできるだけ長く体の首の中へ残す。減らし方は 3 回目と同じ（約 9,000 三角形、顔の保護）。頭は `head` に 1.0
   - 首の左右回転と上下の傾きを 5° おきに 0〜30°（左右）、0〜20°（上下）で作り、それぞれで次を測る: つなぎ目のすき間（頭の首元と体の首の、外から見える開き）、頭の首元が体の首から外へ突き出す量、髪やあごが襟・肩・肩ベルトに食い込む深さ。半径を比べるときは、両方の面と交わる向きだけを使う
   - すき間が外から見えず、食い込みが 2 mm 以下に収まる角度の範囲を「首の動きの範囲」として書く
   - 立ち姿で、前の開きにつなぎ目の段が見える場合だけ、前の開きに見える首の肌に `head` を混ぜる。混ぜる量は、襟との境目からの距離に沿って 0 から増やす（高さに沿わせない）
4. **リュックのウェイト**: リュック本体は、真下の胴の面から Data Transfer で写す（肩ベルトと同じ）
5. **腕を体へ 10° 寄せるポーズは外す**（立ち姿の角度が元の角度なので）
6. **脇の切り離しを面で確かめる**: QuadriFlow の直後と Shrinkwrap の直後の両方で、脇より下で腕の頂点と腕以外の頂点を両方持つ面を数える。0 でなければ、Shrinkwrap の沿わせる相手を腕と腕以外で分ける

ポーズ・レンダ・測定は 7 回目と同じ。背骨だけのためのウェイトの調整は足さない。

## 確かめること（レンダは自分で開いて見ること）

`metrics.json` に 7 回目と同じ項目と、次を書く。

- 付け替えた面の数と場所
- 首元の断面の中心と、置き直した骨
- 首の角度ごとの、すき間・突き出し・食い込み、決めた首の動きの範囲
- 脇より下の、腕と腕以外をまたぐ面の数（QuadriFlow の直後、Shrinkwrap の直後）
- すべてのポーズの、体全体と関節のまわりごとの裏返り・2 倍超の辺の割合・最大の伸びと、その場所（部位と高さ）

画像は 7 回目と同じものに加えて、`neck-range.png`（首の角度ごとの、正面・斜め・横の拡大を並べたもの）。

## 合否の決め方

- 首: 決めた動きの範囲が、左右 20° 以上、上下 10° 以上あること。その範囲の中で、すき間が見えず、食い込みが 2 mm 以下
- 腕（左右とも前上へ 70° 上げて肘 90°）、背骨（左右 15°、前 15°）、断面、形、輪郭: 7 回目と同じ基準
- 崩れる関節があれば、崩れ方を画像と数値で残して不合格として報告する

## 最終回答

日本語で、結論から。付け替えたラベル、首の骨の位置、首の動きの範囲と角度ごとの値、腕と背骨のポーズの数値と最大の伸びの場所、断面・形・輪郭の値と合否、まだ足りないところ、置いた仮定。前置きと繰り返しは削る。
