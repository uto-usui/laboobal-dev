# 依頼: 髪の内側のキャップを外す

`docs/toy-character/README.md` の工程 7 の続きです。`--stage hair2` の調べ（`.work/toy-character/hair2/log.md`）で、黒い斑点 32,123 画素のうち 24,511 画素は、前の髪のために入れた内側のキャップ（`Baked inner hair cap`）が、B の髪の面より手前に突き出して見えていたものだと分かりました。B の髪は詰めた面から作った閉じた面で、頭皮を覆っているので、キャップは要らないはずです。

1. 内側のキャップの面を外す（低密度の頭から消す）。ほかの面・UV・焼いた画像は変えない
2. キャップを外して、髪の下や生え際から頭の中や肌の裏が見える所がないかを、顔の拡大（正面・35°・横・後ろ）、デモの画角（立ち姿、首左 25° ＋ 上半身左 8°、首上 10°）、髪の裏とあごの下の拡大（首上 10°）で確かめる。見える所があれば、場所を書く（直さない）
3. B の髪で光線が届かなかった画素（3,065 画素）が、焼いたあとに近い髪の色で埋まっているかを確かめる

前提が曖昧なところは妥当な仮定を置いて最後まで進め、置いた仮定は最終回答に書いてください。書き込むのは `scripts/toy-character/` と `.work/toy-character/` の中だけ。コミットはしないでください。`build.py` に段 `hair3` として足し、`.work/toy-character/hair3/` に出力してください。

`hair2` と同じ値（髪の中の肌色の画素、色の差の平均、頭の輪郭 IoU、黒い斑点の画素数）を、`hair2` と並べて `metrics.json` に書き、`hair-compare.png` と `demo-color.png` を出してください。全体の三角形数も書いてください。

最終回答は日本語で、結論から。値の前後比較、キャップを外して見えるようになった所、残った斑点の場所、置いた仮定。前置きと繰り返しは削る。
