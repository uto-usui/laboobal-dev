# 依頼: 移した歩きのアニメーション（案 D）をデモに組み込む

`scripts/toy-character/prompt-walk-smooth2.md` の続きです。キャラの歩きを、恐竜と同じように「作者がキーで付けた歩きを再生し、接地中の足だけを留める」形にします。作者は「さらによくできるならやってほしい」と言っています。

最終回答は `-o` で受け取ります。ファイルへのリンクでなく本文そのものを書いてください。

## ここまでにあるもの

- 今のデモは案 C（手続きの歩き、`src/demos/toy-figure/walk.ts`）。控えは `.work/toy-character/backup-walk-smooth-c/walk.ts`
- 素材: `.work/toy-character/walk-smooth2/vendor/Universal Animation Library[Standard]/` の `UAL1_Standard.glb` の `Walk_Loop`（Quaternius、CC0 1.0。配布ページと同梱のライセンス文で確かめ済み）
- 前の回で作った変換: `.work/toy-character/walk-smooth2/walk-retarget.mjs` と `walk-retarget.json`（キャラの 20 本の骨への回転キー）。IK なしで再生した診断が `d-raw-sheet.jpg` と `d-raw-no-ik.webm`。形は人らしく歩いて見えるが、足が浮き、太ももが休みの姿勢から最大約 48°、膝が約 84° 動く。1 周約 1.33 秒を 0.68 秒で再生している
- 前の回は、この先（足を留める、角度を収める、止まる・歩き出すのつなぎ）で止まった

## やること

1. 変換を仕上げる。キャラは約 3 頭身で脚が短い。歩幅を脚の長さに合わせ、脚の振れ幅を縮めて、太ももと膝が 2026-11-20 に確かめた範囲（太もも前後 25°、膝 60°、腕前後 25°）に収まるようにする。縮めるのは平均の姿勢を中心にした振れ幅で、時間の流れと接地のタイミングは変えない（恐竜の Walk を作り直した `scripts/toy-character/dino4-bake.mjs` と同じ考え方）。歩調は 0.68 秒周期にこだわらず、新しい歩幅で自然に見える値にする
2. 接地中の足を、恐竜と同じやり方で地面に留める（`dinosaurs.ts` の足を留める処理を参考にする。`src/shared/` は変えない）。支える足の滑りは 0 に近く、膝は逆に曲がらない。体の進む速さは、接地中の足の後退量から決める
3. 止まる・歩き出すをつなぐ。押すと足をそろえて止まり、そちらを見て、また歩き出す（今の `walker` の状態の名前と、`data-walk-state` の値は変えない。E2E がそれを見ている）。歩きのポーズと立ちのポーズの間を時間で混ぜ、カクッとならないようにする。動きを減らす設定、画面の外での停止、横のドラッグも今までどおり
4. 焼いた歩きを `src/demos/toy-figure/assets/` に小さなファイル（JSON か GLB）で置き、元の配布ファイルから作り直せる変換スクリプトを `scripts/toy-character/` に置く。素材の取得は `.work/` に置いたまま（配布物はリポジトリに入れない）。`meta.ts` のクレジットに素材を足す
5. C と並べて比べる。D が C より自然に見えないなら、D はデモに入れずに C に戻し、そう書く
