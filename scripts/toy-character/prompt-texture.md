# 依頼: 服の色のモヤモヤの原因を切り分け、つるんとした色にする

`docs/toy-character/README.md` の続きです。Web のデモ（`--stage display2`、`src/demos/toy-figure/assets/character.glb`）を拡大すると、服の色に油絵のようなまだらと、小さな三角形の濃い点・明るい点が見えます（作者のスクショの範囲は、胸から袖・手まで。`.work/toy-character/display2/` の web の拡大と同じ範囲）。作者は、もう少しつるんとした見た目にしたいと言っています。形（404,807 三角形）と骨・ウェイトは変えません。

## 見立て（確かめること）

1. **UV の切れ端**: 生成した色の画像（`.work/toy-character/img3d/out/v4-noglasses_base.png`、4096 px）は、数千の小さな UV の島に分かれている。Web では縮めた画像（mipmap）や、display2 で 2048 px に縮めた画像を使うので、島の境目で隣の島や背景の色が混ざり、三角形の点になっている
2. **生成した色そのもののまだら**: デザインの「フリースの起毛」を、生成モデルが細かい色の斑として塗っている

## やること（比べるのは下の 4 つだけ）

袖（左右）と胸の切り替えの部分で、次の 4 つを作り、Web のデモと同じ描画（three.js、同じ照明・トーンマッピング、1440×900、dpr 2）で、作者のスクショと同じ範囲を撮って比べる。

- **0: 今のもの**（display2、体の色 2048 px）
- **1: 元の 4096 px のまま**（UV はそのまま）。1 の見立てのうち、縮めた分の影響を見る
- **2: UV を作り直して写し直す**: 体に、島の少ない新しい UV を作る（Blender の Smart UV Project か xatlas。袖・胴・脚などの大きな面が大きな島になるように）。同じメッシュの中で、元の UV と元の画像から新しい UV へ色を写す（Emission のベイク。光は焼かない）。4096 px で焼いて 2048 px にし、島のまわりに十分な余白を広げる
- **3: 2 ＋ 色の斑をならす**: 2 の画像に、境目を保つぼかし（bilateral か guided filter）をかけ、細かい色の斑だけを消す。しわやふくらみの大きな明暗は残す。ぼかしは部位（服の色の切り替え）の境目をまたがないようにする

測るもの: 撮った範囲での細かい明暗のばらつき（高い周波数の成分の量）と、三角形の点の数（周りと色が大きく違う小さな塊）。見た目は並べて目で見る。

## 採ったあと

いちばんつるんとして、しわやふくらみが残っているものを採る（どれも差がなければ 2）。採ったもので、体（とできれば顔・髪も同じ方法で。顔は目のまわりの画像と重ならないように）の色を作り直し、`character.glb` を置き換える。GLB は 15 MiB 以内、glTF Validator はエラー 0、`pnpm verify` を通す。

前提が曖昧なところは妥当な仮定を置いて最後まで進め、置いた仮定は最終回答に書いてください。書き込むのは `scripts/toy-character/`、`.work/toy-character/`、`src/demos/toy-figure/` の中だけ。コミットはしないでください。`build.py` に段 `texture` として足し、`.work/toy-character/texture/` に出力してください。開発サーバーは http://localhost:4410 で動いているので、それを使ってかまいません（止めないでください）。

## 確かめること（画像は自分で開いて見ること）

- `compare-sleeve.png`: 0〜3 を並べたもの（袖・胸・手の範囲）
- `uv-before-after.png`: 元の UV の島と、新しい UV の島
- 採ったあとの `web-desktop.png`（全身と、顔・胸・袖の拡大）を display2 と並べたもの
- `metrics.json`: 0〜3 の測った値、UV の島の数、GLB の大きさ、Validator と `pnpm verify` の結果
