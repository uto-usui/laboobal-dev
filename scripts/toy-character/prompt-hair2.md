# 依頼: 髪の色の焼き直し（黒い斑点を消す）

`docs/toy-character/README.md` の工程 7 の続きです。髪の作り直し（`--stage hair`、記録は `.work/toy-character/hair/log.md`）で B（詰めた面から作った髪、14,866 三角形）を採りました。横と後ろは元に近いですが、前髪と頭の上に黒く平らな斑点が残ります（`hair/hair-compare.png` の B / 0 deg、`hair/demo-selected-rest.png`）。

見立て: 元の頭には、毛束のすき間の奥に黒い裏打ちの面（マテリアル `Hair backing neutral black`）がある。B の面は毛束のすき間の上を埋めて通るので、そこから光線を飛ばすと、毛束の表ではなく奥の裏打ちに当たって黒を写している。

直すのは髪の焼き込みだけです。髪の形・UV・ほかの部位は変えません。

1. 焼く元から、裏打ちのマテリアルの面を外して、髪の色・法線・粗さを焼き直す
2. 外したことで届かなくなった画素は、焼いたあとに近い髪の色で埋める（工程 7 と同じ広げ方）
3. 見立てが合っているかを、焼き直す前に確かめて書く: 黒い斑点の画素の位置で、光線が当たっていた面のマテリアルを数える

前提が曖昧なところは妥当な仮定を置いて最後まで進め、置いた仮定は最終回答に書いてください。書き込むのは `scripts/toy-character/` と `.work/toy-character/` の中だけ。コミットはしないでください。`build.py` に段 `hair2` として足し、`.work/toy-character/hair2/` に出力してください。

## 確かめること

- `hair-compare.png`（高密度・前回の B・今回を、顔の拡大の正面・35°・横・後ろで並べる）と、デモの画角の立ち姿・首左 25° ＋ 上半身左 8°・首上 10° を開いて見る
- 前回と同じ 3 つの値（髪の中の肌色の画素、高密度との色の差の平均、頭の輪郭 IoU）と、髪の領域の中の黒い斑点の画素数（明るさが高密度の同じ画素より大きく暗い画素）を、前回の B と並べて書く

## 最終回答

日本語で、結論から。見立てが合っていたか（当たっていた面のマテリアルの数）、値の前後比較、残った斑点の場所、置いた仮定。前置きと繰り返しは削る。
