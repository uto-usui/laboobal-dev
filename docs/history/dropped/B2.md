# 下げたデモ（B2: canvas、three、UI）

laboobal の canvas のページ（`canvas/README.md`）に並んでいた Canvas 2D の基本の 9 個と、UI の virtual-scroll を下げた。どれも旧サイトで動かして見てから決めた。

## canvas-cross-origin

- もと: laboobal/docs/canvas/README.md の「cross origin」（`Canvas/CanvasCrossOrigin`）
- 何だったか: 別のドメインの画像を `crossOrigin = 'Anonymous'` で読み、canvas に描く
- 下げた理由: 画像を読む手順の説明だけで、見せたい動きがない。今は `source.unsplash.com` が止まっていて、旧サイトでは CORS のエラーが出て何も描かれない
- 残しておきたい考え方: `crossOrigin` は `src` を入れる前に付ける。画像のサーバーが `Access-Control-Allow-Origin` を返さないと読み込み自体が止まる（旧サイトで今起きていること）。付けずに読むと絵は描けるが canvas が汚れた扱いになり、`getImageData` や `toDataURL` で初めて例外になる。描けたかどうかでは気づけないので、画素を読むデモ（canvas-fill-text のような）を作るときに思い出す

## canvas-draw-svg

- もと: laboobal/docs/canvas/README.md の「Draw SVG」（`Canvas/DrawSvg`）
- 何だったか: SVG のロゴを `Image` で読み、箱の幅に合わせた大きさで canvas の真ん中に `drawImage` する
- 下げた理由: Canvas 2D の基本。素材の Vogue Japan のロゴは商標なので使えない
- 残しておきたい考え方: SVG は `drawImage` に渡した幅と高さで、その時点でビットマップになる。大きさが変わったら描き直せば、いつでもくっきり出る（写真を拡大したときのようにぼけない）。旧デモはロゴの縦横比（300:79）を箱の幅の割合で書いて、どの幅でも同じ比率で真ん中に置いていた

## canvas-draw-line

- もと: laboobal/docs/canvas/README.md の「Draw line」（`Canvas/DrawLine`）
- 何だったか: 真ん中から 2 本の線を引く
- 下げた理由: Canvas 2D の基本で、MDN に同じ内容がある
- 残しておきたい考え方: 旧デモの canvas は `canvas.width` を CSS の幅と同じにしていて、Retina の画面では 1px の線がにじんでいた。描画の解像度を `devicePixelRatio` 倍にして、座標は CSS の px のまま書けるよう変換を掛ける（共有の `fitCanvas` がしていること）。どの Canvas 2D のデモでも最初にする

## canvas-draw-rect

- もと: laboobal/docs/canvas/README.md の「Draw polygon」（`Canvas/DrawRect`）
- 何だったか: 4〜8 個のでたらめな点を順につないで塗る
- 下げた理由: Canvas 2D の基本で、MDN に同じ内容がある
- 残しておきたい考え方: でたらめな点を順につなぐと辺が交差する。`fill()` は既定の `nonzero` で塗るので、交差してできた内側も塗られる。`fill('evenodd')` にすると重なったところが抜ける。図形を重ねて穴を開けたいときは、パスの向きか塗りの規則で決める

## canvas-draw-circle

- もと: laboobal/docs/canvas/README.md の「Draw Circle」（`Canvas/DrawCircle`）
- 何だったか: でたらめな始まりと終わりの角度で円の一部を塗る
- 下げた理由: Canvas 2D の基本で、MDN に同じ内容がある
- 残しておきたい考え方: `arc` の前に `moveTo(中心)` を入れてから `closePath` すると扇形（パイ）になる。`moveTo` を抜くと弧の両端を結んだ弓形になる。円グラフや、時間で減っていくゲージは前の形で作る

## canvas-draw-text

- もと: laboobal/docs/canvas/README.md の「Draw Text」（`Canvas/DrawText`）
- 何だったか: 「laboobal」を真ん中に書く
- 下げた理由: Canvas 2D の基本で、MDN に同じ内容がある
- 残しておきたい考え方: `textAlign = 'center'` と `textBaseline = 'middle'` にすると、渡した座標が文字の真ん中になる。旧デモはそれに加えて y から文字の大きさを引いていて、文字が上にずれていた。基準線を真ん中にしたら、座標はそのまま真ん中を渡す

## canvas-draw-shadow

- もと: laboobal/docs/canvas/README.md の「Draw Shadow」（`Canvas/DrawShadow`）
- 何だったか: 影を設定してから 2 本の線を引く
- 下げた理由: Canvas 2D の基本で、MDN に同じ内容がある
- 残しておきたい考え方: `shadowBlur` や `shadowColor` は描く図形ではなく context に残る設定で、一度入れるとあとに描くものすべてに付く。旧デモは 2 本とも影が付いていた。一部にだけ付けたいときは `save()` と `restore()` で挟む。`globalAlpha` や `globalCompositeOperation` も同じ

## canvas-draw-gradient

- もと: laboobal/docs/canvas/README.md の「Draw Gradient」（`Canvas/DrawGradient`）
- 何だったか: 線形と円形のグラデーションを 1 つずつ作り、それぞれ 2 つの四角に塗る
- 下げた理由: Canvas 2D の基本で、MDN に同じ内容がある
- 残しておきたい考え方: グラデーションの座標は塗る四角ではなく canvas の座標で決まる。旧デモは 1 つのグラデーションを離れた 2 つの四角に塗っていて、2 つの四角が 1 枚のグラデーションの別々の場所を切り取ったように見えていた。四角ごとに同じ色の変化を付けたいなら、四角ごとに作るか、`translate` で原点を動かしてから塗る

## canvas-alpha-blending

- もと: laboobal/docs/canvas/README.md の「Alpha Blending / CompositeOperation」（`Canvas/AlphaBlending`）
- 何だったか: `globalCompositeOperation` の 26 種類を select で選び、半透明の線を 100 本描き直す
- 下げた理由: Canvas 2D の基本。ページがリンクしているサンプル集や MDN に、同じ一覧の見本がある
- 残しておきたい考え方: 旧デモは描き直すときに白で塗りつぶして消していたが、合成の方法を戻さずに塗っていたので、`destination-out` や `xor` を選んだあとは白い下地がうまく敷けなかった。消すときは先に `globalCompositeOperation = 'source-over'` に戻す（`clearRect` なら合成の方法に左右されない）。また、白で塗りつぶした不透明な下地の上では、`source-in` のように下地の透明度を見る合成はほとんど違いが出ない。合成の違いを見せたいなら、下地を透明のまま残す

## virtual-scroll

- もと: laboobal/docs/UI/virtualScroll.md（`UI/VirtualScroll`）
- 何だったか: 9 個の箱を使い回して、13 件の名前の並びをホイールで無限に回す
- 下げた理由: 本文が「tes」だけの試しのページで、見えるのは箱の列が流れることだけ。中身の名前は漫画の登場人物で、そのまま使えない。ホイールの量を速さとして入れて減らさないので、一度回すと止まらずに流れ続ける
- 残しておきたい考え方: DOM の数を見えている分（9 個）に固定し、上の端を出た箱を一番下の箱のさらに下へ移して、中身を「一番下の箱の次の番号」に入れ替える。逆向きも同じ。これで件数がいくつあっても DOM は 9 個のままで、つなぎ目なく回り続ける。止まるようにするには、ホイールで入れた速さを毎フレーム 0 へ近づける（旧デモはここが抜けていた）
