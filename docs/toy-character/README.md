# 写真から作るおもちゃ風の 3D キャラ

子どもの写真から、おもちゃ風のかわいい 3D キャラを作り、ボーンを入れて labobal.dev のデモとしてマウスで動かします。この文書は、作り方と決めたことの記録です。あとから同じ手順で作り直せるように、工程ごとの入力、出力、確かめ方を残します。

## 役割

- 制作は Codex（`codex exec`）が受け持つ。画像の生成、Blender のスクリプト、three.js の実装まで
- Claude Code は進行役。Codex への依頼文を書いて渡し、出てきたものを確かめ、作者に見せる場面を決める
- 見た目は作者が決める。デザイン画と、工程の区切りのレンダは作者に見せてから先へ進む

Codex への依頼文は `scripts/toy-character/prompt-*.md` に残す。実行は次の形（モデルと effort は毎回指定する）。

```sh
cat scripts/toy-character/prompt-<名前>.md | codex exec -m gpt-6.1-sol -c model_reasoning_effort=medium \
  --sandbox workspace-write -o .work/toy-character/codex-<名前>-out.md --cd <リポジトリのルート> -
```

Blender を動かす依頼だけは `--sandbox danger-full-access` にする。`workspace-write` のサンドボックスでは、Blender が起動時の GPU（Metal）の初期化で落ちる（SIGSEGV、2026-11-18 に Blender 5.2.2 と codex-cli 0.169.0 で確かめた）。サンドボックスの外なら EEVEE も Cycles も動く。そのぶん、依頼文に「書き込むのは worktree の中だけ」と書く。

| 5 | 頭を別に生成してデザイン画に合わせる | v4 の頭の切り抜き | 頭のメッシュ（seed 42） | `fidelity-method.md` の「近い」の基準。作者に見せる |
| 6 | 面を落とす（全身を減面、首を重ねる、手首の境目を分ける） | 体と頭の高密度メッシュ | 軽いメッシュ（約 5 万三角形） | 距離と輪郭の基準、仮の骨で曲げたポーズのレンダ |

| 8 | デザイン画の色を投影する（光を抜いた色） | v4、3 面図 | 直したテクスチャ | `fidelity-method.md` の色の基準、4 方向のレンダ |
| 9 | 目を画像の層に分け（3 コマと黒目）、眼鏡を付ける | 軽いメッシュ | 顔の部品 | 正面・斜めのレンダとまばたきの途中の形。作者に見せる |

| 12 | Web のデモ | GLB | `src/demos/<slug>/` | ブラウザで開き、canvas が描かれ、マウスに追従するか |

Blender の作業は `blender -b --factory-startup -P scripts/toy-character/build.py` で、毎回スクリプトから作り直す。手で触った .blend を正にしない。`.blend` と確認用のレンダは `.work/toy-character/`（コミットしない）に出す。
